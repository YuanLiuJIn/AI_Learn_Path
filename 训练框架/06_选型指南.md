# 训练框架选型指南

> 结合你已有的基础（Qwen2.5-7B SFT 经验 + AgentRL 专题 + 多模态检索专题），
> 给一套"按场景 / 按资源"直接照着选的方案。

---

## 1. 按"你要做什么"选

```text
Q1：预训练千亿模型？
  └─ Megatron-LM / DeepSpeed + 万卡（你基本不用）

Q2：SFT / LoRA 一个开源模型？
  ├─ 最省事        → LLaMA-Factory（有 UI）
  ├─ 单卡显存紧    → Unsloth
  ├─ 要训 VLM     → ms-swift
  └─ 想写代码控制 → TRL / Axolotl

Q3：做 RL（对齐 / 推理 / Agent）？
  ├─ 入门 GRPO/PPO → TRL
  ├─ 中规模 RLHF   → OpenRLHF
  ├─ 读源码学 RL   → Slime
  ├─ 多模态 RL     → veRL
  └─ 多轮 Agent RL → AReaL

Q4：训 VLM（看图）？
  ├─ 学原理       → LLaVA 源码
  ├─ 快速出模型   → ms-swift / LLaMA-Factory
  └─ VLM + RL     → veRL + R1-V 思路

Q5：训完部署？
  ├─ 高吞吐       → vLLM
  ├─ Agent/结构化 → SGLang
  └─ 训推一体     → LMDeploy
```

---

## 2. 按"你的资源"选

| 条件 | 推荐 |
|---|---|
| 单张消费卡 24G | Unsloth + LoRA，Qwen2.5-7B |
| 单/多张 80G | LLaMA-Factory 全参 SFT，或 TRL 跑 GRPO |
| 小集群几~几十卡 | FSDP2 / DeepSpeed + LLaMA-Factory |
| 想做 Agent RL | 先 TRL 跑通 GRPO，再上 veRL / AReaL |
| 想做 VLM | ms-swift 起步最快 |

---

## 3. 给你的一条具体路线

```text
第 1 步（巩固）：LLaMA-Factory 复现你的 SFT
  → 把 2300 条数据工程化、可复现

第 2 步（省资源）：Unsloth 单卡把 SFT 跑更快更省
  → 验证你 92% 准确率可更低成本复现

第 3 步（多模态）：ms-swift 把 Qwen 接成 VLM
  → 输入 UE 截图+日志，输出测试判断
  → 打通"多模态检索"专题

第 4 步（RL 入门）：TRL 跑通 GRPO
  → reward = 生成的 JSON 用例是否合法可执行
  → 打通 AgentRL 专题

第 5 步（进阶）：veRL / AReaL 做多轮 Agent RL
  → 你的 UE5 测试 Agent 天然场景
```

---

## 4. 常见误区

```text
误区 1："用 AI 生成" = 用了全部 AI 技术
  真相：大部分只是第 3 层推理（调 API），连模型都没碰

误区 2：RL 框架一定需要 Critic
  真相：GRPO 去掉 Critic，用组内均值当 baseline，更稳

误区 3：训 VLM 必须自己写训练代码
  真相：ms-swift / LLaMA-Factory 一行命令就能训 Qwen-VL

误区 4：框架越新越要用
  真相：先 LLaMA-Factory/TRL 跑通，再按需上 veRL/AReaL
```

---

## 一句话总结

> 记住三句话：**个人 SFT 用 LLaMA-Factory/Unsloth，多模态用 ms-swift，
> RL 从 TRL 入门再上 veRL/AReaL，部署用 vLLM/SGLang。** 先跑通最省事的，
> 再按需深入底层框架。
