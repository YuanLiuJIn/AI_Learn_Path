# 02 各模态评测工作与评测体系建设

> 对应 JD：「LLM、T2I、T2V、I2V、MLLM 模型评测工作和评测体系建设」。
> 本章是四个模态专题笔记（`语言/多模态/扩散/语音模型评测/`）在「体系建设」层面的上位概括，并补上此前未细讲的 **T2V（文生视频）/ I2V（图生视频）**。

---

## 0. 评测体系建设通用方法论（从 0 到 1）

不管评哪类模型，体系搭建都遵循同一套流程：

```
① 评测目标定义 ──► 业务/模型迭代想知道什么？
② 能力维度拆解 ──► 把"好不好"拆成正交、可判定、有区分度的维度树
③ 指标选型 ──────► 每个维度选客观指标 or 人评 or LLM-judge，并验证与人评相关性
④ 数据集建设 ────► 真实日志>专家写>公开改造>合成；做标注规范(Rubric)+κ一致性
⑤ 自动化Pipeline ─► 配置化、可复跑、可复现（记录模型hash/版本/参数）
⑥ 报告与归因 ────► 分维度雷达图 + bad case 聚类 + 能力边界 + 训练归因
⑦ 闭环 ─────────► 接 CI，checkpoint 自动评测，成为发布门禁
⑧ 防过拟合 ──────► 测试集隔离 + 滚动更新(LiveBench 思路) + 污染检测
```

> 这一节是 JD「评测体系建设」的骨架，后面 5 类模型只是这套骨架的不同实例。

## 1. LLM 评测工作

### 1.1 评测维度（能力树）
知识(MMLU/C-Eval) / 推理(GPQA/MATH) / 代码(HumanEval/SWE-bench) / 指令遵循(IFEval) / 长上下文(RULER) / Agent(τ-bench) / 偏好(MT-Bench/Arena) / 安全(HarmBench) / 效率(TTFT/吞吐)。详见 `语言模型评测/学习笔记.md` §2。

### 1.2 两种打分实现（必懂）
- **Loglikelihood**（base 模型、客观题）：比选项对数似然取最大，有长度归一化问题（acc vs acc_norm）。
- **生成式**（chat 模型）：正则抽取答案，依赖格式遵循。

### 1.3 评测体系建设要点
- 客观题用 greedy（T=0）；采样题固定 seed 多次取均值。
- 复现差异排查表（语言笔记 §1.2）：模板/解码/后端/few-shot 顺序。
- 报告必须写清"用哪种打分"。

## 2. MLLM（多模态大模型）评测工作

### 2.1 特有维度
感知(OCR/物体) / 认知(图表推理) / 幻觉(POPE) / Grounding(RefCOCO, IoU@0.5) / 视频理解(Video-MME) / 多模态 Agent(ScreenSpot)。详见 `多模态模型评测/学习笔记.md` §2。

### 2.2 方法论武器（评测体系建设必用）
- **纯文本消融**：去图后 LLM 还能答对的题是无效题（MMStar 的 ML 泄露指标）。
- **CircularEval**：N 选项循环移位，N 次全对才算过，暴露位置偏置。
- **MG / ML 指标**：证明分数是"真视觉能力"而非语言先验。

### 2.3 体系建设要点
- 每题标：能力维度 / 是否依赖视觉 / 图像类型。
- 多选题设计强干扰项。
- 开放式题给 Rubric + 参考答案，用 GPT-4V judge 并报告一致率。

## 3. T2I（文生图）评测工作

### 3.1 指标三层
| 层 | 指标 | 说明 |
|---|---|---|
| 质量 | FID(clean-fid) / IS / 美学分 | FID 有 6 坑（扩散笔记 §3.1） |
| 一致性 | CLIPScore / **VQAScore** / TIFA / GenEval | VQAScore 当前最优组合一致性 |
| 偏好 | ImageReward / HPSv2 / PickScore | 易 reward hacking，需交叉验证 |

### 3.2 组合性专项
GenEval（检测器验证 6 类）、T2I-CompBench（属性绑定/空间关系）——多数模型在"位置"和"属性绑定"崩溃。

### 3.3 体系建设要点
- 评测配置必须统一公开：步数/CFG/seed/分辨率/负prompt/是否改写 prompt。
- 每个 prompt 生成 ≥4 张取均值（生成方差大）。
- 自动指标必须与人评做 Spearman 校准（EvalCrafter 回归法）。

## 4. T2V（文生视频）评测工作

### 4.1 为什么比 T2I 难
视频多了**时序维度**：一致性、运动、流畅度。静止视频能拿高"一致性"分却毫无价值 → VBench 专门加 **dynamic degree** 维度对抗。

### 4.2 核心指标
- **FVD**：I3D 特征上的 FID，对帧数/分辨率极敏感。
- **VBench 16 维**：质量类（主体/背景一致性、时序闪烁、运动平滑度、动态程度、美学、成像）+ 一致性类（物体/动作/颜色/空间/场景/风格/整体），**每维都做了与人评对齐验证**。
- **VideoScore**：在 37.6k 人标上训练的回归模型，5 维自动分，Spearman 优于 GPT-4V。

### 4.3 工程要点
- 抽帧策略（均匀/关键帧）、帧数上限、是否用字幕 → 必须报告否则不可比。
- 数据体量大（TB 级），需预抽帧缓存。

**论文**：VBench (arXiv:2311.17982)、EvalCrafter (arXiv:2310.11440)、VideoScore (arXiv:2406.15252)
**代码库**：[VBench](https://github.com/Vchitect/VBench)、[EvalCrafter](https://github.com/evalcrafter/EvalCrafter)

## 5. I2V（图生视频）评测工作

### 5.1 与 T2V 的区别
输入多了一张**参考图**，评测要额外关心：
- **首帧保真度**：生成视频第 1 帧与输入图的相似度（用 CLIP/IQA/SSIM 计算）。
- **主体一致性**：视频中物体外观是否始终与参考图一致（人物脸/物体 ID 不漂移）。
- **运动合理性**：参考图是静物，生成的动作是否符合物理（不抽搐、不形变）。
- **指令遵循**：文本 prompt 描述的动作/镜头是否执行。

### 5.2 I2V 特有指标
- **首帧一致性**：第 1 帧特征与参考图的 cosine（CLIP image-image）。
- **身份保持度**：用人脸/物体识别模型抽帧特征，算与参考图的平均相似度曲线（看是否逐帧漂移）。
- **时序一致性**：VBench 的主体/背景一致性维度同样适用，但阈值更严。
- **动态程度**：避免"假视频"（几乎不动）。

### 5.3 常见失败模式
参考图人脸在视频中逐渐失真、物体数量变化、违反物理的运动、与 prompt 动作不符。

**论文/项目**：Stable Video Diffusion (arXiv:2311.15127)、I2V 多用 VBench 扩展 + 自研首帧指标
**代码库**：[VBench](https://github.com/Vchitect/VBench)（可扩展 I2V 维度）、[ComfyUI](https://github.com/comfyanonymous/ComfyUI)

## 6. 五类模型评测维度横向对比

| 模型 | 主维度 | 首选客观指标 | 首选框架 | 人评必要性 |
|---|---|---|---|---|
| LLM | 知识/推理/指令/偏好/安全 | MMLU/SWE-bench/MT-Bench Elo | OpenCompass/harness | 偏好类需 |
| MLLM | 感知/认知/幻觉/Grounding | MMBench/POPE/MMMU | VLMEvalKit | 开放式需 |
| T2I | 质量/一致性/偏好 | FID/VQAScore/GenEval | clean-fid/VQAScore | 必须 |
| T2V | 质量+时序一致性 | VBench 16维/FVD | VBench | 必须 |
| I2V | 首帧保真+主体一致+动态 | 首帧CLIP/VBench扩展 | VBench扩展 | 必须 |

## 7. 评测体系建设的组织与工程化

### 7.1 指标中台（维度字典）
把每个维度定义成结构化配置：维度名 / 数据类型 / 指标 / 判分方式 / 人评 Rubric / 是否门禁项。

### 7.2 版本门禁（Release Gate）
- 每个模型版本必须过的最低分（按维度设阈值）。
- 回归对比上一版本，delta 超阈值阻断发布。
- 给 bootstrap 95% 置信区间，避免噪声误判（语言笔记 §7）。

### 7.3 评测看板
- 分维度雷达图 + 时间轴曲线（看训练退化）。
- bad case 画廊 + 可筛选（按维度/错误类型）。
- 成本-效果曲线（同成本最优模型）。

### 7.4 防评测集过拟合
- **训练/测试隔离**：评测集不进训练，定期滚动更新（LiveBench 每月更新）。
- **污染检测**：n-gram / canary / 时间切分 / 改写鲁棒性（语言笔记 §5.2）。
- **多集交叉**：官方集 + 自有 holdout，避免只在一个集上刷分。

### 7.5 人评体系（生成类命脉）
- 拆问题（一致性 vs 质量），双盲 + 随机顺序 + 锚点样本。
- 报 Krippendorff's α / Fleiss' κ，< 0.6 回炉。
- 自动指标做日常回归，人评做版本终审（两级机制）。
