# Chapter 04：联合嵌入预测架构——JEPA 与 I-JEPA

## 4.1 核心思想：预测"含义"，而非"像素"

Dreamer 要重建画面，扩散模型要生成画面。JEPA（Joint-Embedding Predictive Architecture，联合嵌入预测架构）提出一个反直觉的主张：

> **预测未来，不必重建未来。** 只需在**抽象表征空间**里预测，而不是在像素空间。

动机：把容量花在"画清楚背景"上，对决策毫无帮助；而且像素级预测会被**不可预测的细节**（树叶摆动、光照闪烁）逼着去"猜噪声"。JEPA 干脆放弃像素，只预测"会发生什么"的语义。

出处：LeCun《A Path Towards Autonomous Machine Intelligence》(2022)。

## 4.2 架构：三个网络

```text
上下文 x ──► context encoder ──► s_x ──► predictor ──► ŝ_y
                                                         │  对比（表征空间 L2）
目标   y ──► target encoder  ──► s_y ────────────────────┘
              （EMA 慢更新，不接收梯度）
```

- **context encoder**：编码可见部分（如图像未被遮挡的块）。
- **target encoder**：编码要预测的部分；用 **EMA（指数滑动平均）** 从 context encoder 复制，不参与梯度。
- **predictor**：在表征空间从 $s_x$ 预测 $s_y$。

这个结构和 **BYOL**（Grill et al., 2020, arXiv:2006.07733）非常像——都是"在线网络预测 EMA 目标网络的表征"。I-JEPA（Assran et al., CVPR 2023, arXiv:2301.08243）把它用于图像：遮住若干块，预测这些块的**表征**（而非重建像素）。

## 4.3 防坍塌：JEPA 的第一难题

如果没有任何约束，网络可能把所有输入都映射成**同一个向量**——预测任务"白送"完成，这叫**表征坍塌（collapse）**。三种常用对策：

| 手段 | 机制 | 代表 |
|---|---|---|
| **EMA + stop-gradient** | 目标网络慢更新、不回传，打破对称 | BYOL、I-JEPA |
| **方差-协方差正则（VICReg）** | 惩罚某一维方差过小、不同维相关性过高 | Bardes et al., ICLR 2022 |
| **对比损失** | 拉近正样本、推开负样本 | SimCLR、CPC |

**VICReg 三项损失**（记住名字即可，不必背公式）：

```text
invariance：s_x 与 s_y 尽量接近（预测要准）
variance  ：每个维度在 batch 内要有足够方差（不许压成常数）
covariance：不同维度之间要去相关（防冗余）
```

这三项合起来，让表征"既预测得准、又信息丰富"——从信息论看，是在做**信息最大化 + 冗余最小化**。

## 4.4 从 I-JEPA 到 V-JEPA 2

| 工作 | 年份 | 做什么 |
|---|---|---|
| **I-JEPA** | 2023 | 图像：遮挡块表征预测，无需数据增强 |
| **V-JEPA** | 2024, arXiv:2404.08471 | 视频：时空块表征预测，学"运动与物体"直觉 |
| **V-JEPA 2** | 2025, arXiv:2506.09985 | **动作条件世界模型 + 机器人规划**：用视频预训练，再在少量机器人数据上适配，实现零样本规划 |

V-JEPA 2 是本系列的一个关键转折点：它证明"表征空间世界模型"不仅能学视觉直觉，还能**直接支撑具身规划**——预测未来表征，然后在表征空间里做规划、反推动作。

## 4.5 应用与局限

**应用**：视频理解、机器人操作中的视觉推理、作为 RL 的表征骨干（替代从头学编码器）。

**局限**
- **不可渲染**：你拿不到"未来画面"，人无法直观检查模型对不对，评估更难。
- **预测什么由谁定**：预测目标块/时空段的选取是超参，影响学到的抽象层次。
- **长程仍是难题**：表征预测同样有误差累积，只是发生在语义层。
