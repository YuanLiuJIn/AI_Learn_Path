# Agent 系统设计

> 目标：系统学习如何设计一个生产级的 AI Agent 系统，理解"上下文 × 工具 × 循环"的乘积关系。

## 核心公式

```text
Agent 能力 = 上下文质量 × 工具可用性 × 循环效率
```

**不是加和，是乘积。** 任一要素为 0，整体能力归零。

## 学习目标

学完这个专题后，你应该能回答：

1. 为什么 Agent 能力是乘积而非加和？
2. 上下文设计的"不可能三角"是什么？如何权衡？
3. 五层上下文分区分别放什么？为什么这样分？
4. 什么是"稳定前缀设计"？为什么它对 Cache 友好？
5. 渐进式工具发现如何节省 80% 的初始 Token？
6. 为什么"描述清晰度 = 成功率"？
7. 四层错误反馈分别是什么？各有什么作用？
8. 三层循环控制如何防止 Agent 死循环？
9. Memory 如何实现跨会话知识复用？
10. 如何把 Agent 设计模式应用到 UE5 测试项目？
