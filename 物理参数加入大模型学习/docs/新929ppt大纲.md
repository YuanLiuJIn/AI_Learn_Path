A2. 自动微分 vs 离散化约束的系统比较
论文：arXiv:2609.07437（2026-09）
解决什么问题：AD（无网格、连续）与离散化约束（差分、弱形式）两条路线，此前没有系统研究过各自适用边界。
Idea：在从线性 Poisson 到高马赫数高超声速流动（含强间断）的问题谱上，用严格的误差分解（近似误差 / 优化误差 / 截断误差）对比两类范式，同时对比 MLP 与 GNN。
结论：非线性越强，离散化约束越占优——它用更小的优化误差补偿了截断误差；非线性与边界条件越复杂，GNN 相对 MLP 的优势越大。
尚存问题：摘要未给实验规模、误差分解的具体数值；结论对维度、网格分辨率的依赖边界未知；未比较计算成本。
A3. 数值精度之争（FP64 vs FP32）
论文：FP64 is All You Need: Rethinking Failure Modes in Physics-Informed Neural Networks（OpenReview 公开评审版）
Idea：挑战"PINN 失败源于损失病态/梯度不平衡"的主流理解，论证真正的元凶是FP32 精度不足，改用双精度即可大幅消除所谓"病态"。
意义：如果成立，前几年大量针对"损失刚性"设计的复杂加权/因果训练方案，其收益可能部分来自浮点误差补偿。
A4. 领域系统综述的冷静结论
论文：arXiv:2608.10047（J. Intelligent Manufacturing），覆盖 212 篇 PIML-for-PHM 文献
结论：四类方法（观测/归纳/学习/混合偏置）在预测性能上一致优于纯数据驱动基线；但文献极度集中在锂电池与轴承两类对象；多为问题定制方案，缺乏可迁移性。
最尖锐的一条：PIML 宣称能改善"泛化差、因果推断缺失、可解释性不足"这三个原初动机，目前缺乏充分证据支撑。
建议方向：可迁移设计模式、统一基准、可在线部署的轻量化 + 鲁棒的不确定性模型。

B2. Transformer / 注意力系
OrthoSolver（ICLR 2026）：从 POD（本征正交分解）到互信息，提出"神经正交分解"框架，把求解器的内部表示显式正交化，在 PDEBench 七个基准（Advection / Burgers / Navier–Stokes / Diffusion-Sorption / Diffusion-Reaction 等）上取得最优。
并行多尺度注意力（2026）：宣称在单张 GPU 上处理数百万点，在弹性、塑性、流体、多孔介质以及 ShapeNet-Car / Ahmed-ML 等大规模气动数据集上验证。
Transolver 的 Physics-Attention 仍是基线；PirateNets（自适应残差连接、由浅入深）成为新默认骨干。
尚存问题：注意力类方法在 3D、长时间 rollout、强间断上的优势不如在 2D 光滑问题上明确；可解释性差；训练成本高。
B3. KAN 系
KAN-PINN / PIKAN / Chebyshev-KAN（Sci. Rep. 2025 等）：把可学习激活函数放到边上而非节点上，可解释性更强、能导出符号表达式。混合 Kolmogorov–Arnold 网络被用于改善 MLP 的谱偏置。
尚存问题：KAN 的训练成本与稳定性在规模上不如 MLP，目前多在低维、小问题上有效；"可导出公式"这一优势在含噪真实数据上常不成立。

  主线 C：从解方程到 PDE 基座模型
这是范式级的变化：从"一个 PDE 训一个网络"转向"大规模预训练 + 少样本微调"。

C1. NESTOR（CVPR 2026，arXiv:2602.22059）
解决什么问题：现有神经算子依赖单一网络架构，无法捕捉异构 PDE 系统的多样特征，成为大规模 PDE 预训练的瓶颈。
Idea：两级嵌套混合专家（Nested MoE）——图像级 MoE 捕捉全局依赖，词元级 Sub-MoE 捕捉局部依赖；按输入选择性激活最合适的专家。在 12 个 PDE 数据集上大规模预训练并迁移到下游。
尚存问题：嵌套 MoE 的路由塌缩与负载均衡风险、显存与训练成本都高于单架构；摘要未说明 OOD 表现与专家学到何种物理语义。
C2. 生成式 PDE 基座模型：Flow Marching（arXiv:2509.18611）
解决什么问题：现有 PDE 基座模型多为确定性 Transformer，缺乏生成式灵活性；长期 rollout 误差累积（drift）严重。
Idea：把神经算子学习与 flow matching 桥接。关键设计是联合采样噪声水平与物理时间步，学到一个统一 velocity field，把带噪当前状态输运到干净的下一步状态 → 减少长期漂移 + 支持不确定性感知的集成分支采样。配套 P2VAE（物理预训练 VAE 压缩隐空间）+ FMT（Flow Marching Transformer，含 diffusion-forcing 与隐式时间金字塔，相对全长度视频扩散最高 15× 效率提升）。语料约 250 万条轨迹、12 个 PDE 族。
注意：该文已被 arXiv:2602.11229 大幅扩展并取代，引用时请用后者。
尚存问题：隐空间压缩可能丢失高频/小尺度细节（湍流风险点）；"15×"是相对视频扩散模型而非相对确定性算子；生成式推理本身比单次前向更贵。
C3. 组合式与统一算子
CompNO / Compositional Neural Operators（2026-03）：模块化架构，用结构化物理模块组合求解多维流体。
Starter-Iterator Neural Operator（arXiv:2606.18305v2，2026-09）：统一处理正问题与反问题的单一架构。
AOT-POT（arXiv:2605.15793）：自适应算子变换用于大规模 PDE 预训练。
尚存问题：这些工作普遍缺少与经典数值求解器在同等精度下的成本对比；预训练分布外的 PDE 泛化性存疑；"基座模型"是否真带来 scaling law 收益仍有争议。

主线 D：LLM / Agent 与 PIML 融合
这是与你工作区名"物理参数加入大模型学习"最贴近的方向。

D1. PiT-PO（arXiv:2602.10576，2026-07）
解决什么问题：科学方程自动发现（symbolic regression）中，LLM 生成的候选方程往往物理上无效（量纲不符、违反守恒）。
Idea：Physics-informed Token-regularized Policy Optimization——用强化学习把 LLM 从"静态提议器"变成"自适应生成器"。核心是双重约束机制：在序列层面强制层级化物理有效性，同时在 token 层面做细粒度正则化。闭环进化过程 + 物理校验器作为奖励。
尚存问题：依赖可自动化的物理校验器（量纲/守恒好写，复杂约束难写）；搜索空间随方程复杂度爆炸；未在真实实验数据上闭环验证。
D2. Lang-PINN（GitHub: poochat/LANG-PINN）
Idea：多智能体框架，从自然语言自动生成 PINN：包括方程解析、损失构建、网络配置、训练调优四类智能体，适配 PINNacle 基准 PDE 任务，可直接运行。
尚存问题：本质是"LLM 写代码"，不是"LLM 内嵌物理"；对复杂几何/多物理问题的成功率与鲁棒性未充分报告。
D3. 与 A5 呼应
"物理对齐（Physics Alignment）"被提出为新的前沿问题：如何让 AI 的优化目标（通过测试）与真正的科学目标（符合物理定律）保持一致。这与 RLHF 的 alignment 是同一逻辑，只是奖励函数变成了物理自洽性。
