# 微调框架（SFT / LoRA / DPO）

> 这层是你**最常用**的：用小数据集让开源模型擅长你的任务。
> 你做过的"2300 条数据 SFT 微调 Qwen2.5-7B"就在这里。
> 特点是：从"写代码训练"进化成"填配置训练"。

---

## 1. LLaMA-Factory

### 特点

```text
- 最火的国产友好微调框架，Web UI + CLI 双形态
- 覆盖 100+ 模型，LLM 和 VLM 都支持
- 支持 LoRA / QLoRA / 全参 / DPO / KTO 等多种方法
- 有可视化 Web UI，新手友好
- 适合：绝大多数 SFT / 对齐任务的首选
```

### 安装

```bash
# 方式一：pip 直接装
pip install llamafactory

# 方式二：源码安装（推荐，方便看例子）
git clone https://github.com/hiyouga/LLaMA-Factory
cd LLaMA-Factory
pip install -e ".[torch,metrics]"
```

### 最小可运行示例（CLI）

准备一个 YAML 配置 `qwen_lora_sft.yaml`：

```yaml
model:
  model_name_or_path: Qwen/Qwen2.5-7B-Instruct

stage: sft
do_train: true
finetuning_type: lora
lora_rank: 16
lora_target: all

dataset:
  - identity
  - glaive_toolcall_zh

output_dir: saves/qwen2.5-7b/lora/sft
per_device_train_batch_size: 4
gradient_accumulation_steps: 4
learning_rate: 1e-4
num_train_epochs: 3.0
bf16: true
```

启动：

```bash
llamafactory-cli train qwen_lora_sft.yaml
```

启动 Web UI：

```bash
llamafactory-cli webui
```

## 2. ms-swift（ModelScope 魔搭）

### 特点

```text
- 魔搭社区出品，训练/评测/部署一体
- 支持 600+ 文本模型 + 400+ 多模态模型（VLM/语音/视频）
- 一条命令完成 SFT，多模态能力尤其强
- 适合：想训 VLM、或想要"训完直接评测部署"的一站式体验
```

### 安装

```bash
pip install ms-swift
# 可选：需要多模态时
pip install ms-swift[llm]   # 或 [all]
```

### 最小可运行示例

```bash
# 单卡 LoRA SFT Qwen2.5-7B
swift sft \
    --model Qwen/Qwen2.5-7B-Instruct \
    --dataset ai-modelscope/self-cognition \
    --train_type lora \
    --lora_rank 16 \
    --output_dir output_qwen_lora

# 训 VLM（图文）
swift sft \
    --model Qwen/Qwen2.5-VL-7B-Instruct \
    --dataset AI-ModelScope/LaTeX_OCR \
    --train_type lora
```

Python 代码方式：

```python
from swift.llm import Swift, Trainer, Model, dataset
model = Model.load('Qwen/Qwen2.5-7B-Instruct')
tuner = Swift.prepare_model(model, {'lora_rank': 16})
trainer = Trainer(model, tuner, dataset=['ai-modelscope/self-cognition'])
trainer.train()
```

## 3. Axolotl

### 特点

```text
- 社区老牌，YAML 配置驱动，极简
- 对各类模型和 LoRA 配置支持灵活
- 适合：喜欢"一个 yaml 搞定一切"的玩家
```

### 安装

```bash
git clone https://github.com/axolotl-ai-cloud/axolotl
cd axolotl
pip install -e ".[flash-attn,deepspeed]"
```

### 最小可运行示例

`config.yml`：

```yaml
base_model: Qwen/Qwen2.5-7B-Instruct
model_type: AutoModelForCausalLM
tokenizer_type: AutoTokenizer
load_in_4bit: true
adapter: qlora
lora_r: 16
lora_alpha: 32
datasets:
  - path: mhenrichsen/alpaca_2k_test
    type: alpaca
num_epochs: 3
micro_batch_size: 4
learning_rate: 2e-4
```

启动：

```bash
accelerate launch -m axolotl.train config.yml
```

## 4. Unsloth

### 特点

```text
- 手改 CUDA / Triton kernel，训练速度约 2x，显存减半
- 单卡消费级显卡（如 24G）也能训 7B/14B
- API 兼容 HuggingFace，改几行就能用
- 适合：显存紧、只想快速 SFT 的个人玩家（你的最佳起步）
```

### 安装

```bash
pip install unsloth
# 如需特定 CUDA 版本（如 12.1）
pip install "unsloth[cu121] @ git+https://github.com/unslothai/unsloth.git"
```

### 最小可运行示例

```python
from unsloth import FastLanguageModel
from trl import SFTTrainer
from datasets import load_dataset

# 1. 加载模型（4bit 量化，省显存）
model, tokenizer = FastLanguageModel.from_pretrained(
    model_name="Qwen/Qwen2.5-7B-Instruct",
    max_seq_length=2048,
    load_in_4bit=True,
)

# 2. 注入 LoRA
model = FastLanguageModel.get_peft_model(
    model,
    r=16,
    lora_alpha=16,
    lora_dropout=0,
    target_modules=["q_proj", "k_proj", "v_proj", "o_proj"],
)

# 3. 标准 SFT
dataset = load_dataset("json", data_files="train.jsonl")["train"]
trainer = SFTTrainer(
    model=model,
    tokenizer=tokenizer,
    train_dataset=dataset,
    max_seq_length=2048,
    dataset_text_field="text",
)
trainer.train()

# 4. 保存
model.save_pretrained("qwen_lora_unsloth")
```

## 5. 四者怎么选

| 维度 | LLaMA-Factory | ms-swift | Axolotl | Unsloth |
|---|---|---|---|---|
| 形态 | UI+CLI | CLI | YAML | Python 库 |
| 多模态 | ✅ | ✅✅ 强 | 一般 | 一般 |
| 速度/显存 | 中 | 中 | 中 | 最快最省 |
| 上手 | 最易 | 易 | 中 | 需写点代码 |
| 你用得到 | SFT 首选 | VLM 首选 | 灵活党 | 单卡神器 |

---

## 一句话总结

> 微调框架把"写训练循环"变成"填配置"；你 2300 条数据 SFT 用
> **LLaMA-Factory**（最省事）或 **Unsloth**（单卡最省显存）都能复现，
> 想训 VLM 直接上 **ms-swift**。
