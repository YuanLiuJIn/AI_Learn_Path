# 26 删除有序数组中的重复项

> 标签：数组、双指针、原地修改
> 难度：简单
> 核心考点：有序数组→重复项相邻、快慢指针（与 #27 同源）、边界处理

---

## 1. 题目要点回顾

- 给定**非递减排序**的数组 `nums`，**原地**删除重复元素，使每个元素只出现一次。
- 保持**相对顺序**不变（即保留每个值的「第一次出现」）。
- 返回去重后唯一元素的个数 `k`，`nums` 前 `k` 个为去重结果（`k` 之后无所谓）。
- 提示：`nums` 已排序，这是关键。

---

## 2. 关键思路（先想清楚再写）

> **数组已排序 ⇒ 重复元素一定相邻。**
> 所以只需要判断「当前元素」是否等于「它前一个元素」：不等于 → 是新唯一元素，搬过来；等于 → 是重复，跳过。

这和 #27 的快慢指针一模一样，只是 #27 判断「是否 == val」，这里判断「是否 == 上一个元素」。

---

## 3. 需要补 / 复习的知识点

| 点 | 说明 |
|---|---|
| **有序数组的性质** | 排序后相同值必定连续，去重只需看「和前一个是否相同」即可，无需哈希表 |
| **快慢指针** | fast 遍历，slow 收集「要保留的元素」，和 #27 完全同构 |
| **边界：空 / 单元素** | `nums.size()==0` 直接返回 0；单元素无需处理直接返回 1 |
| **原地写回安全** | `nums[slow] = nums[fast]` 中 `slow <= fast`，不会覆盖未读数据 |
| **与 #27 的联系** | 都是「过滤 + 收集有效元素」；区别在于判断条件 |

---

## 4. 正确解法

### 解法：快慢指针（最优，O(1) 空间）
```cpp
int removeDuplicates(vector<int>& nums) {
    if (nums.empty()) return 0;          // 边界：空数组
    int slow = 1;                         // 第 0 个元素一定保留，slow 从 1 开始
    for (int fast = 1; fast < nums.size(); fast++) {
        if (nums[fast] != nums[fast - 1]) {  // 和「前一个」不同 → 新唯一元素
            nums[slow++] = nums[fast];
        }
        // 相同 → 重复，跳过（fast 继续走，slow 不动）
    }
    return slow;                          // slow 就是唯一元素个数 k
}
```

**推演** `nums=[0,0,1,1,1,2,2,3,3,4]`：
- slow=1；fast 扫到 `1`(idx2) ≠ 前 `0` → `nums[1]=1`,slow=2
- `1`(idx3)==前`1` 跳过；`1`(idx4) 跳过
- `2`(idx5)≠前`1` → `nums[2]=2`,slow=3
- `2`(idx6) 跳过
- `3`(idx7)≠前`2` → `nums[3]=3`,slow=4
- `3`(idx8) 跳过
- `4`(idx9)≠前`3` → `nums[4]=4`,slow=5
- 返回 5，前 5 个为 `[0,1,2,3,4]` ✓

### （拓展）用 `nums[slow-1]` 比较的写法（更通用）
```cpp
int removeDuplicates(vector<int>& nums) {
    if (nums.empty()) return 0;
    int slow = 1;
    for (int fast = 1; fast < nums.size(); fast++) {
        if (nums[fast] != nums[slow - 1]) {  // 和 slow 前一个已去重元素比
            nums[slow++] = nums[fast];
        }
    }
    return slow;
}
```
两种写法都对；`nums[fast] != nums[fast-1]` 利用了「排序后重复相邻」，更直观。

> **为什么 #26 可以用「俩 fast」(`nums[fast-1]`)，但 #80 不能用 `nums[fast-2]`？**
> 关键在**距离**与**原地写覆盖的时机**：
> - #26 比「前一个」（距离 1）。位置 `p` 在 `fast=p+1` 时作为 `nums[fast-1]` 被读，而写头 `slow` 要覆盖位置 `p` 至少得到 `fast=p+1` 当轮判断**之后**（且即便写也是同值），所以这一读永远落在覆盖之前 → 读到原始值，**安全**。
> - #80 比「前两个」（距离 2）。位置 `p` 在 `fast=p+2` 时作为 `nums[fast-2]` 被读；但 `slow` 遇重复「跳过」时会停住，可能早在 `fast=p+1` 就把位置 `p` 覆盖成别的值（见 #80 笔记第 7 节 `[1,1,2,3]` 的错）。读点落在写点之后 → **脏值，不安全**。
> 结论：**距离 1 的「俩 fast」读点恒在写点前，安全；距离 ≥2 时读点可能落在写点后，必须改用 `nums[slow-k]` 读结果区。**

---

## 5. 一句话总结

> 排序数组去重 = 快慢指针 + 「当前 ≠ 前一个」即保留。和 #27 同源，记住**有序 ⇒ 重复相邻**这个性质就能秒。
