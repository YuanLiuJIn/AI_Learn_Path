# 01. Agent 自进化全景：从"静态执行"到"持续成长"

> 目标：理解 Agent 自进化的定义、分类框架和核心价值。

---

## 1. 什么是 Agent 自进化？

```text
普通 Agent：
  能力 = 训练时学到的 + Prompt 写死的
  部署后不再改变
  想提升？→ 人工改 Prompt / 重新训练

自进化 Agent：
  能力 = 初始状态 + 运行时自我提升
  部署后会自己变强
  提升方式：
    从经验中学习（记忆+反思）
    自己生成训练任务（自动课程）
    自己发现可复用技能（技能库）
    自己调整决策策略（RL优化）
```

---

## 2. 自进化的核心闭环（统一框架）

来自 Self-Evolving Agents Survey (2025) 的统一框架：

```text
┌─────────────────────────────────────────────────┐
│                                                  │
│   System Inputs（系统输入）                        │
│     用户指令、环境状态、工具返回                     │
│           ↓                                      │
│   Agent System（Agent 系统）                       │
│     模型推理、工具调用、记忆检索                     │
│           ↓                                      │
│   Environment（环境）                              │
│     执行动作、得到反馈、产生经验                     │
│           ↓                                      │
│   Optimisers（优化器）                             │
│     从经验中学习：更新记忆、提炼技能、优化策略        │
│           ↓                                      │
│   回到 System Inputs（形成闭环）                    │
│                                                  │
└─────────────────────────────────────────────────┘
```

关键点：

```text
"优化器"是自进化的引擎：
  - 把原始经验加工成可复用的知识
  - 把失败案例变成策略改进的信号
  - 把成功模式提炼为技能
```

---

## 3. 自进化的四大维度

### 维度 1：进化什么？（What）

```text
① 进化模型
   用 RL/GRPO 持续微调模型权重
   例：Voyager 用失败反馈改进代码生成能力

② 进化提示词
   从经验中自动优化 System Prompt
   例：任务描述写得更清晰、加入常见错误提示

③ 进化记忆
   从对话中提取知识，更新长期记忆
   例：用户偏好、项目约定、操作经验

④ 进化工具/技能
   自动发现新技能、更新已有技能
   例：Voyager 的代码技能库、SkillRL 的模块化技能
```

### 维度 2：何时进化？（When）

```text
在线进化：边执行边学习
  每完成一个任务 → 立即提炼经验
  优点：实时响应
  缺点：可能影响当前任务性能

离线进化：执行完一批后批量学习
  积累一批经验 → 统一分析 → 更新策略
  优点：不影响当前任务
  缺点：延迟反馈

混合进化：在线记录 + 离线优化
  边执行边记录，空闲时批量优化
```

### 维度 3：如何进化？（How）

```text
RL 驱动：GRPO/PPO 优化决策策略
课程学习：自动生成越来越难的任务
元学习：学会"如何学习"
技能发现：从经验中提取可复用模式
反思归因：分析每一步的成败原因
```

### 维度 4：在哪里进化？（Where）

```text
单 Agent 内：个人成长，越用越懂你
多 Agent 间：团队成长，共享经验和技能
跨环境：在虚拟环境学习，迁移到真实环境
```

---

## 4. 自进化的三个层次

```text
Level 1：记忆驱动自进化
  核心机制：经验存储 + 检索 + 反思
  代表：Generative Agents、MemGPT
  
  例：Agent 记住了"用户偏好 pnpm"
      下次自动使用 pnpm 命令
      但推理策略本身没有变

Level 2：技能驱动自进化
  核心机制：技能自动发现 + 技能库 + 技能组合
  代表：Voyager、SkillRL、SAGE
  
  例：Agent 从多次任务中提炼出"排查日志三步骤"
      下次遇到日志问题时自动调用
      不仅记住了什么，还学会了怎么做

Level 3：元认知自进化
  核心机制：自我评估 + 自动课程 + 策略优化
  代表：AgentEvolver、ADAS
  
  例：Agent 自己发现"我最近在 A 类任务上表现下降"
      自动生成 A 类任务的练习题
      练习后能力恢复
      完全是"知道自己不知道，自己补课"
```

## 5. 为什么 2025-2026 是自进化 Agent 的爆发期？

```text
技术前提同时成熟：

1. LLM 能力够强
   → 能够自己分析经验、反思失败、生成改进方案

2. RL 训练方案成熟（GRPO）
   → 不需要海量数据就可以训练 Agent 决策能力

3. Agent 框架完善
   → Agent Loop、工具调用、记忆系统已经是标配

4. 企业需求爆发
   → Agent 上了生产环境后，发现"不动脑子"会退化
   → 必须让 Agent 在生产中自己持续进化
```

---

## 6. 一句话总结

> Agent 自进化 = 从"执行一次、用完即弃"升级为"持续执行、越用越强"。核心技术是：从经验中提取知识（记忆进化）、发现可复用模式（技能进化）、自动优化决策策略（RL 进化）。最终目标是让 Agent 在生产环境中自己成长，无需人类频繁介入。
