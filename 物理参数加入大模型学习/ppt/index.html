换监督信号
DNN 训练本需海量标注，但科学问题往往没数据；物理定律本身可以在任意时空点提供"免费标签"。

软约束 + 硬约束
软：写进损失，近似满足。硬：写进结构，自动满足。两种强度，同一目标——把物理"注入"网络。

软约束 / SOFT CONSTRAINT · PINN
04 / 12
物理进损失函数

PINN：把物理写进损失

不改变网络结构，把 PDE 残差、边界条件、初值条件作为惩罚项加进损失。约束是"软"的——只是被鼓励满足，不保证精确满足。

不改变结构
仍是标准 MLP，可用现成优化器与框架
三类惩罚项
PDE 残差 / 边界条件 / 初值条件
代价
权重难调、精度上限低，约束无保证
硬约束 / HARD CONSTRAINT · ARCHITECTURE
05 / 12
物理进网络结构

硬约束：让约束恒成立

通过构造网络输出形式，使边界条件、对称性、守恒律在数学上恒成立——严格满足、误差为机器精度，不依赖惩罚项。典型形式：û = u_lift + φ(x)·N_θ(x)

01优先硬约束 / PREFER HARD
能硬则硬
边界条件、对称性、守恒律优先硬约束，把损失简化成纯 PDE 残差。
  • 边界条件 · 对称性 · 守恒律
  • 初值硬约束 · 单调性 / 正性
02退回软约束 / FALL BACK
难硬则软
复杂几何边界、未知本构、含噪数据用软约束；约束一旦非线性或多物理耦合，投影算子难以解析构造。
  • 复杂几何 · 未知本构
  • 含噪数据 · 多物理耦合

07 / 12
六类瓶颈 · 按紧迫度由高到低

物理对了，精度和可信度还没对上

评测
全球统一基准缺失；不同论文各用 PDE 与误差度量；"物理改进"的宣称常无对照实验
精度
收敛精度卡在 1e-3，与经典谱方法 / FEM 差 3–6 个数量级；只报告 L2 而掩盖局部最大误差
导数可靠性
函数值精度 ≠ 导数精度，二阶导数在高曲率 / 边界处失真 → "物理约束"可能是假的
理论 / 优化
泛化、鲁棒性、收敛速率缺严格分析；多目标损失权重无普适解；梯度病态与数值刚性
谱偏置 / 约束权衡
高频、多尺度、强间断解仍难捕捉；软 vs 硬 vs 数据如何最优组合无理论指导
基座 / 落地 / 可解释
预训练覆盖有限、OOD 与 scaling law 存疑；缺轻量化与工程级验证；"可解释"多为事后叙事
主线 A / TRACK A · 评测与失效机制的"打假"
08 / 12
过去一年最值得关注的变化

社区开始怀疑自己的评测协议

A1 · arXiv:2609.13171
导数保真度失效模式
把"导数不准"形式化为独立失效模式；函数值精度与导数精度解耦，二阶导数在高曲率与边界处被放大。
疑点：仅 1D 解析函数，非真实残差训练流程
A2 · arXiv:2609.07437
AD vs 离散化约束
在 Poisson 到高超声速的谱系上做误差分解对比：非线性越强，离散化约束越占优；边界越复杂，GNN 优势越大。
疑点：未给规模与成本，依赖维度未知
A3 · OpenReview
FP64 is All You Need
挑战"失败源于损失病态"的主流理解：真正元凶是 FP32 精度不足，改用双精度可大幅消除所谓"病态"。
含义：复杂加权方案的收益或来自浮点补偿
A4 · arXiv:2608.10047
领域系统综述的冷静结论
覆盖 212 篇 PIML-for-PHM 文献：四类方法一致优于纯数据驱动，但文献极度集中于电池与轴承，缺乏可迁移性。
最尖锐：对泛化/因果/可解释的改善缺证据
A5 · ICML 2026 WS
物理对齐 · Physics Alignment
物理学家监督 AI 写科学软件的两个失败案例：凑合参数 α=0.27 通过全部测试却换参即废；早期选错分支后 33/57 次会话都在错架构里调参。
启示：测试通过 ≠ 物理正确
共同指向
评测协议本身
成了研究对象
当错的是尺子，SOTA 就失去意义。

09 / 12

从"MLP + 调参"到"结构里就带着物理"

B1 · 硬约束架构
HardNet / WHC-PINN
投影层强制输入相关硬约束，并证明硬约束下的万能逼近定理——施加约束不牺牲表达能力。
距离函数法：û = u_lift + φ(x)·N_θ(x)，新进展在复杂三维几何
B2 · Transformer / 注意力
OrthoSolver
"神经正交分解"把求解器内部表示显式正交化，在 PDEBench 七个基准上取得最优。
并行多尺度注意力单卡处理数百万点；PirateNets 成新默认骨干
B3 · KAN 系
KAN-PINN / PIKAN
可学习激活函数放在边上而非节点上，可解释性更强、能导出符号表达式。
疑点：训练成本与稳定性在规模上不如 MLP；含噪真实数据下常导不出公式
B4 · 优化与损失平衡
没有普适的加权
平衡方法的效果还取决于优化器、网络规模与问题刚性——"哪种加权最好"没有普适答案。
量化瓶颈：收敛精度普遍停留在 1e-3 量级
主线 C / TRACK C · 从解方程到 PDE 基座模型
10 / 12
范式级变化
C

从"一个 PDE 训一个网络"转向"大规模预训练 + 少样本微调"。

语料从单一方程扩展到一个 PDE 族集合，模型开始拥有可迁移的"物理底座"。

C1
NESTOR · CVPR 2026 · arXiv:2602.22059
两级嵌套混合专家：图像级 MoE 捕捉全局依赖，词元级 Sub-MoE 捕捉局部依赖，按输入选择性激活；12 个 PDE 数据集大规模预训练后迁移下游。
疑点：路由塌缩与负载均衡风险，显存与训练成本高，OOD 未说明
C2
Flow Marching · arXiv:2509.18611
把神经算子与 flow matching 桥接：联合采样噪声水平与物理时间步，学到统一 velocity field，减少长期漂移并支持不确定性采样。配 P2VAE + FMT，约 250 万条轨迹、12 个 PDE 族。
注意：该文已被 arXiv:2602.11229 大幅扩展并取代；"15×"是相对视频扩散而非确定性算子
C3
组合式与统一算子
CompNO（结构化物理模块组合求解多维流体）、Starter-Iterator NO（arXiv:2606.18305v2，单一架构统一正/反问题）、AOT-POT（自适应算子变换）。
疑点：普遍缺少与经典数值求解器等精度的成本对比；"基座"是否带来 scaling law 收益仍有争议
主线 D / TRACK D · LLM / Agent 与 PIML 融合
11 / 12
与工作区"物理参数加入大模型学习"最贴近的方向

从手写损失，到自然语言自动构建 PINN

D1
arXiv:2602.10576 · 2026-07
PiT-PO
符号回归中 LLM 生成的方程常物理无效。用强化学习把 LLM 从"静态提议器"变成"自适应生成器"：序列层强制层级化物理有效性，token 层做细粒度正则化，物理校验器作为奖励形成闭环。
疑点：依赖可自动化的物理校验器；搜索空间随方程复杂度爆炸
D2
GitHub: poochat/LANG-PINN
Lang-PINN
多智能体框架，从自然语言自动生成 PINN：方程解析、损失构建、网络配置、训练调优四类智能体协同，适配 PINNacle 基准并可端到端运行。
疑点：本质仍是"LLM 写代码"，不是"LLM 内嵌物理"；复杂几何与多物理的成功率未充分报告
D3
与 A5 呼应
物理对齐成为前沿问题
如何让 AI 的优化目标（通过测试）与真正的科学目标（符合物理定律）保持一致。这与 RLHF 的 alignment 是同一逻辑，只是奖励函数变成了物理自洽性。
