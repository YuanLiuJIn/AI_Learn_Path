# Chapter 05：对比与融合——未来方向

## 5.1 三大流派的本质区别

| 维度 | MBRL（Ch02） | EBM / 扩散（Ch03） | JEPA（Ch04） |
|---|---|---|---|
| **预测目标** | 隐状态 $z$ | 能量 / 像素分布 | 抽象表征 |
| **目标函数** | ELBO（重构+KL）+ 奖励 | 去噪 / 对比 / 打分匹配 | 表征 L2 + 防坍塌正则 |
| **归纳偏置** | 世界是可压缩的隐动力学 | 世界是多模态概率分布 | 决策只需语义，不需像素 |
| **采样代价** | 低（一次前向） | 高（几十步去噪） | 最低（一次前向） |
| **可解释性** | 中（可解码） | 高（能看画面） | 低（看不到未来） |
| **最适场景** | 决策 / RL | 仿真 / 生成 | 表征 / 具身 |

**一句话总结三者分工**：

```text
Dreamer ：为决策而"压缩"世界   —— 便宜、可微、适合训练策略
扩散     ：为渲染而"重建"世界   —— 逼真、多模态、适合当模拟器
JEPA     ：为理解而"抽象"世界   —— 省容量、抗噪声、适合具身规划
```

## 5.2 混合架构：三条正在发生的融合

1. **Dreamer + JEPA**：用 JEPA 式表征替换 RSSM 的编解码器，去掉像素重建，只保留隐空间动力学与 KL。动机：省下"画背景"的算力，把容量留给决策。
2. **扩散替代 RSSM 解码器**：RSSM 负责时序与压缩，扩散负责把隐状态解码成清晰观测。兼顾"决策友好"与"生成逼真"。
3. **MuZero 式"不重建"**：只学价值 / 奖励 / 隐状态，连观测都不解码，靠 MCTS 在线规划。与 JEPA 神似，但用规划而非预测承担决策。

共同趋势：**把"预测什么"与"用来干什么"解耦**——不再要求一个模型同时会重建、会决策、会规划。

## 5.3 如何评估世界模型的质量

这是当前最不成熟、也最关键的一环。四个维度：

| 维度 | 问题 | 可能的度量 |
|---|---|---|
| **预测准确度** | 多步 rollout 后还准吗？ | 多步 NLL / 表征误差随 horizon 的曲线 |
| **泛化** | 换环境、换任务还行吗？ | 零样本迁移、分布外场景回报 |
| **组合性** | 会解"没见过的组合"吗？ | 组合式任务（如新物体+新指令） |
| **因果理解** | 分清"我做的"与"世界自己变的"吗？ | 反事实预测、干预实验 |

**核心难点**：像素清晰 ≠ 决策有用。最好用的评估是**下游回报**（模型帮策略提升了多少），但它又依赖具体的 RL 算法，不纯粹。目前没有公认的统一基准，这是开放问题。

## 5.4 开放问题与展望

- **世界模型 = 序列预测？** Genie、Genie 2、Sora 以及"world model as next-token prediction"的思路，把世界建模统一到 Transformer 的序列预测框架下，用海量视频预训练，展示出可控交互环境。这可能是下一步的统一范式。
- **如何避免误差累积？** 短 horizon（Dreamer）、因果扩散（Diffusion Forcing）、表征空间（JEPA）都只是缓解，不是根治。
- **如何落到具身？** V-JEPA 2 展示了"视频预训练 + 少量机器人数据 → 零样本规划"的路径，是当前最有说服力的方向之一。
- **如何评估与对齐？** 当世界模型足够强，它本身就是一个"想象机器"；如何保证它想象得既准又安全，仍是开放的。

## 5.5 全书总结

```text
Ch01  世界模型 = 预测未来的内部模型；三大流派坐标
Ch02  Dreamer ：RSSM + 想象训练，为决策压缩世界（最成熟的落地范式）
Ch03  EBM/扩散：能量与去噪，为渲染重建世界（最逼真、最多模态）
Ch04  JEPA    ：表征空间预测，为理解抽象世界（最省、最抗噪）
Ch05  三者不是替代关系，而是"压缩 / 重建 / 抽象"三种取舍的融合
```
