大家好，我是刘晋元。今天汇报的主题是如何让大模型学会物理，参考主线是 Physics-informed Machine Learning，也就是把物理规律作为机器学习的额外信息。

这不是简单地把一个更大的语言模型放进物理问题，而是回到一个基本问题：当数据不够、噪声很大、几何很复杂时，我们能不能让模型利用方程、边界条件、守恒律和结构先验来减少搜索空间。

今天的汇报会从 PINN 的软约束和硬约束开始，再看过去一年 PIML 的四条主要工作线：评测与失效机制、架构与约束、PDE 基座模型，以及 LLM/Agent 与 PIML 的融合。最后我会把问题收束到 Physics Alignment。

01 · concept

Physics-informed ML：
给学习系统加入物理信息

传统数值方法

有限差分、有限元、谱方法可以精确表达 PDE，但面对噪声数据、复杂网格、高维参数化和隐藏物理反问题时成本上升。

物理信息学习

网络不仅拟合观测数据，还通过 PDE、边界条件、初值条件或守恒律获得额外监督。

∇
核心转变：换监督信号

科学问题往往没有海量标注，但物理定律可以在任意时空点提供“免费标签”。

先定义什么是 PIML。传统数值方法有清晰的数学结构，但它们并不总能适应真实世界的数据条件。真实数据会带噪声，几何会变复杂，参数维度会升高，还可能存在我们并不知道的隐藏物理。

纯数据驱动模型的另一面是，它需要大量高质量标注，而科学计算中这种标注往往昂贵甚至不存在。PIML 的关键思想就是换一个监督信号：不仅使用观测数据，还让物理方程和边界条件参与训练。

所以物理规律在这里可以被看作一种额外的信息来源。它不是简单的先验口号，而是可以在时空配点上计算残差，直接进入优化目标，或者被写入网络结构，让某些约束天然成立。

02 · constraint design

物理注入网络，有两种强度

软约束 · PINN

PDE 残差、边界条件和初值条件进入损失函数，灵活但只是被“鼓励”满足。

L = L_data + λ_f L_PDE + λ_b L_BC + λ_0 L_IC
PINN loss decomposition

硬约束 · 特制架构

构造网络输出形式，使边界条件、对称性或守恒律在数学上恒成立。

û(x) = u_lift(x) + φ(x) Nθ(x)
Physics-informed training loop
RULE OF THUMB能硬则硬：边界、对称、守恒优先硬约束；难硬则软：复杂几何、未知本构和含噪数据使用软约束。

物理注入可以分成软约束和硬约束。PINN 是最典型的软约束，它保留了网络的通用结构，把方程残差和边界残差放进损失函数。优点是灵活，缺点是约束权重、梯度病态和数值精度都会影响结果。

硬约束更强。我们可以通过距离函数、投影层或特定输出结构，让边界条件在数学上自动成立，这样不需要用很大的惩罚项把网络拉回可行域。

但硬约束不是越多越好。复杂几何、多物理耦合和反问题里，解析构造会迅速变难。所以一个实际原则是：能硬则硬，难硬则软。把真正应该严格成立的条件放进结构，把复杂或不确定的部分留给损失和数据。

03 · landscape

过去一年，PIML 的四条主要工作线

A打假与评测：我们是不是一直测错了？fidelity / FP64 / benchmark
B架构与约束：从 MLP 调参到 Transformer、KAN、硬约束architecture
CPDE 基座模型：从一个 PDE 一个网络到预训练 + 微调foundation model
DLLM / Agent：从自然语言自动构建 PINNphysics alignment

范式变化：从“求解一个方程”，走向“学习一类物理问题”。

把近一年的工作放在一张图里，可以看到四条主线。第一条是评测和失效机制，社区开始反思函数值准确是否真的意味着导数准确、物理残差准确。

第二条是架构与约束，研究者不再只是在 MLP 上调损失权重，而是尝试硬约束、Transformer、KAN、域分解等更明确的结构。

第三条是 PDE 基座模型。过去常见的是一个 PDE 训练一个网络，现在开始探索跨 PDE 族预训练，再迁移到新的下游问题。

第四条是 LLM 和 Agent 的进入。自然语言可以描述方程、边界和目标，模型可以自动生成 PINN 或候选方程。这个方向最终会触及一个更大的问题：AI 优化的目标，是否真的和物理目标一致。

04 · line A / evaluation

第一条主线：
重新检查“物理一致性”

导数保真度

函数值拟合得好，不代表自动微分得到的一阶或二阶导数可靠，边界和高曲率处误差可能放大。

arXiv:2609.13171

AD vs 离散化

非线性越强，离散化约束可能用更小的优化误差补偿截断误差；复杂边界下 GNN 可能更有优势。

arXiv:2609.07437

FP64 vs FP32

部分 PINN 失败可能不是损失病态，而是浮点精度不足；双精度会改变我们对优化问题的判断。

precision debate
WARNING测试通过 ≠ 物理正确；函数值正确 ≠ 导数正确。

第一条主线是“打假”，这里的打假不是否定 PIML，而是重新检查我们使用的评测协议。

一个很关键的失效模式是导数保真度。PINN 的物理一致性依赖自动微分，但过去大家经常只看函数值误差。如果曲线看起来很准，二阶导数却在高曲率或边界附近严重失真，那么所谓的物理约束可能只是表面上的。

另一个问题是自动微分和离散化约束的边界。面对强非线性和强间断，离散方法可能更稳定。FP64 的争论也提醒我们，很多复杂的损失加权策略，可能在补偿数值精度不足。

这一页最重要的结论是：测试通过不等于物理正确，函数值正确也不等于导数正确。

05 · line B / architecture

第二条主线：把物理写进结构

01
HardNet / 投影层

在网络内部强制输入相关约束，并研究施加约束后是否仍保留万能逼近能力。

02
Transformer / 注意力

OrthoSolver、Transolver 等尝试建模跨点依赖和多尺度 PDE 表示。

03
KAN 系

把可学习激活放到边上，增强低维问题中的可解释性和符号表达能力。

04
损失平衡

没有普适的最优加权，优化器、网络规模和物理刚性都会改变平衡策略的有效性。

难点仍在：复杂几何、多物理耦合、含噪反问题与公平基准。

第二条主线是架构和约束。HardNet 一类工作试图用投影层在网络内部强制约束，并进一步证明约束不一定会牺牲表达能力。

Transformer 和注意力方法希望处理更大规模的点集和跨区域依赖。它们在二维光滑问题上表现很强，但到了三维、长时间 rollout 和强间断场景，优势还没有完全稳定。

KAN 把可学习函数放到边上，带来更强的符号表达想象空间，但目前通常是在低维、小规模问题上展示优势，面对真实含噪数据时仍需要谨慎。

最后是损失平衡。很多论文都提出过动态权重，但系统分析告诉我们，没有一种策略在所有物理问题上都最好。问题的刚性、网络规模和优化器都会影响结论。

06 · line C / foundation models

第三条主线：从一个 PDE 一个网络，
转向预训练 + 微调

NESTOR

Nested MoE：图像级专家捕捉全局依赖，token 级子专家捕捉局部模式，在多个 PDE 数据集上预训练迁移。

arXiv:2602.22059

Flow Marching

将神经算子与 flow matching 结合，联合建模噪声水平和物理时间步，缓解长期 rollout 漂移。

arXiv:2602.11229

组合式算子

CompNO、Starter-Iterator、AOT-POT 等探索模块化、正问题与反问题统一及大规模预训练。

operator pretraining
OPEN QUESTION预训练分布外的 PDE 泛化，是否真的遵循 scaling law？

第三条主线是 PDE 基座模型。这是一个范式变化：从一个方程训练一个网络，转向在多个 PDE 族上预训练，再对具体任务微调。

NESTOR 用嵌套混合专家处理异构 PDE。它的潜力是让不同专家学习不同的物理模式，但路由塌缩、负载均衡、显存和训练成本都变成新的问题。

Flow Marching 则更偏生成式，把神经算子和 flow matching 结合，希望减少长期 rollout 的 drift，并通过采样表达不确定性。但隐空间压缩可能丢掉高频细节，而且生成式推理本身更贵。

这一方向最需要警惕的是“基座模型”这个名字是否自动带来 scaling law。只有在同等精度、同等成本，并且覆盖分布外 PDE 的对比下，才知道预训练是否真的提供了普适收益。

LLM writes PINN

重要边界

“LLM 写出了代码”不等于“LLM 内嵌了物理”。复杂几何、多物理和真实实验闭环仍缺少鲁棒性证据。

第四条主线和大模型最直接相关：让自然语言成为物理建模接口。PiT-PO 针对符号回归，尝试用强化学习让模型生成方程时遵守量纲和守恒。

Lang-PINN 更像一个多智能体工程系统：一个智能体解析方程，一个构建损失，一个配置网络，还有一个负责调优。这样用户可以用自然语言描述问题，系统自动生成并运行 PINN。

但这里要划清一个边界。LLM 能够写出 PINN 代码，不代表它真正把物理内化了。只要换到复杂几何、多物理耦合或真实实验数据，系统是否还能稳定工作，仍然需要更严格的报告。

因此，大模型进入 PIML 的关键不只是代码生成，而是让模型的优化目标真正对齐科学目标。

08 · paper walkthrough · 2026

把波动物理先验注入扩散模型

Incorporating Wave Physical Priors into Diffusion ModelsSeismic Resolution Enhancement · Surveys in GeophysicsDOI: 10.1007/s10712-026-09965-4

论文要解决什么？

现场地震数据缺少成对的高分辨率标签，同时存在带宽受限、噪声和薄层难分辨问题。目标是直接从现场观测中恢复高分辨率地震剖面。

PHYSICS LOOP高分辨率反射系数 x̂₀卷积波子 w现场观测 xx ≈ x̂₀ * w

三项核心设计

自监督渐进训练 · Robinson 卷积物理约束 · 扩散采样不确定性量化

01
现场数据自监督构对

原始观测 x 经过低通算子得到低分辨率条件 x̃ = FLP(x)；原始 x 作为当前阶段目标，不需要高分辨率标签。

02
前向扩散制造训练输入

对目标加入噪声：xt = √ᾱtx + √(1−ᾱt)ε，形成 (xt, x̃) → x 的训练三元组。

03
U-Net 直接预测干净数据

条件扩散网络接收噪声样本、低分辨率观测和时间步，直接预测 x̂₀ = fθ(xt, x̃, t)。

04
渐进式分阶段细化

当前阶段输出 y(k) 经低通得到新的条件，再作为下一阶段目标；重复 K 个阶段，逐步扩大分辨率差距。

05
训练时加入复合损失

L = λmseLmse + λphyLphy + λ1L1 + λtvLtv：同时约束重建、物理一致性、稀疏反射系数和横向连续性。

06
反向采样中做物理校正

每个去噪步计算卷积物理损失梯度，先更新 x̃t = xt − λ∇xₜLphy，再执行扩散反向更新。

07
输出增强结果与置信度

用不同噪声种子重复采样，平均得到高分辨率结果，样本标准差形成空间不确定性图，标出低置信区域。

输入：现场低分辨率地震数据→PG-SSDM：自监督 + 物理引导扩散→输出：薄层恢复 · 降噪 · 连续性 · 不确定性

Tang et al., 2026 · Open access · Surveys in Geophysics

这一页用一篇具体论文把“物理先验如何进入生成模型”完整拆开。论文针对的是地震分辨率增强，现场数据通常没有成对的高分辨率标签。

第一步，原始现场数据经过低通得到低分辨率条件，原始数据本身充当当前阶段的目标，因此训练是自监督的。第二步，对目标做前向扩散得到带噪样本。第三步，U-Net 不预测噪声，而是直接预测干净的高分辨率数据。

第四步是渐进式训练。一个阶段的增强结果会成为下一阶段的目标，低通版本成为下一阶段条件，从而把一次很难的分辨率跃迁拆成多个小跃迁。

第五步是复合损失：MSE 保证重建，物理损失要求预测结果和低分辨率观测满足 Robinson 卷积模型，L1 鼓励稀疏反射系数，TV 保证横向连续性。

第六步是关键创新：物理约束不仅用于训练，也进入反向采样。每个去噪步先沿物理损失的负梯度修正中间状态，再继续扩散采样。最后通过多次随机采样得到均值结果和标准差不确定性图。

需要强调，这篇论文的物理先验依赖合理的地震子波估计。论文的实验包括 Overthrust、SEAM Arid 和 3D 现场数据，并与 SSI、PISSD 比较。

09 · proposed idea

Transformer + PINN：
让模型从局部拟合走向全局建模

PINN 的瓶颈

MLP 以点为中心独立拟合，难以表达长距离依赖；高频、多尺度和强间断解容易被谱偏置抹平；长时间 rollout 误差累积。

用注意力建立跨配点、跨区域的信息交互，再由 PDE 残差、边界条件和守恒律筛选物理可行解。

物理校验

启发：Transolver / Physics-Attention、OrthoSolver、Fourier Neural Operator；PINN 约束形式沿用 Raissi et al.

这一页提出我们的可尝试方向：不是用 Transformer 简单替换 MLP，而是让 Transformer 负责全局依赖建模，让 PINN 负责物理校验。

PINN 的一个核心问题是 MLP 通常对每个时空点进行局部映射，点与点之间的关系只能通过损失函数间接传递。这会导致高频、多尺度和长时间问题比较难学。

Transformer 的注意力机制可以直接让不同位置、不同时间步和不同物理变量之间交换信息。我们可以把时空采样点编码成 token，再把 PDE、边界和初值条件作为条件 token 或 attention bias 注入。

但 Transformer 本身不保证物理正确，因此最后仍然需要 PDE residual、边界条件和守恒律进行约束。这不是替代 PINN，而是用 Transformer 补齐 PINN 的全局建模能力。

10 · experiment design

把“补齐缺点”变成可验证的实验假设

RESEARCH QUESTIONTransformer 的全局表示，能否在相同物理约束和计算预算下，稳定改善 PINN 的局部误差、导数误差与长时间预测？

这一页把想法变成可验证的实验假设。第一，Transformer 是否能改善 PINN 的高频和多尺度问题；第二，注意力带来的跨区域交互是否能改善复杂边界和长程依赖；第三，时间 token 和物理时间步是否能缓解长期 rollout 漂移。

实验不能只看平均 L2。还应该看局部最大误差、导数误差、守恒误差、长期 rollout 和计算成本。

基线至少包括 MLP-PINN、纯 Transformer 神经算子，以及加入 Physics-Attention 和 PINN loss 的模型。这样才能区分收益到底来自更强网络，还是来自物理约束和结构设计。

这页最后留下一个明确问题：在相同物理约束和相近计算预算下，Transformer 是否真的能补齐 PINN 的短板。

takeaways · Q&A

让模型不仅会拟合，
还要尊重物理

PIML 的下一阶段，不是简单扩大网络，而是建立可信评测、结构化约束、跨 PDE 预训练与 Physics Alignment 的统一闭环。

evaluate honestlyconstrain wiselyalign with physics

最后总结三句话。第一，评测要诚实：函数值、导数、局部误差、长期 rollout 和计算成本都要报告，不能只挑一个漂亮数字。

第二，约束要有层次：能硬则硬，难硬则软，同时要知道数据、软约束和硬约束之间的代价与边界。

第三，目标要对齐：让模型通过测试只是最低要求，让它真正符合物理规律、能够解释失败、能够在分布外任务上保持可靠，才是 PIML 和大模型结合的长期目标。
