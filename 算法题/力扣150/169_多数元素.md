# 169. 多数元素（Majority Element）

## 题目概述
给一个长度为 n 的数组，返回**多数元素**——即出现次数 **严格大于 ⌊n/2⌋** 的元素。
题目保证多数元素一定存在。

示例：
- `nums = [3,2,3]` → 返回 `3`
- `nums = [2,2,1,1,1,2,2]` → 返回 `2`

---

## 你的代码与错误

```cpp
class Solution {
public:
    int majorityElement(vector<int>& nums) {
        nums.sort();                          // ① 编译错误
        int count =0;int slow =0;             // ② slow 声明，但下面用了 low
        int kill=nums.size()/2;
        for(int fast=0;fast<nums.size();fast++)
        {
            if(nums[low]!=nums[fast])         // ③ low 未声明 → 编译错误
            {
                if(fast-low>kill)             // ③ 同上
                {
                    count++;
                }
                low = fast;                    // ③ 同上
            }
        }
        return count;                          // ④ 返回值类型错：应返回元素值，不是个数
    }
};
```

### ① `nums.sort()` 不是 vector 的成员
- `std::vector<int>` **没有** `.sort()` 成员函数。
- 排序要用算法库的自由函数：`sort(nums.begin(), nums.end());`（需 `#include <algorithm>`）。
- 只有少数容器自带成员 `sort()`（如 `std::list`、`std::forward_list`）；`vector` 是随机访问容器，统一用 `std::sort`。

### ②+③ `low` 未声明（拼写不一致）
- 声明的是 `int slow = 0;`，但第 9/11/15 行用的是 `low` —— 未定义标识符，编译报错。统一改成 `slow`。

### ④ 返回值语义错
- `majorityElement` 要求返回**多数元素的值**，而 `return count;` 返回的是个数。即使编译通过答案也错。

---

## 正确解法

### 解法一：排序取中间（最简洁，利用本题性质）
排序后多数元素一定落在下标 `n/2`（它出现超过一半，必然盖住正中间）：
```cpp
int majorityElement(vector<int>& nums) {
    sort(nums.begin(), nums.end());
    return nums[nums.size() / 2];
}
```
时间 O(n log n)，空间 O(1)（原地排序）。

### 解法二：排序 + 统计连续段（贴近你的思路）
```cpp
int majorityElement(vector<int>& nums) {
    sort(nums.begin(), nums.end());
    int slow = 0;
    int half = nums.size() / 2;
    for (int fast = 1; fast < nums.size(); fast++) {
        if (nums[fast] != nums[slow]) {
            if (fast - slow > half) return nums[slow];  // 该段超一半即多数元素
            slow = fast;
        }
    }
    return nums[slow];   // 最后一段必是多数元素
}
```

### 解法三：Boyer-Moore 投票法（最优，面试加分）
O(n) 时间、O(1) 空间，无需排序：
```cpp
int majorityElement(vector<int>& nums) {
    int candidate = nums[0], votes = 0;
    for (int x : nums) {
        if (votes == 0) candidate = x;
        votes += (x == candidate) ? 1 : -1;
    }
    return candidate;   // 题目保证多数元素一定存在
}
```
原理：把不同元素两两抵消，最后剩下的必是出现超过半数的那个。

编译错误已修好（`sort` 用法对、`slow` 拼写统一），但**返回值语义仍错**：
```cpp

    int kill=nums.size()/2;
    for(int fast=0;fast<nums.size();fast++)

```
### ① `count++` 思路偏
本题多数元素最多 1 个，「统计超半的段有几段」没意义。应在「发现某段超半」时直接 `return nums[slow]`（那段的元素值），而非 `count++`。

### ② 漏掉最后一段 + 返回类型错
- 循环只在「遇到新段开头」时检查，会漏掉**最后一段**（循环结束没有下一个不同值触发检查）。而最后一段可能正是多数元素，必须循环后再查一次。
- `return count` 返回个数（示例 1/2 都算得 `count=0`，返回 0），期望是元素 `3`/`2`。

### 修正（保留连续段思路）
```cpp
int majorityElement(vector<int>& nums) {
    sort(nums.begin(), nums.end());
    int slow = 0;
    int half = nums.size() / 2;
    for (int fast = 1; fast < nums.size(); fast++) {
        if (nums[fast] != nums[slow]) {
            if (fast - slow > half) return nums[slow];  // 返回元素值
            slow = fast;
        }
    }
    return nums[slow];   // 补上最后一段（题目保证多数元素必存在）
}
```
### 最简正确写法
```cpp
int majorityElement(vector<int>& nums) {
    sort(nums.begin(), nums.end());
    return nums[nums.size() / 2];   // 排序后多数元素必在中间下标
}
```
