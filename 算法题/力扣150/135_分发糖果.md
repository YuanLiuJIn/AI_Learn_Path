# 135. 分发糖果（Candy）

## 题目
- n 个孩子站一排，`ratings[i]` 是评分。
- 每个孩子至少 1 个糖果；相邻孩子中**评分更高的**获得更多糖果。
- 返回需要的最少糖果总数。
- 提示：`1 <= n <= 5*10^4`。

## 核心思路：两趟扫描
单趟同时比左右不行——糖果数是「连续段长度」决定的。两趟分工：
1. **左→右**：处理「右比左高」的上升段 → `candy[i] = candy[i-1] + 1`。
2. **右→左**：处理「左比右高」的下降段 → `candy[i] = max(candy[i], candy[i+1] + 1)`。
取 max 保证山谷两侧约束同时满足且不浪费。

## 解法（O(n) 时间 O(n) 空间）
```cpp
int candy(vector<int>& ratings) {
    int n = ratings.size();
    vector<int> candy(n, 1);              // 每个孩子至少 1 个
    for (int i = 1; i < n; i++)           // 左→右：上升段
        if (ratings[i] > ratings[i - 1])
            candy[i] = candy[i - 1] + 1;
    for (int i = n - 2; i >= 0; i--)      // 右→左：下降段
        if (ratings[i] > ratings[i + 1])
            candy[i] = max(candy[i], candy[i + 1] + 1);
    int sum = 0;
    for (int c : candy) sum += c;
    return sum;
}
```

## 推演
**`[1,0,2]`** → 初始 [1,1,1]
- 左→右：i=2: 2>0 → [1,1,2]
- 右→左：i=0: 1>0 → max(1,2)=2 → **[2,1,2]**，和 5 ✓

**`[1,2,3]`**（连续上升，靠左→右）
- 左→右：[1,2,3]；右→左：不变 → 和 6 ✓

**`[3,2,1]`**（连续下降，靠右→左）
- 左→右：[1,1,1]；右→左：[3,2,1] → 和 6 ✓

**`[1,2,2]`**（相邻相等不加糖）
- 左→右：i=1: 2>1 → [1,2,1]；i=2: 2>2?否
- 右→左：2>2?否、1>2?否 → [1,2,1]，和 4 ✓

## 易错点（写代码时注意）
1. **`vector<int> candy(n, 1)`**：第二参数把全部初始化为 1（只写 n 默认是 0）。
2. **比较用 `>` 不带等号**：相邻评分相等不要求更多糖果。
3. **两趟都要跑**：只跑一趟会漏上升或下降段（[1,2,3] 只右→左就全 1；[3,2,1] 只左→右也全 1）。
4. **第二趟取 max**：不是赋值覆盖，否则山谷左侧的上升约束会被破坏。
5. **边界**：n=1 时两趟循环都不进，sum=1，天然正确（不要访问 ratings[1]）。

## 你的提交分析（2026-08-20）
```cpp
int candy(vector<int>& ratings) {
    vector<int>fin(ratings.size(),1);
    int i=0,left=0,right=1;
    int num=0;
    if(ratings[i]>ratings[right]){fin[i]++;}   // ③ n=1 时 ratings[1] 越界
    i++;
    for(i=1;i<ratings.size()-1;i++) {
        if(ratings[i]>ratings[left]){fin[i]++;}  // ② 只 +1，处理不了连续上升/下降
        if(ratings[i]>ratings[right]){fin[i]++;}
        num=num+fin[i];                          // ① num 漏加 fin[0] 和 fin[n-1]
        left++; right++;
    }
    if(ratings[i]>ratings[left]){fin[i]++;}
    return num;
}
```
### ① num 漏加首尾
`num` 只在中间循环累加，`fin[0]`/`fin[n-1]` 从未加入。示例 1 `[1,0,2]` 返回 1（正确 5）。
### ② `fin[i]++` 只加一次（核心）
`[1,2,3]` 正确需 `[1,2,3]`（和 6），`++` 至多到 2。糖果数 = 连续段长度，须两趟扫描累加。
### ③ n=1 越界
`ratings[0]>ratings[1]` 当 n=1 越界。n>=2 时开头比较也多余，两趟扫描天然覆盖。
### 正确做法
见上「解法」：左→右累加上升段 + 右→左取 max 补下降段。

### 结论
