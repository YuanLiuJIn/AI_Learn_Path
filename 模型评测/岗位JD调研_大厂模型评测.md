## 一、真实 JD 汇总

### 1. 字节跳动 — 大模型自动化评测专家（大模型数据服务中心，上海）

**岗位职责**
1. 负责大模型自动化评测体系的建设与迭代，涵盖评测流程设计、指标体系制定、工具与平台开发，确保评测结果科学、稳定、可复用；
2. 基于 Agent 与 Workflow 等先进技术，搭建自动化评测 Pipeline，支持文本、多模态及 AI 应用的效果评估；
3. 深入研究新型大模型评测方法与技术，制定科学合理的评测策略，推动评测体系的智能化与标准化，为模型优化提供有价值的反馈；
4. 与研发团队紧密协作，将自动化评测体系嵌入模型训练与产品研发流程，形成评测与优化的闭环支持。

**任职要求**
1. 本科及以上学历，计算机科学、人工智能、计算语言学等相关专业优先；
2. 掌握 Python 等编程语言，具备 PE（Prompt Engineering）撰写调优、Agent/Workflow 搭建实践经验优先；
3. 具备 1 年以上大模型评测或相关经验，熟悉常见评测指标和方法，了解自动化评测工具或平台的开发与应用；
4. 对大模型评测与优化充满热情，关注前沿研究动态，具备快速学习与持续探索能力；
5. 思路清晰、逻辑性强，具备跨团队协作与沟通能力。

> 字节相关岗位族还包括：多模态大模型数据评测专家、AI 大模型数据评测专家（剪映方向）、大模型自动化评测实习生、测试开发（大模型评测方向）等。

## 三、对应到学习计划的核心主题

结合上述 JD，学习计划应覆盖（与 `Model_Evaluation/` 目录可对照）：

1. **评测方法论**：客观评测 vs 主观评测、指标设计（准确率/胜率/Elo/校准）、能力维度拆解 → `01_evaluation_overview.md`
2. **主流 Benchmark**：MMLU/C-Eval/GPQA/HumanEval/SWE-bench/BFCL/长文本/多模态榜单，及其局限（污染、饱和）→ `02_benchmark_landscape.md`、`03_contamination_and_reliability.md`
3. **LLM-as-a-Judge**：判分 Prompt 设计、偏差（位置/长度偏好）、与人工一致性 → `04_llm_as_judge.md`
4. **评测框架实战**：OpenCompass、lm-evaluation-harness、EvalScope 等，跑通端到端评测 → `05_evaluation_frameworks.md`
5. **Agent/多轮评测**：任务完成率、工具调用准确率、轨迹评估 → `06_agent_evaluation.md`
6. **评测数据集建设**：数据设计、标注规范、合成数据管线（腾讯/阿里 JD 重点）
7. **自动化评测平台工程**：用 Python 搭建评测 Pipeline，嵌入训练闭环（字节 JD 重点）
8. **项目产出**：从 0 到 1 做一个垂直领域 Benchmark + 自动化评测工具，作为求职作品（多个 JD 的"优先项"）
