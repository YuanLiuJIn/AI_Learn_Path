# PaperSpine 本地快速开始

PaperSpine 只有一个 `paper-spine` Skill。把论文需求和允许使用的材料交给宿主 Agent；Agent 负责实际研究、写作、制图与审阅。Web 保存配置、选择和反馈，展示进度、预览与下载。启动网页本身不会生成论文。

## 已安装 Skill 的用户

在原宿主对话中说明写作目标、已有材料和是否需要新增研究，并要求使用 paper-spine。已有任务提供其网址或编号，继续原任务。Agent 读取安装后的 Skill，启动或复用公共 Web，用你指定的浏览器打开返回网址；正常使用不要求安装旧 MCP 插件、重新登录宿主或填写开发路径。

宿主创建或恢复任务并读取已授权材料。Web 打开该任务后，你完成当前步骤的配置与选择；无需在网页另建任务或重复登记相同材料。

## 从解压包启动

本包内置运行环境适用于 Windows x64。保留原 ZIP，解压到稳定的程序目录，在解压目录打开 PowerShell：

```powershell
.\runtime_vendor\windows-py312\python.exe -B .\standalone\paper-spine\scripts\paperspine5_web.py launch --no-open
```

用选择的浏览器打开返回网址。首次使用空的默认本地配置，后续自动复用；任务和成果保存在程序目录之外。已有配置可以显式选择：

```powershell
.\runtime_vendor\windows-py312\python.exe -B .\standalone\paper-spine\scripts\paperspine5_web.py launch --profile-root "<已有配置目录>" --remember --no-open
```

`--remember` 记住该本地目录，后续宿主工具读取相同数据。已有任务查不到时先核对配置，不新建另一任务或复制数据库。旧开发服务的路径绑定由集成者一次完成，见 Skill 中的 public workflow。

## 完成一篇论文

1. **配置。** 选择写作场景、语言、交付格式及是否新增研究。只使用材料时，Agent 使用已有内容和结果，作必要提取与核对，不擅自新增分析或检索。
2. **研究与动机。** Agent 按保存的设置实际工作，提供有依据的动机或贡献候选。你选择后，Agent 读取保存的选项与意见继续。已有代选授权按范围沿用，未知作者事实不能代填。
3. **稿件与图件。** 图件目录中的当前图、参考图和候选自动出现。比较实际图像后选择保留、修改或采用候选；也可在原宿主对话提出具体修改。
4. **审阅。** 独立审阅者检查当前稿件、引用、图表及真实 PDF/DOCX 显示；宿主修复问题并重新检查受影响部分。页面状态不是质量证明。
5. **下载。** 点击实际成果的下载链接，确认文件保存到电脑。论文包包含请求的正文格式、图件及可编辑源；完整本地工作包还包括所需分析和说明。私有原始材料不默认放入分享包。
6. **返修。** 在网页保存意见或上传 .md/.txt 意见文件，或在原宿主对话提出要求。Agent 读取同一任务的意见，保留旧版本，修订受影响内容并交付新版本。

当前步骤可操作，历史步骤只读回看。点击历史步骤不会推进科研。Agent 活跃时等待保存结果并继续；宿主被中断后，回原对话恢复相同任务。网页不会启动另一位科研 Agent。

## 给宿主的实际入口

从安装的 Skill 目录运行：

```text
python scripts/paperspine5_web.py launch --no-open
python scripts/paperspine5_web.py host tools
python scripts/paperspine5_web.py host snapshot --task-id "<原任务编号>"
```

宿主按 tools 返回的真实参数调用公共工具。没有预配置 MCP 连接时，CLI 使用包内公共 MCP 通道。产物直接写入公开任务返回的 workspace_root 下 paper/，再发布实际文件，无需移到外部目录重新授权。更多接口细节见 [API 参考](API_REFERENCE.md)。

## 故障与恢复

- 连接中断：运行同一启动命令并读取 status，保留相同配置与任务。若另一版本仍在运行，先确认并停止其准确进程，再切换，不能并行启动两份数据服务。
- 提交响应丢失：读取页面与任务最新状态，原样重试同一次请求。超时不代表没有执行，不把不同选项混进旧请求。
- 等待输入超时：选择仍未完成，宿主继续等待或响应新消息，不能编造选项。
- 文件、渲染或工具失败：修复实际问题，重做受影响部分，复用有效成果。下载失败只重试已有文件。
- 未确认的患者单位、终点、作者、伦理等事实：记录限制并补充可信来源；不编造相关结论，也不停止安全的本地改进。

## 隐私与完成边界

原始材料在本地按授权读取。检索公开论文、核对公开引用和读取公开参考图是 Skill 的常规能力，无须另开联网选项或重复授权；具体工作仍遵循本次研究范围和用户明确的离线要求。公开检索不授权发送私有材料：未经授权不上传私有临床数据，不默认分享原始材料，不自动投稿、发布或发送消息。

可下载文件、科学质量与投稿条件分别判断。示例数据只证明操作能力；测试通过、文件存在或阶段完成不能证明完整论文已经合格。
