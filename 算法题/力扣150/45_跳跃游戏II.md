# 45. 跳跃游戏 II（Jump Game II）

## 题目
- 0 索引数组 `nums`，初始在下标 0。
- `nums[i]` 表示从 `i` 可向后跳的最大长度（可跳到 `i+j`，`0<=j<=nums[i]` 且 `i+j<n`）。
- 返回到达 `n-1` 的**最小跳跃次数**。
- **保证能到达 `n-1`**。
- 提示：`1 <= n <= 10^4`，`0 <= nums[i] <= 1000`。

## 与 #55 的区别
| 题 | 问什么 | 前提 |
|---|---|---|
| 55 | 能否到达末尾（bool） | 不一定能到 |
| 45 | 最小跳跃次数（int） | 保证能到 |

## 思路速记
最小步数 = **按层（BFS）贪心**：把每次跳跃能覆盖的区间当一层。在「当前层」范围内，先算出所有位置「再跳一步」能到的最远位置 `farthest`；一旦遍历到当前层边界 `curEnd`，说明必须再跳一步，步数 +1，并把下一层边界更新为 `farthest`。

- `curEnd`：当前这一跳能到达的区间右边界。
- `farthest`：在当前层里任意位置起跳，下一跳能到达的最远位置。

## 解法一：贪心层序（★推荐，O(n) 时间 O(1) 空间）
```cpp
int jump(vector<int>& nums) {
    int n = nums.size();
    int jumps = 0;
    int curEnd = 0;        // 当前层能覆盖到的右边界
    int farthest = 0;      // 下一步能到达的最远位置
    // 只遍历到 n-2：到达 n-1 即成功，不需要为它再起跳计数
    for (int i = 0; i < n - 1; i++) {
        farthest = max(farthest, i + nums[i]);  // 本层内刷新最远
        if (i == curEnd) {                       // 走到当前层边界，必须再跳一步
            jumps++;
            curEnd = farthest;                    // 进入下一层
        }
    }
    return jumps;
}
```

## 解法二：BFS（队列，O(n) 但空间 O(n)）
按层扩展，每层一次跳跃，第一次触及 `n-1` 的层数即答案：
```cpp
int jump(vector<int>& nums) {
    int n = nums.size();
    if (n == 1) return 0;
    queue<int> q; q.push(0);
    int steps = 0;
    while (!q.empty()) {
        int size = q.size();
        steps++;
        for (int k = 0; k < size; k++) {
            int i = q.front(); q.pop();
            for (int j = 1; j <= nums[i]; j++) {
                int nxt = i + j;
                if (nxt >= n - 1) return steps;
                q.push(nxt);
            }
        }
    }
    return steps;
}
```
> 面试首选解法一（省空间）；解法二好理解但重复访问多、空间大。

## 推演：`nums = [2,3,1,1,4]`，n=5
| i | farthest=max(farthest,i+nums[i]) | i==curEnd? | 动作 |
|---|---|---|---|
| 0 | max(0,0+2)=2 | 是(0==0) | jumps=1, curEnd=2 |
| 1 | max(2,1+3)=4 | 否 | — |
| 2 | max(4,2+1)=4 | 是(2==2) | jumps=2, curEnd=4 |
| 3 | max(4,3+1)=4 | 否(3!=4) | — |
| (i 到 n-2=3 结束) | | | 返回 jumps=2 ✓ |

结果 `2`：下标 0→1（跳1步），下标 1→4（跳3步）。

## 推演：`nums = [2,3,0,1,4]`
- i=0: farthest=2, i==curEnd(0)→jumps=1, curEnd=2
- i=1: farthest=max(2,4)=4
- i=2: farthest=max(4,2+0)=4, i==curEnd(2)→jumps=2, curEnd=4
- i=3: farthest=max(4,4)=4, i!=4
- 返回 2 ✓

## 易错点（写代码时注意）
1. **循环条件写 `i < n-1` 不是 `i < n`**：到达 `n-1` 即成功，不必再为最后位置计数，否则会多算一步。
   - 原因：`jumps++` 在 `i == curEnd` 触发，记的是「跳出当前层」那一跳。当 `curEnd` 已覆盖 `n-1`，「到达末尾的那一跳」已计入 `jumps`；若还遍历到 `i=n-1`，会在此终点上再 `jumps++` 一次（多算 1 步）。
   - 推演 `nums=[2,3,1,1,4], n=5`：i=0→jumps=1,curEnd=2；i=2→jumps=2,curEnd=4；若 `i<n` 继续到 i=4，因 `4==curEnd(4)` 再 jumps++→3 ❌；写 `i<n-1` 在 i=3 结束 → 返回 2 ✓。
   - 等价写法：`i < n` 但加 `if (curEnd >= n-1) break;`。
2. **`curEnd` 与 `farthest` 别混**：`curEnd` 是「本层边界」，只在该跳时更新；`farthest` 每步刷新。
3. **`n==1` 直接返回 0**：解法一的 `i<n-1` 循环不进，返回 0，天然正确；解法二需特判。
4. **别套 #55 的「能否到达」逻辑**：本题保证能到，求的是步数，不是可达性。

## 你的提交分析（2026-08-10）
```cpp
int jump(vector<int>& nums) {
    int curr=0;int maxsize=0;
    int jps=0;
    for(int i=0;i<nums.size()-2;i++) {            // ① 循环到 n-2 而非 n-1
        maxsize=max(maxsize,i+nums[i]);
        if(i==maxsize) { jps++; curr=maxsize; }   // ② 触发条件用反变量
    }
    return jps;
}
```
### Bug 1（致命）：触发条件用反变量
`if(i==maxsize)` 应改成 `if(i==curr)`。`maxsize`(farthest) 是最远可达、`curr`(curEnd) 是当前层边界。正确是「`i` 走到当前层边界 `curr` 再跳一步」；写成 `i==maxsize` 因 `maxsize>=i` 几乎永不触发 → `jps` 基本为 0。
- 推演 `nums=[2,3,1,1,4]`,n=5，循环 i<3：i=0→maxsize=2(0==2否)；i=1→maxsize=4(1==4否)；i=2→maxsize=4(2==4否) → 返回 **0** ❌（正确 2）。

### Bug 2：循环 `i<n-2` 应 `i<n-1`
砍掉下标 n-2，漏算一次跳跃。例 `nums=[1,1,1,1]`（需 3 跳）：修好 Bug1 后循环 i<2 → jps 只到 2 ❌（正确 3）。

### Bug 3（隐患）：`nums.size()-2` 无符号下溢
`nums.size()` 是 `size_t`；`n<=2` 时 `n-2` 下溢成巨大正数，循环恒真、`i` 越界访问 `nums[i]`。应先 `int n=nums.size();`。

### 修正
```cpp
int jump(vector<int>& nums) {
    int n = nums.size();
    int curEnd = 0, farthest = 0, jps = 0;
    for (int i = 0; i < n - 1; i++) {        // ✅ n-1
        farthest = max(farthest, i + nums[i]);
        if (i == curEnd) {                   // ✅ 比较层边界
            jps++;
            curEnd = farthest;
        }
    }
    return jps;
}
```
