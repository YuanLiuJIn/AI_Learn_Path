# 方向一：大模型基础入门

> 面向零基础/转行人群，讲清楚"大模型到底是怎么工作的"。

## 节目形式

```text
PPT + 动画示意图 + 少量公式（配"人话翻译"）
每期 10-20 分钟
```

## 风格要求

```text
不是念 PPT，而是"探案式"叙事
先讲"为什么需要这个东西"，再讲"这个东西怎么工作"
每个概念都先给直觉，再给公式
公式不是用来背的，是用来理解"为什么这个设计有效"
每期结尾给一个"记住这张图"的总结卡片
```

## 内容大纲

### 第 1 期：大模型是什么？—— 从 ChatGPT 说起

```text
核心问题：ChatGPT 到底是魔法还是数学？

内容：
  1. 大模型 = 一个"预测下一个词"的函数
  2. 直觉类比：读完整个图书馆的人，问他下一句该说什么
  3. 不是搜索，不是复制，是"续写"
  4. 为什么续写能变聪明？—— "涌现"

Hook：
  "你有没有想过，ChatGPT 回答你的时候，
   它其实不是在'回答'，而是在'续写'？"

视觉素材：
  打字机效果展示"预测下一个词"
  图书馆 → 大脑 → 输出的动画
```

### 第 2 期：Tokenization —— 模型怎么"读"文字

```text
核心问题：模型只认识数字，文字怎么变成数字？

内容：
  1. 为什么不能直接喂文字
  2. 按"词"切 vs 按"字符"切 vs 按"子词"切
  3. BPE 原理：谁总是一起出现，就把谁合并
  4. 中文为什么比英文"费 token"
  5. token = 钱（API 计费） + 上下文窗口的单位

Hook：
  "你问 ChatGPT 一个问题，它先做的事情不是思考，
   而是把你的话切成一小块一小块的'积木'。"

视觉素材：
  文字 → token 的动画分解
  BPE 合并过程动画
  中文 vs 英文 token 数对比图
```

### 第 3 期：Embedding —— 文字怎么变成向量

```text
核心问题：向量是什么？为什么语义相近的词向量也相近？

内容：
  1. 向量 = 一串数字（高维空间中的一个点）
  2. "国王 - 男人 + 女人 ≈ 王后" 是什么意思
  3. 不是巧合，是训练出来的
  4. Embedding 就是"给每个词在高维空间里找一个位置"

Hook：
  "如果我说'猫'和'狗'的距离比'猫'和'汽车'的距离更近，
   你觉得合理吗？那如果我说这是数学算出来的呢？"

视觉素材：
  3D 空间中词向量的分布图
  "国王-男人+女人=王后" 的向量运算动画
```

### 第 4 期：Attention —— 模型怎么"理解上下文"

```text
核心问题：模型怎么知道"它"指的是书还是桌子？

内容：
  1. 注意力 = 处理每个词时，动态决定"该看哪些其他词"
  2. 查字典类比：Query / Key / Value
  3. 公式直觉：QK^T 算相似度 → softmax 变权重 → 加权求和
  4. 多头注意力：8 个人同时从不同角度读同一句话

Hook：
  "'小明把书放在桌子上，因为它太重了。'
  你瞬间知道'它'指的是书。
  模型怎么做到的？"

视觉素材：
  QK^T 矩阵热力图动画
  softmax 把相似度变成权重的过程
  多头注意力的并行示意图
```

### 第 5 期：Transformer —— 大模型的骨架

```text
核心问题：为什么所有大模型都用 Transformer？

内容：
  1. Transformer = Attention + FFN + 残差 + LayerNorm 堆叠
  2. 为什么能替代 RNN：可并行、长距离依赖一步到位
  3. 残差连接：让 100 层的网络也能训练
  4. 三种变体：Encoder-only / Decoder-only / Encoder-Decoder

Hook：
  "2017 年之前，做翻译的主流是 RNN，像接力赛一棒一棒传。
   2017 年一篇论文说：不用接力了，大家直接面对面开会。"

视觉素材：
  RNN 串行 vs Transformer 并行的对比动画
  Transformer Block 结构图
  残差连接"高速公路"示意图
```

### 第 6 期：预训练 —— 模型怎么"学知识"

```text
核心问题：模型是怎么从海量文本里学到知识的？

内容：
  1. "预测下一个词"怎么逼出智能
  2. 预训练需要什么：海量文本 + 几千张 GPU + 几百万美元
  3. 基座模型的状态：博学但不会聊天
  4. 为什么大多数人"不做预训练，只做微调"

Hook：
  "如果让你猜'中国的首都是___'，你填'北京'。
   如果让你猜'1+1=___'，你填'2'。
   大模型也是这么学的——只不过它猜了几万亿次。"

视觉素材：
  预训练数据规模的可视化（几 TB 文本）
  下一词预测的训练过程动画
  "博学但不会聊天"的对比示例
```

### 第 7 期：微调 —— 让模型"会聊天"

```text
核心问题：基座模型只会续写，怎么让它变成会回答的助手？

内容：
  1. SFT：用"问-答"对教模型"怎么回答问题"
  2. RLHF：人类打分训练 Reward Model，再用 RL 优化
  3. DPO：跳过 Reward Model，直接用偏好数据优化
  4. 三段式养成：预训练 → SFT → 对齐

Hook：
  "一个读完整个图书馆的人，你问他'法国的首都是哪里'，
   他可能说'这个问题很多人都会问。此外，德国的首都是...'
   他是在续写，不是在回答。怎么教他'回答'？"

视觉素材：
  基座模型 vs SFT 后 vs 对齐后的回答对比
  RLHF 流程图
  DPO 的简洁性示意图
```

### 第 8 期：LoRA —— 怎么在消费级显卡上微调大模型

```text
核心问题：全量微调要几百 G 显存，普通人怎么微调大模型？

内容：
  1. 核心 trick：不动原始权重，只训练两个小矩阵
  2. W' = W + B × A（原始大矩阵 + 两个小矩阵的乘积）
  3. 参数量对比：全量微调 vs LoRA（通常 < 1%）
  4. 为什么 LoRA 让"个人微调大模型"成为可能

Hook：
  "微调一个 70 亿参数的模型，全量微调要 100G+ 显存。
   但用 LoRA，一张 RTX 3090 就够了。
   不是魔法，是数学。"

视觉素材：
  全量微调 vs LoRA 的参数量对比图
  LoRA 矩阵分解示意图
  显存占用对比图
```

### 第 9 期：RAG —— 让模型"先查资料再回答"

```text
核心问题：模型的知识截止到训练日期，怎么让它回答"新问题"？

内容：
  1. 闭卷考试 vs 开卷考试
  2. 离线：文档切块 → 向量化 → 存入向量库
  3. 在线：问题向量化 → 检索 → 拼接上下文 → 生成答案
  4. 为什么 RAG 能减少幻觉
  5. RAG 的局限：搜一次拿什么用什么

Hook：
  "你问模型'我们公司上周发布的新政策是什么'，
   它说'抱歉，我的知识截止到某个日期'。
   但如果给它接上一个'可以随时查阅的资料库'呢？"

视觉素材：
  闭卷 vs 开卷考试的对比图
  向量检索流程图
  RAG 全链路动画
```

### 第 10 期：Agent —— 让模型从"会聊天"到"会干活"

```text
核心问题：模型只会输出文字，怎么让它真正"做事"？

内容：
  1. Agent = 大模型（大脑）+ 工具（手脚）+ 循环 + 记忆
  2. ReAct：思考 → 行动 → 观察 → 再思考
  3. 工具调用：模型输出"我要调用天气 API"，程序执行后把结果喂回去
  4. ChatBot vs Agent 的本质区别

Hook：
  "你问 ChatGPT'帮我查下北京天气'，
   它说'我无法获取实时信息'。
   但 Agent 会说'北京今天 15℃，晴。'
   区别在哪？"

视觉素材：
  ChatBot vs Agent 的能力对比图
  ReAct 循环动画
  工具调用流程图
```

## 每期通用结构

```text
0-2 分钟：Hook —— 用一个极端例子或类比建立好奇心
2-4 分钟：为什么需要这个 —— 展示"没有它之前有多惨"
4-10 分钟：核心概念 —— 动画 + 直觉 + 公式人话翻译
10-14 分钟：一个最小例子 —— 用手算或代码演示
14-18 分钟：在实际项目里怎么用 —— 结合你的 UE5 测试项目
18-20 分钟：总结卡片 + 下期预告 + 延伸阅读
```

