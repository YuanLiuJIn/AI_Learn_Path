# 02. 核心评测基准全景

> 目标：了解 50+ 主流评测基准，知道什么时候用什么。

---

## 1. 知识理解类

| 评测 | 维度 | 规模 | 特点 |
|---|---|---|---|
| **MMLU** | 57学科知识 | 14,042 选择 | 最广泛使用的知识评测基准 |
| **C-Eval** | 52 学科中文 | 13,948 选择 | 中文 MMLU |
| **CMMLU** | 67 学科中文 | 11,000+ 选择 | 更丰富的中文知识覆盖面 |
| **AGIEval** | 高考/公务员 | 8,000+ | 中国标准化考试 |
| **ARC** | 科学推理 | 7,787 选择 | 以选择题测试科学推理、逻辑 |

**MMLU 代表性**：

```text
MMLU 考什么？
  数学、物理、化学、生物、计算机、法律、医学...
  57 个学科，每个学科约 200 道选择题

局限：
  都是选择题 → 不考推理性
  题目老旧 → 可能被训练数据覆盖（数据污染）
  2026 年主流模型已接近天花板（GPT-5 > 90%）
```

---

## 2. 推理能力类

| 评测 | 维度 | 特点 |
|---|---|---|
| **GSM8K** | 小学数学 | 8,500 道应用题，最常用数学评测 |
| **MATH** | 竞赛数学 | 12,500 道，比 GSM8K 难得多 |
| **BBH** | 综合推理 | 23 项 Big-Bench 难点精选 |
| **HellaSwag** | 常识推理 | 选择题，选最合理的后续场景 |
| **WinoGrande** | 代词消解 | 2,000 道 | **MMLU** |
| **DROP** | 阅读理解+数学 | 需要读段落做计算 |

---

## 3. 代码能力类

| 评测 | 特点 |
|---|---|
| **HumanEval** | 164 道 Python 函数补全，通过率评测 |
| **MBPP** | 1,000 道 Python 基础编程 |
| **LiveCodeBench** | 防污染，从 LeetCode/Codeforces 抓新题 |
| **BigCodeBench** | 140 个真实编程任务 |

---

## 4. 指令遵循与对话

| 评测 | 方式 | 特点 |
|---|---|---|
| **MT-Bench** | LLM-as-Judge | 80 个多轮对话，GPT-4 评分 |
| **AlpacaEval** | LLM-as-Judge | 805 条指令，LC 版和 Arena 相关度 0.98 |
| **Chatbot Arena** | 人类盲投 | 实时对战，用户投票，最权威的对话评测 |
| **IFEval** | 规则检查 | 精确评估指令遵循（如"输出必须是 JSON"） |

---

## 5. 安全与对齐

| 评测 | 维度 |
|---|---|
| **TruthfulQA** | 模型是否说实话（常识/误解类问题） |
| **ToxiGen** | 毒性内容生成风险 |
| **RealToxicityPrompts** | 100K 真实对话中的毒性 |
| **WildGuard** | 安全拒绝率 + 有害内容检测 |

---

## 6. 多模态

| 评测 | 类型 | 特点 |
|---|---|---|
| **MMBench** | 图文理解 | 20 个能力维度的全方位评测 |
| **MMMU** | 多学科多模态 | 跨 30 学科，需要图表/公式理解 |
| **Video-MME** | 视频理解 | 900 个视频，时长 1s~2h |
| **SEED-Bench** | 多模态综合 | 19K 题，12 个评测维度 |

---

## 7. 长上下文

| 评测 | 上下文长度 | 特点 |
|---|---|---|
| **Needle-in-a-Haystack** | 1K~1M tokens | 在某处插入"针"，看模型能否找到 |
| **LongBench** | 5K-20K 平均 | 双语、多任务长文本理解 |
| **RULER** | 4K~128K | 多维度长上下文评测 |

---

## 8. Agent 评测（详见第 6 章）

| 评测 | Agent 类型 | 特点 |
|---|---|---|
| **SWE-bench** | Coding Agent | 2,294 真实 GitHub Issue |
| **WebArena** | Web Agent | 812 个 Web 操作任务 |
| **AgentBench** | 综合 Agent | 8 类交互环境 |
| **GAIA** | 通用 Agent | 466 个需要多步推理的问题 |

---

## 9. 如何选择评测？

```text
通用能力摸底 → MMLU + GSM8K + HumanEval
中文能力 → C-Eval + CMMLU
代码能力深度 → HumanEval + BigCodeBench
对话体验 → Chatbot Arena + AlpacaEval
安全性 → TruthfulQA + ToxiGen
Agent 能力 → SWE-bench + WebArena
长上下文 → Needle-in-a-Haystack + LongBench

原则：不同评测测不同能力，组合使用才能画出能力剖面。
```
