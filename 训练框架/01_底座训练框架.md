# 底座训练框架（预训练 / 大规模）

> 这层框架解决一个核心问题：**模型太大，一张卡装不下、训不动**。
> 它们通过并行策略把模型/数据/显存切到多卡甚至多机。
> 个人和小团队一般**不直接用**（太重），但理解它们能看懂所有上层框架的底层。

---

## 1. Megatron-LM（NVIDIA）

### 特点

```text
- NVIDIA 出品，3D 并行祖师爷：张量并行 TP + 流水线并行 PP + 数据并行 DP
- 首个系统性提出 Transformer 张量并行的论文（2019）
- 和 Transformer Engine 深度绑定，充分利用 Hopper/Blackwell 算力
- 适合：从零预训练千亿~万亿参数模型
- 缺点：概念重、上手难、强绑定 NVIDIA 生态
```

### 安装

```bash
git clone https://github.com/NVIDIA/Megatron-LM
cd Megatron-LM
pip install -r requirements.txt
# 通常还需要 transformer-engine、apex
```

### 最小可运行示例（伪代码示意）

```bash
# 启动一个 8 卡张量并行的 GPT 预训练
torchrun --nproc_per_node=8 pretrain_gpt.py \
    --tensor-model-parallel-size 8 \
    --pipeline-model-parallel-size 1 \
    --num-layers 24 \
    --hidden-size 1024 \
    --num-attention-heads 16 \
    --micro-batch-size 4 \
    --global-batch-size 32 \
    --train-iters 1000 \
    --tokenizer-type NullTokenizer \
    --vocab-size 51200 \
    --data-path my_corpus
```

> 真实预训练还需要准备 tokenized 数据集、配置 tokenizer、设置学习率调度器等，
> 这里只展示"怎么把并行维度传进去"的核心参数。

## 2. DeepSpeed（Microsoft）

### 特点

```text
- Microsoft 出品，核心是 ZeRO 显存优化：
  ZeRO-1：分片优化器状态
  ZeRO-2：+ 分片梯度
  ZeRO-3：+ 分片模型参数
  ZeRO-Offload：把分片卸载到 CPU/NVMe
- 生态极广，是很多上层框架（含部分 RL 框架）的底层引擎
- 适合：中等规模全参训练、显存紧张时 offload
- 缺点：配置项多、和 PyTorch 原生并行偶有摩擦
```

### 安装

```bash
pip install deepspeed
# 验证
ds_report
```

### 最小可运行示例

`ds_config.json`：

```json
{
  "train_micro_batch_size_per_gpu": 4,
  "gradient_accumulation_steps": 8,
  "bf16": { "enabled": true },
  "zero_optimization": {
    "stage": 3,
    "offload_optimizer": { "device": "cpu" }
  },
  "optimizer": { "type": "AdamW", "params": { "lr": 2e-5 } }
}
```

`train.py`（标准 HuggingFace Trainer + DeepSpeed）：

```python
from transformers import Trainer, TrainingArguments, AutoModelForCausalLM, AutoTokenizer
from datasets import load_dataset

model = AutoModelForCausalLM.from_pretrained("Qwen/Qwen2.5-7B")
tok = AutoTokenizer.from_pretrained("Qwen/Qwen2.5-7B")
ds = load_dataset("json", data_files="train.jsonl")["train"]

args = TrainingArguments(
    output_dir="out",
    per_device_train_batch_size=4,
    gradient_accumulation_steps=8,
    bf16=True,
    deepspeed="ds_config.json",
)
Trainer(model=model, args=args, train_dataset=ds, tokenizer=tok).train()
```

启动：

```bash
deepspeed --num_gpus=4 train.py
```

## 3. FSDP2（PyTorch 原生）

### 特点

```text
- PyTorch 原生 Fully Sharded Data Parallel（第二代，基于 DTensor）
- 不需要装额外库，torchrun 直接能用
- 组合式并行：FSDP + TP + PP 可自由拼，比一代 FSDP 更灵活
- 适合：不想绑死 DeepSpeed、用 PyTorch 原生栈的小团队
- 缺点：高级特性（offload 策略）不如 DeepSpeed 成熟
```

### 安装

```bash
# FSDP2 随 PyTorch 2.2+ 自带，无需额外安装
pip install torch>=2.2
```

### 最小可运行示例

```python
import torch
from torch.distributed.fsdp import FullyShardedDataParallel as FSDP
from torch.distributed.fsdp import ShardingStrategy
from torch.distributed._composable import fully_shard  # FSDP2 推荐写法
from transformers import AutoModelForCausalLM

# 单卡示例（多卡用 torchrun 启动）
model = AutoModelForCausalLM.from_pretrained("Qwen/Qwen2.5-7B")

# FSDP2：逐层分片（composable API）
for module in model.modules():
    if isinstance(module, torch.nn.Linear):
        fully_shard(module)
fully_shard(model)

# 之后像普通模型一样训练
inputs = torch.randint(0, 1000, (1, 128))
out = model(inputs).logits
out.sum().backward()
```

多卡启动：

```bash
torchrun --nproc_per_node=4 train_fsdp.py
```

## 4. 三者怎么选

| 维度 | Megatron-LM | DeepSpeed | FSDP2 |
|---|---|---|---|
| 出身 | NVIDIA | Microsoft | PyTorch 原生 |
| 核心能力 | TP+PP+DP 3D 并行 | ZeRO 分片+卸载 | 组合式原生并行 |
| 上手难度 | 高 | 中 | 低 |
| 生态绑定 | NVIDIA/TE | 较独立 | 纯 PyTorch |
| 你用得到吗 | 基本不用 | 底层可能用到 | 小团队首选 |

## 一句话总结

> 底座框架解决"大模型装不下、训不动"，靠并行把模型切到多卡；个人基本不直接用，
> 但理解 ZeRO / TP / PP / FSDP，能看懂上层所有微调/RL 框架的显存与速度来源。
