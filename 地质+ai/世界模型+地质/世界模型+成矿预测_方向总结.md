# 世界模型 + 地质成矿预测：方向总结

> 一句话：**把找矿从"静态空间分类"重构为"部分可观测序贯决策"，用世界模型充当观测生成器与决策引擎，最终输出地下未知矿产的概率预测与信息最优的勘探动作。**

产品形态仍是"地下未知矿产预测图"，但**真正的 novelty 不在那张图，而在"下一步该做什么"**。

---

## 一、核心命题（问题驱动，不要方法驱动）

不要写"用世界模型做成矿预测"（方法驱动，必被追问 in what sense）。要写成：

> 在矿物质系统约束下，将区域找矿重构为部分可观测序贯决策过程（POMDP），
> 学习可跨区域迁移的地下前向算子 $p(o\mid s)$，
> 实现钻孔选址的信息价值（VOI）最优，
> 并在此基础上输出地下未知矿产的概率预测。

三个可证伪假设，缺一不可：

| 假设 | 内容 | 检验方式 |
|---|---|---|
| **H1 可学性** | $p(o\mid s)$ 冻结后跨区域迁移，精度下降 < X% | 换区域只重训解码器 |
| **H2 有效性** | 同预算下 VOI 策略发现吨位显著 > 判别式策略 | 同预算对照实验 |
| **H3 机理** | 反事实查询能识别判别模型漏掉的矿致异常 | 已知矿床回溯 |

**H3 最有说服力**：它证明的不是"我 AUC 高"，而是"我看到了别的方法结构上看不到的东西"——这才是世界模型存在的理由。

---

## 二、四档强度：只有后两档配叫世界模型

| 档 | 做法 | 是不是世界模型 | 可行性 |
|---|---|---|---|
| ① 判别式 | 图层堆叠 → 成矿概率图 | ❌ 不是 | 已饱和 |
| ② 盒内重建 | 生成式反演，从观测推断三维地下 | ❌ **不是**（是贝叶斯反演 / 三维建模） | 高 |
| ③ ②+观测算子+主动选孔 | 信念空间里做序贯决策 | ⚠️ **是（弱）**，belief-space world model | 中 |
| ④ ③+成矿过程作动力学 | 潜空间里有可学的状态转移 | ✅ **是（强）** | 低，风险高 |

**世界模型试金石（三问全"是"才算）：**
1. 有显式的 $p(o\mid s)$ 吗？
2. 能做贝叶斯更新 $p(s\mid o_{1:k})\to p(s\mid o_{1:k+1})$ 吗？
3. 能对**尚未发生的观测**求期望并据此排序动作吗？

任一"否" → 是三维模拟或反演，不是世界模型。

**红线**：如果做的东西答不出"下一个钻孔该打哪儿"，**就是三维模拟换了时髦名字**。

## 三、数学骨架（世界模型三件套）

$$ \underbrace{p(s)}_{\text{生成器 / 矿物质系统先验}} \;+\; \underbrace{p(o\mid s)}_{\text{可迁移前向算子}} \;+\; \underbrace{\pi(a)}_{\text{信息最优选址} \;=\; \text{VOI}} $$

**技术栈建议：扩散/流模型做提议分布 + SMC 做加权重采样。**

| 组件 | 方案 | 说明 |
|---|---|---|
| Generator | 条件扩散 / 流模型 | 生成三维地下实现 |
| Forward | 代理正演（emulator） | 必须快、可微、可批量 |
| Update | SMC / 粒子滤波 | 真正严格的序贯贝叶斯；退火避免粒子退化 |
| Decision | VOI / EIG + 贪心+局部搜索 | 效用主指标用**信息增益**，不用金属价格 |

**为什么正演必须是代理模型**——算力账：

$$ 10^4 \text{ 候选位置} \times 100 \text{ 后验样本} \times 1 \text{ 次正演} = 10^6 \text{ 次正演} $$

有限元地震一炮 10 秒 → 算不完；重磁解析正演毫秒级 → 能算完。

## 四、两个时间轴：必须选一个（技术分水岭）

| | **时间轴 A：勘探序列** | **时间轴 B：地质时间** |
|---|---|---|
| $t$ | 第 $k$ 个钻孔 | 成矿演化阶段 |
| $s_t$ | 当前信念 / 后验 | 古地质状态（岩浆房、流体、构造） |
| 动力学 | 贝叶斯更新（客观、可算） | 成矿过程（极难标定） |
| 数据支撑 | ✅ 能（每孔一个时间步） | ❌ 几乎不可能 |
| 可否验证 | ✅ 留一钻孔 | ❌ 无真值 |
| 能否直接决策 | ✅ 就是"下一个孔打哪" | ⚠️ 需额外转译 |

**推荐配置：A 当操作轴，B 当先验动力学。**

用**成矿过程模型约束先验** $p(s)$ 和状态转移方向性（地质专业性在这里进得去），
用**勘探序列作为决策时间轴**（可计算、可验证、可发论文）。

这个配置的正经名字：**过程约束的生成式先验 + 序贯主动决策**。
它既避开 B 的不可验证，又防止 A 退化成"纯空间插值"——**这是本 idea 最有价值的形态**。

## 五、三类信息必须拆开（最容易被做错的地方）

绝大多数"多模态融合成矿预测"论文把三类信息塞进一个 encoder。**错。**

| 信息类型 | 真实角色 | 应该进哪里 |
|---|---|---|
| 地表地质图、遥感、地形 | **边界条件 / 初始条件** | 进**先验** $p(s)$ |
| 重磁电震 | 观测算子（带噪声、有分辨率限制） | 进 $p(o\mid s)$ |
| 钻孔 | 稀疏、点状、高置信观测 | 进 $p(o\mid s)$，但**噪声结构完全不同** |

**把"边界条件"当成"观测"的后果**：模型会试图用地表地质"反推"深部岩性——物理上没道理。地表地质是深部的**约束**，不是深部的**采样**。混淆这两者，似然就是错的，后验也就是错的。

**这个区分本身就是可发表的贡献**，绝大多数论文没做。

## 六、世界模型特征 × 现存问题对齐表

**最关键的是最后一列——它告诉你哪些话不能说。**

| 现存方法的真问题 | 对应世界模型能力 | 是否唯一解 | 强度 |
|---|---|---|---|
| 只能回答"哪里像矿"，不能回答"下一步做什么" | 主动决策闭环 | ✅ **是** | **核心** |
| 无法回答 what-if（"在那里测会看到什么"） | 观测算子 + 反事实采样 | ✅ **是** | **核心** |
| 静态输出，新数据只能整体重训 | 序贯贝叶斯更新 | ⚠️ 部分（EnKF 也行） | 中 |
| 只给单值概率，无决策可用不确定性 | 生成式后验（情景集合） | ⚠️ 部分（分位数回归也行） | 中 |
| 跨区必须重训，迁移性差 | 潜空间共享动力学 | ⚠️ **必须自证** | 高价值但需验证 |
| 假负样本、标签不可靠、未发现区≠无矿 | ❌ **世界模型解决不了** | — | **别硬扯** |

**用法**：主线走第 1、2 行（唯一解）；第 3、4、5 行当"顺带获得的额外能力"，不做主线；第 6 行**主动排除**。

## 七、故事五段式（把故事讲完整）

**第 1 段 · 问题层（地质 + 经济）**
找矿本质是**序贯、昂贵、信息受限的决策过程**，钻孔成本极高且不可回收。
真问题不是"哪里最可能有矿"，而是"**有限预算下，下一步该做什么**"。

**第 2 段 · 现状层（文献缺口）**
现有 MPM 从 LR → RF → CNN → Transformer，方法一路演进，**但问题设定从未改变**：输入图层，输出概率图，结束。
典型的"方法在进步、问题在停滞"。

**第 3 段 · 洞察层（机制的，非修辞的）**
为什么改不了？因为它们建模的是 $p(\text{矿}\mid\text{图层})$——**没有动作、没有观测生成模型**的条件概率。

$$ \text{缺 } p(o\mid s) \;\Longrightarrow\; \text{永远算不出"再观测一次值多少"} $$

这是**结构性缺陷，不是容量不足**。所以加容量、换骨干网络，永远解决不了。
→ 这句话是反驳"我把 AUC 从 0.88 提到 0.91"式质疑的关键。

**第 4 段 · 方法层**：三件套挂到第 1 段的问题上。

**第 5 段 · 证据层**：见 §九。

### 必须补的三块（否则故事不完整）

1. **Timing**：为什么现在能做、五年前不行？→ 生成式模型（扩散/流）成熟 + 物探代理正演可行 + GPU + 公开钻孔数据。
   没有这一段，会被问"为什么不是别人早做过了"。
2. **兜底**：主动定义失败条件（例：留一钻孔观测预测不优于克里金 → 数据密度不足）。主动认输显著提升可信度。
3. **边界声明**：见 §十一。

### 最容易被忽略但最要命的一段

现成方法（模拟退火布孔 2013、VOI 加权勘探设计 2022）**已经在做序贯决策**。
必须有一节解释"为什么它们不够"。三条候选理由，**只选一条当主线**：

| 理由 | 内容 | 可证明性 |
|---|---|---|
| **A** | 它们假设观测高斯/线性，无法处理非线性多模态（岩性→物性→物探） | **最好证 ← 建议选** |
| B | 它们假设先验平稳（变差函数），无法编码成矿过程约束 | 中 |
| C | 它们做单步贪心 VOI，无法处理轨迹级长期价值 | 理论价值最高，最难证 |

这一段没写，审稿人第一句话就是"这跟模拟退火布孔有什么区别"。

## 八、实施路线

| 阶段 | 周期 | 任务 | 止损判据 |
|---|---|---|---|
| **P0 空白确认 + 探区锁定** | 2–4 周 | 三组检索式钉死空白；探区硬指标：**重磁/物探覆盖 + 钻孔 ≥30–50 个 + 孔间有测线 + 有已发表 baseline** | 找不到满足的探区 → 版本③不成立 |
| **P1 复现 baseline** | 6–8 周 | RF/XGB/CNN 跑到已发表水平 | **不可跳过**，没有 baseline 就没有分母 |
| **P2 学前向算子 $p(o\mid s)$** | 8–12 周 | 先学"物性→地球物理"代理正演（合成数据预训练），再学"岩性→物性"；**留一钻孔**评测 | 若不显著优于克里金/最近邻 → **立即退回版本②** |
| **P3 反演与增量同化** | 8–12 周 | 条件生成 $p(s\mid o_{1:k})$，$k:0\to N$，量化后验收敛速度 | 收敛曲线无平台 → 观测信息量不足 |
| **P4 决策闭环** | 8–12 周 | 效用=信息增益；对比四策略：随机 / 判别分数最大处 / 地统计-VOI / **学习式 VOI** | **这是核心结果** |
| **P5 迁移实验**（加分） | 4–6 周 | 冻结前向算子，换区只重训解码器 | 这是 H1 的唯一检验方式 |

**P2 才是真正的技术核心，也是最大风险点。** 很多人以为核心是决策，其实决策水到渠成；学不出 $p(o\mid s)$ 才会死人。

**探区选择硬指标**：优先"**有重磁数据 + 密集钻孔**"的探区。
原因：重磁正演是解析的（毫秒级）、测井可用岩石物理经验式（Gassmann/Wyllie/Archie），
这是最快最便宜拿到可用 $p(o\mid s)$ 的组合。

## 九、证据四级（从弱到强）

| 级别 | 证据 | 作用 |
|---|---|---|
| **准入线** | where 精度**不劣于** baseline | **不是卖点，是保命线** |
| 中 | 留一钻孔的观测预测精度 | 证明 $p(o\mid s)$ 真学到了 |
| 强 | 同预算下 VOI 策略发现收益 > 判别式策略 | 证明决策价值 |
| 最强 | **反事实回溯**：按新策略重放历史勘探，会在第几个孔发现已知矿 | 故事闭环 |

准入线很重要：**保证新增能力的同时判别精度不塌**，否则一句话被击倒——"你的 where 还不如随机森林"。

## 十、风险清单（按严重度）

**严重（可能直接毙掉）**

1. **真值不可得 → 无法验证世界模型本身。**
   审稿人必问"你怎么知道地下模型是对的"。
   → 唯一解法：全部评测建立在**可观测预测**上（留一钻孔、留一测线），明确声明不主张恢复真值。**必须正面写，不能回避。**
2. **数据密度不足 → 前向算数学不出来。**
   十几个钻孔在二维栅格上学不出 $p(o\mid s)$。**这是最可能让整个 idea 崩掉的一条**，必须最先验证。
3. **baseline 太强 → 增量不显著。**
   VOI 的解析/地统计近似已成熟（2013 模拟退火、2022 Efficacy of Information）。
   必须证明学习式正演在某维度上**本质**更强（见 §七理由 A/B/C）。

**中级（引发大修）**

4. **效用函数任意性**：金属价格、钻孔成本、折现率全人为设定 → **主指标用信息增益（EIG），经济效用只做敏感性分析**。
5. **命名风险**：若实际做的是"物理正演代理 + 贝叶斯反演"，没有动作空间学习、没有 policy learning，审稿人会说根本不是世界模型。
   → **主动改名**为"可迁移地下生成正演模型 + 序贯决策"。**为迎合时髦词套不匹配的术语，是最常见的自伤。**
6. **跨尺度**：物探分辨率 vs 钻孔分辨率 vs 图件尺度，前向算子要跨尺度，需显式建模。

**轻度（会被问但不致命）**

7. 验证区域太少 → H1 无法统计检验（可降到 2 区域 + 单侧检验）。
8. 全流程算力重（三维生成 + 反演 + 决策搜索）。
9. 与 GAN 三维建模工作（2019, 164 引；2024, 83 引）的边界模糊，需反复划清。

### 一个必须处理的隐性陷阱：钻孔位置不是随机缺失

- 前人为什么在那里打孔？因为他们看到了什么（露头、异常、构造）。
- 钻密的地方往往交通好、矿化好、或已被开采。

→ 直接拿来当训练/验证集，模型会学到被"前人已找过的区域"饱和过的分布。

**处理方向**：① 把钻孔位置本身作为协变量（位置是信息，不是噪声）；② 倾向性加权校正采样偏差。
很多论文完全忽略，处理了就是加分项。

## 十一、边界声明（主动划界 > 被人戳破）

**明确不主张：**
- 不恢复地下真值（只保证可观测预测的校准性）
- 不预言未发现的矿
- 不解决标签不可靠 / 假负样本问题

---

## 十二、前置三动作（先做完再投入）

1. **三组检索式钉死"组合型空白"**——决定所有后续工作立足点。
2. **一周证伪实验（成本最低、信息量最大）**：
   选有重磁 + 密集钻孔的探区 → 钻孔岩性/物性 → 解析重磁正演 → 与实测比。
   - 孔上残差小 → $p(o\mid s)$ 没问题
   - 孔间残差大且结构化 → **核心困难是"孔间 $s$ 未知"，不是正演不准**
     → 技术路线必须是"生成式先验 + 序贯观测约束"，而非"提高正演精度"
   也做留一钻孔实验：49 孔训 → 预测第 50 孔测井；再看加邻近孔物探能提升多少。
   **若加条件观测几乎无提升 → 观测手段对状态不敏感 → idea 必须重估。**
3. **定探区**（硬指标见 P0）。

---

## 十三、悬而未决的三个决定性问题

1. **where 精度能不能不降？** 能 → 故事稳（净增益）；不能 → 故事崩（用精度换花活）。**比写故事更急。**
2. **能不能拿到"同预算对照"的数字？** 拿不到 → 故事只能停在"方法可行"，无法证明"决策更优"。
3. **选 A / B / C 哪条作为"比模拟退火强"的理由？** 选定后才能设计对应实验。

---

## 十四、降级路径（保证有产出）

版本③不成立 → 版本②（多模态融合 + 地质文本推理出靶区）
→ 再不行退到"判别式 + 严格不确定性量化 + 空间交叉验证"的规范化改进研究。

## 附：世界模型 vs 三维模拟（速查）

| 维度 | 三维地质模拟 | 世界模型 |
|---|---|---|
| 建模对象 | 状态 $s$ 的空间分布 | $p(s)$ 与 $p(o\mid s)$ 的**联合** |
| 观测的角色 | 硬数据约束、插值锚点，单向 | 推断入口，可反向更新后验 |
| 观测算子 | 通常没有 | **核心组件** |
| 输出 | 一组等概率几何模型 | 后验情景 + 预测观测 + 决策 |
| 序贯 | 无 | 有 |
| 能否算 VOI | 不能 | 能（定义要求） |
| 评测 | 地质合理性、与井吻合 | 留一钻孔似然、同预算决策收益 |

**世界模型 ⊃ 三维模拟。** 三维模拟可以是世界模型的解码器/先验，但本身不构成世界模型——缺观测算子和决策闭环。
已有接近者 FWIGAN（2023, 95 引，物理信息 GAN 全波形反演）有正演有反演，**但不闭环到决策** → novelty 边界必须落在"决策闭环"。
