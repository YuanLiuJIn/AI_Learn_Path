# 06 · 工程素养（伴读）

> 对应原始库：`dev/`（51 文件）+ `misc/`（18 文件）。
> 这些不直接讲 AI，但决定你能不能"把模型跑起来、调得动、部署得出去"。随时补，不阻塞主线。

## 1. 开发环境 → `dev/environment/`（23 文件，最常用）
- 环境管理：conda / venv / 多 CUDA 版本切换。
- 依赖管理与复现（requirements、lockfile）。
- **和你的 `升腾910b_infra/` 互补**：那里讲 NPU 环境，这里讲通用 Python/AI 环境。

## 2. 容器化 → `dev/docker/`
- Docker 基础、镜像构建、GPU/NPU 容器内可见性。
- 训练任务容器化是生产标配。

## 3. 版本控制 → `dev/git-github/`
- git 工作流、分支策略、PR review。
- 配合你正在做的"提交/push 学习笔记"就是这个范畴。

## 4. Python 功底 → `dev/python-数据结构/`、`dev/python-advanced/`
- 数据结构、装饰器、生成器、元类、异步。
- `python-advanced/` 是写出高质量 agent/训练脚本的基础。

## 5. 软件工程 → `dev/软件工程/`、`dev/设计模式/`
- 设计模式（工厂/策略/观察者等）在 agent 框架编排里很常用。
- 可测试性、模块化。

## 6. 并发与网络 → `dev/multi-threads/`、`dev/网路问题/`
- 多线程/多进程/异步 IO（推理服务并发）。
- 网络排查（端口、代理、连通性）——分布式训练/部署的常见雷区。

## 7. 前端 → `dev/web-frontend/`、`dev/技术栈选型/`
- 给 agent / 推理服务做 demo 界面时用。
- 技术栈选型：什么时候用啥框架。

## 8. 杂项 → `misc/`
- `leetcode/`：算法刷题（面试/基本功）。
- `data_science/`：数据分析（pandas/可视化，处理训练数据用）。
- `vibe-coding/`：AI 辅助编程（用 LLM 写代码的新范式）。
- `signal_system/`：信号与系统（偏底层，按需）。
- `tools/`：各类工具链。
- `models.ipynb` / `resources.ipynb`：模型与资源汇总。

## 9. 阅读建议

工程素养**不要集中刷**，而是：
- 跑不起来环境 → 翻 `dev/environment/`、`dev/docker/`
- 代码写不顺 → 翻 `python-advanced/`、`软件工程/`
- 要部署/排查 → 翻 `git-github/`、`网路问题/`、`multi-threads/`
- 面试准备 → 翻 `misc/leetcode/`

## 在原始库里的阅读落点

`dev/environment/` → `dev/docker/` → `dev/git-github/` → `dev/python-advanced/` → `dev/软件工程/` + `设计模式/` → `dev/multi-threads/` + `网路问题/` → `dev/web-frontend/`；`misc/leetcode/`、`misc/data_science/`、`misc/vibe-coding/`
