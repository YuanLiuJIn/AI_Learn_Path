## 3. 深度学习技术（Deep Learning Technology）

深度学习（deep learning）是指以人工神经网络为代表的、基于深度神经网络模型的机器学习方法，它能够有效识别矿产预测中与矿化存在隐性关联的特征与数据类型，弥补了普通机器学习算法的不足 [4]。人工神经网络是一种模拟生物神经网络行为特征、以分布式并行信息处理复杂数据输入的算法数学模型 [75]，其以结构化方式定义网络中的变量及其拓扑关系 [34]。随着深度学习的不断发展，越来越多的深度学习算法被应用于找矿预测，已成为研究的热点与前沿。

### 3.1. 深度自编码器（Deep Autoencoder）

自编码器（autoencoder, AE）是一种**无监督特征学习网络**，它利用反向传播算法使目标输出值等于输入值。自编码器由输入层、隐藏层和输出层组成。输入层输入后，数据在隐藏层被压缩编码以增强数据特征，然后再进行解码 [30,76]。其编码公式 (1) 与解码公式 (2) 分别为：

$$Z = \varphi(W_e \theta x) \tag{1}$$

$$X = W_D Z = W_D \varphi(W_e \theta x) \tag{2}$$

式中，$x$ 表示训练数据（含偏置），$W_e$ 表示编码器，$\varphi$ 表示激活函数，$Z$ 表示输出值；$W_D$ 表示解码器，负责将输出值还原为输入值。由于自编码器模型单元的输入数据与输出值遵循单个真实神经元的基本逻辑 [77]，解码操作过程函数为恒等函数，以获得输出值与编码输入值。

深度信念网络（Deep Belief Network, DBN）由 Hinton 于 2006 年提出，是由堆叠的受限玻尔兹曼机（constrained Boltzmann sets）组成的概率生成模型。通过训练神经元之间的权重，整个神经网络能够按最大概率生成训练数据 [30,78,79]。**深度自编码器（DAE）** 是在深度信念网络的基础上发展起来的。首先训练一个模型学习样本的模式分布，通过最小化输出值与输入值之间的差异来重建样本，然后将重建误差较高的样本识别为异常。

自编码器可以在无差别的情况下训练样本，减少无关特征信息的提取，在数据降维方面效果良好 [4,80]。由于自编码器对异常样本的重建误差高、对背景样本的重建误差低，它在处理地球物理、地球化学和遥感数据方面具有良好的适用性，能够快速识别数据异常。根据成矿规律与找矿实践，矿床的形成与发现是小概率事件。与矿化有关的数据异常往往属于低概率样本，对自编码器的贡献很小，因此其编码与重建效果较差、重建误差相对较高 [29,30,81]。我们可以利用这些重建误差较大的数据来识别找矿预测中的离群值。

### 3.2. 生成对抗网络（Generative Adversarial Network）

作为一种深度生成模型，生成对抗网络（GAN）由生成网络与判别网络组成。生成网络通过学习数据分布来生成接近真实样本的样本；判别网络用于评估样本是来自真实样本还是生成样本。两个神经网络模型持续进行二元极小极大博弈，直至二者之间的对抗达到纳什均衡，常用于处理复杂、高维的数据 [82]。与传统自编码器框架相比，生成对抗网络框架新增的判别器具有调节反馈、引导生成器的功能 [29]。生成对抗网络的基本框架公式为：

$$L(D) = \mathbb{E}[\log D(x)] + \mathbb{E}[\log(1 - D(G(z)))] \tag{3}$$

$$L(G) = \mathbb{E}[\log(D(G(z)))] \tag{4}$$

式 (3) 为判别器损失函数，式 (4) 为生成器损失函数；$x$ 表示真实数据，$z$ 表示噪声，$G$ 代表生成模型，$D$ 代表判别模型，$G(z)$ 表示输入噪声经生成网络后的输出。生成器的目标是生成非常接近真实数据的数据，即让 $D(G(z))$ 尽可能接近 1。

在深度学习过程中，地质勘查数据的有限性与不平衡性往往导致模型误差较大或过拟合特征明显。使用生成对抗网络进行数据增强处理，非常适合解决地质数据正样本数量少的问题。在处理正负样本不平衡的数据时，生成对抗网络能够捕捉原始地质数据中复杂的模式与依赖关系，从而生成高质量的样本数据 [52,83,84]。Farahbakhsh 等 [84] 使用生成对抗网络生成高度逼真、贴近平行数据分布的高质量样本，以增加模型中正样本的数量，有效解决了地质数据中正样本不足导致的训练数据不平衡问题。Wu 等 [52] 使用条件生成对抗网络，在初始随机噪声上添加合适的标签，生成与原始地质数据相似的合成样本，调整正负样本的分布并提升数据质量。经生成对抗网络增强后的数据集模型表现出更好的鲁棒性，训练集与测试集精度均达到较高水平，模型具有更好的抗过拟合能力。

生成对抗网络在训练过程中生成的图像更为清晰，但容易出现模态坍塌（mode collapse）与梯度消失 [80]。生成对抗网络也缺乏有效的推理机制，其数据往往难以进行抽象推理过程。已有研究利用生成对抗网络与深度自编码器之间的关联来训练其推理能力 [85]。因此，前人使用生成对抗网络进行找矿预测时，往往利用其超强的样本集生成能力进行数据增强操作，后续的找矿预测建模过程则使用其他深度学习算法。换言之，前人使用生成对抗网络进行找矿预测时，常利用其极强的样本生成能力来增强数据，生成的数据与原始数据具有更好的一致性；在此基础上，研究者再将其与其他深度学习方法结合来进行找矿预测。

### 3.3. 卷积神经网络（Convolutional Neural Network）

卷积神经网络（CNN）是机器学习中的一种深度前馈人工神经网络分类方法，它采用局部感受野与时间/空间下采样的思想，具有平移不变性和权值共享结构的特点，显著减少了网络中的自由参数数量。卷积神经网络的优点在于，它不仅能学习数据的整体特征，还能学习数据的局部特征，且这些局部特征之间也具有一定的相关性。通过对矿床数据逐层提取特征，可以获得成矿因子与矿床之间的相关性 [4,86]。卷积神经网络以图像为基础，而找矿预测中使用的多源地质数据与遥感数据可以很方便地统一为图像格式，这为卷积神经网络在找矿预测中的应用提供了基础条件 [87]。

基本的卷积神经网络结构一般包括输入层、卷积层、池化层、全连接层和输出层。输入层以原始的网格化数据作为输入数据。由于输入层数据未经处理，且隐藏层部分无法人工干预，卷积神经网络避免了研究者主观认知及其自身局限可能带来的影响 [34,76,86,88]。池化是对卷积所完成的数据特征进行压缩与汇聚，减少计算量并提取数据的主要特征 [89]。池化一般选择两种方式：平均池化与最大池化 [86]。平均池化对硬件要求相对较低，能够减少卷积层所获得的数据冗余，尽可能保留地质特征的多样性；最大池化能够突出最显著的特征，降低计算复杂度并增强模型的鲁棒性 [9,90]。在全连接层中，每个节点都与前一层的所有节点相连，将卷积层与池化层提取的特征进行整合，在网络末端实现特征映射与分类。全连接层的本质是一个反向传播神经网络 [86,88,91]。

卷积神经网络用于找矿预测的一般流程包括：数据收集与整理 → 生成训练集、验证集、测试集 → 模型构建 → 训练与验证 → 确定找矿预测区。由于地质数据种类繁多，卷积神经网络能够充分挖掘不同种类数据之间的深层关系，对充分利用数据带来很大帮助。因此，卷积神经网络在地质找矿预测中应用广泛。

### 3.4. 循环神经网络（Recurrent Neural Network）

在深度学习领域，具有循环连接的循环神经网络（RNN）能够处理变长序列输入，对序列数据进行建模以实现序列识别与预测，通过循环迭代函数存储信息，并能很好地捕捉上下文信息。为实现瞬态依赖学习，其研究对象主要是序列数据，如文本、时间序列数据等 [92]。循环神经网络由输入层、隐藏层和输出层组成。在使用过程中，人们发现它难以建立长期依赖关系，因此前人设计了更复杂的激活函数来解决这一问题，其中最重要的方法包括**长短期记忆网络（LSTM）**（图 2）与**门控循环单元（GRU）** [93–95]。LSTM 专为分析序列数据而设计，其主要思想是通过循环连接的记忆单元以及每个记忆块中的三个关键门控单元（即遗忘门、输入门和输出门）进行预测。门控是通过激活函数选择性保留或遗忘信息的一种方式 [96]。GRU 具有调节单元内部信息流动的门控单元，但没有单独的存储单元，在较小数据集上表现出更好的性能 [97]。

**图 2（Figure 2）** 一个基本的 LSTM 模块 [98]。$f_t$、$i_t$、$O_t$ 分别为时间步 $t$ 的遗忘门、输入门和输出门的输出；$C_{t-1}$ 与 $C_t$ 对应时间 $t-1$ 与时间 $t$ 的单元状态；$\tilde{C}_t$ 表示时间步 $t$ 新引入的信息；$\sigma_L$ 与 $\sigma_R$ 用作激活函数；+ 表示相加，× 表示相乘。

循环神经网络注重学习相互影响变量之间的相互作用，并有潜力整合高度相关的地质特征用于找矿预测。LSTM 能够捕捉序列内部的上下文信息，弥补了 CNN 在上下文序列建模方面的不足，是解释与成因有关的地球化学元素的首选 [99]。循环神经网络的这一优势在基于文本的地质数据使用中发挥着非常重要的作用，能够整合原始数据并提取与矿化有关的重要信息。
