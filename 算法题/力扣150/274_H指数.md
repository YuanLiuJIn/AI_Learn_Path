# 274. H 指数（H-Index）

## 题目
- `citations[i]` 表示第 i 篇论文被引用次数。
- h 指数：至少发表了 h 篇论文，且**至少**有 h 篇论文被引用次数 ≥ h。h 有多种可能时取最大的。
- 提示：`1 <= n <= 5000`，`0 <= citations[i] <= 1000`。

## 关键性质
- **h 不可能超过论文总数 n**（最多 n 篇论文）。
- 定义翻译：「有 h 篇论文被引用 ≥ h」⇔ 排序后存在某个位置，其后（含）恰有 ≥h 篇且引用数都 ≥h。

## 解法一：排序后线性扫描（★推荐，O(n log n)）
升序排序后，从前往后找**第一个**满足 `citations[i] >= n-i` 的位置，`h = n-i` 即为最大可行 h（因为 `n-i` 随 i 增大而减小，第一个满足的就是最大的 h）。
```cpp
int hIndex(vector<int>& citations) {
    sort(citations.begin(), citations.end());
    int n = citations.size();
    for (int i = 0; i < n; i++) {
        int h = n - i;                  // 从 i 到末尾共 h 篇，引用都 >= citations[i]
        if (citations[i] >= h) return h; // 这 h 篇都满足 >=h，h 可行
    }
    return 0;
}
```

## 解法二：计数排序（桶，O(n) 时间 O(n) 空间，面试加分）
h ∈ [0, n]，引用数 ≥ n 的都等价于 n（h 不会超 n）。统计各引用次数的论文篇数，再从 h=n 倒着累加，累计篇数 ≥ h 即答案。
```cpp
int hIndex(vector<int>& citations) {
    int n = citations.size();
    vector<int> cnt(n + 1, 0);
    for (int c : citations) {
        if (c >= n) cnt[n]++;           // 引用超过 n 的钳到 n
        else cnt[c]++;
    }
    int cum = 0;                        // 累计“引用数 >= 当前 h”的篇数
    for (int h = n; h >= 0; h--) {
        cum += cnt[h];
        if (cum >= h) return h;          // 至少 h 篇被引用 >= h
    }
    return 0;
}
```

## 推演：`citations=[3,0,6,1,5]`，n=5
升序排序 → `[0,1,3,5,6]`
| i | citations[i] | n-i (h) | citations[i]>=h? | 动作 |
|---|---|---|---|---|
| 0 | 0 | 5 | 否 | 继续 |
| 1 | 1 | 4 | 否 | 继续 |
| 2 | 3 | 3 | **是** | 返回 h=3 ✓ |

其余两篇(5,6)引用 >3，符合「至少 3 篇 ≥3」。

## 推演：`citations=[1,3,1]`，n=3
升序 → `[1,1,3]`
| i | citations[i] | n-i | >=? | 动作 |
|---|---|---|---|---|
| 0 | 1 | 3 | 否 | 继续 |
| 1 | 1 | 2 | 否 | 继续 |
| 2 | 3 | 1 | **是** | 返回 h=1 ✓ |

## 易错点（写代码时注意）
1. **h 上限是 n**：别写成「citations[i] >= i+1」那类反向条件；用 `n-i` 才是「后面还有几篇」。
2. **排序方向 + 扫描方向要配套**：升序排序就「从前往后找第一个 `citations[i] >= n-i`」；若降序则用「从后往前找 `citations[i] >= i+1`」。混着写会错。
3. **break/return 取第一个满足的**：`n-i` 随 i 增大递减，第一个满足即最大 h。遍历到底返回 0（全 0 等情况）。
4. **计数法要钳上限**：`c >= n` 必须 `cnt[n]++` 而非 `cnt[c]++`，否则越界且 h 统计失真。
5. **「至少 h 篇」不是「恰好」**：判断用 `>=`，提示里 `citations[i]` 可为 0，h 可为 0。
