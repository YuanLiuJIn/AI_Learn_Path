## 0. 评测岗为什么必须懂原理

评测不是"跑个脚本看分数"。模型侧的每一个设计选择都会影响你的评测结果：

| 你不懂的原理 | 评测时会踩的坑 |
|---|---|
| 不知道 chat template 的存在 | 复现 MMLU 和官方差 10 分 |
| 不知道 CFG 是什么 | T2I 一致性分数因默认 CFG 不同而不可比 |
| 不知道 RoPE 与上下文长度 | 长文评测用了超出训练长度的 prompt，分数虚高 |
| 不知道 logits 采样 vs 生成式打分 | 同一题两种打分方式差 5-10 分 |
| 不知道检测器 IoU 阈值 | Grounding 评测结果和论文对不上 |

所以本章是后面所有评测章节的地基。

## 1. Transformer —— 一切的起点

### 1.1 为什么出现
RNN 串行、难并行、长程记忆衰减。Transformer 用**自注意力**一步算全序列两两关系，可完全并行训练。

### 1.2 核心：缩放点积注意力
$$
\text{Attention}(Q,K,V)=\text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$
- $Q,K,V$ 由输入线性投影得到；$\sqrt{d_k}$ 防止点积过大导致 softmax 梯度消失。
- **多头注意力**：并行多组 $(Q,K,V)$，捕捉不同子空间关系。

### 1.3 位置编码（评测强相关）
注意力本身**置换不变**，必须注入位置信息：
- **绝对位置**（原始 Transformer，sin/cos 或可学习）
- **相对位置**（T5、Transformer-XL）：编码"相对距离"
- **RoPE（旋转位置编码）**：把位置编码成旋转矩阵，LLaMA/Qwen 等主流用。**评测注意**：RoPE 外推能力有限，超长 prompt 需 NTK-aware 缩放或 YaRN，否则长文分数虚高。

### 1.4 三种典型结构
| 结构 | 代表 | 评测用途 |
|---|---|---|
| 仅编码器（Encoder-only） | BERT | 文本分类/检索/特征抽取 |
| 编码器-解码器（Enc-Dec） | T5、mT5 | 翻译、摘要、Seq2Seq |
| 仅解码器（Decoder-only） | GPT、LLaMA、Qwen | 自回归生成、Chat 模型 |

### 1.5 评测视角
- **KV Cache**：自回归解码时缓存历史 K/V，显存随长度线性增长 → 长文评测要监控显存与 TTFT。
- **推理后端差异**：vLLM（PagedAttention）vs HF 生成结果可能略有不同 → 同批对比必须同一后端（见语言笔记 §1.2）。

**论文**：Attention Is All You Need (arXiv:1706.03762)
**代码库**：[HuggingFace Transformers](https://github.com/huggingface/transformers)、[nanotron](https://github.com/huggingface/nanotron)、[xformers](https://github.com/facebookresearch/xformers)

## 2. BERT 与预训练语言模型（编码器）

### 2.1 核心思想
把"理解语言"变成填空游戏。用 **Masked Language Model (MLM)** 随机遮盖 15% token 让模型预测，强制学双向上下文。

### 2.2 训练目标
- **MLM**：预测被 [MASK] 的 token。
- **NSP（Next Sentence Prediction）**：判断两句是否相邻（后续 RoBERTa 证明可去掉）。

```python
# 简化版 MLM 训练
masked_input = mask_tokens(input_ids, mask_prob=0.15)
logits = bert(masked_input).last_hidden_state  # [B, L, vocab]
loss = cross_entropy(logits[mask_positions], original_ids[mask_positions])
```

### 2.3 评测视角
- BERT 类模型**不能直接做生成式评测**，要用于：文本分类、NER、语义相似度（STS）、**检索/向量库**（embedding 模型）。
- 评测 embedding 模型用 **MTEB** 榜单（多任务文本向量基准），指标含 STS 的 Spearman、检索的 nDCG/Recall@K。
- **base vs chat 模型区别同样适用**：BERT 用 `[CLS]` 池化做分类，模板错了分数崩。

**论文**：BERT: Pre-training of Deep Bidirectional Transformers (arXiv:1810.04805)；RoBERTa (arXiv:1907.11692)
**代码库**：[transformers](https://github.com/huggingface/transformers)、[sentence-transformers](https://github.com/UKPLab/sentence-transformers)

## 3. CNN 家族：ResNet / VGG（视觉骨干）

### 3.1 卷积直觉
卷积核在图上滑动提取局部特征（边缘→纹理→部件→物体），**权重共享 + 局部连接**大幅降参。

### 3.2 VGG：堆叠小卷积
用连续的 3×3 卷积堆深度（VGG16/19），结构简单但参数量大。

### 3.3 ResNet：残差连接（里程碑）
深层网络梯度消失。ResNet 引入**跳跃连接** $y = F(x) + x$，让网络学"残差"：
```
plain:  H(x)           ──► 难训
resnet: H(x) = F(x)+x  ──► 易训，可堆到 152 层
```
**评测视角**：ResNet-50 是图像分类评测的常用 backbone 与 ImageNet Top-1 基准线；也是很多生成评测器（如 GenEval 用 Mask2Former）的底层特征来源。

### 3.4 评测指标
- **Top-1 / Top-5 Accuracy**：分类正确率（Top-5 允许前 5 个预测含正确答案）。
- ImageNet 是标准测试集（1000 类）。

**论文**：ResNet (arXiv:1512.03385)；VGG (arXiv:1409.1556)
**代码库**：[torchvision](https://github.com/pytorch/vision)（models.resnet50、models.vgg16）

## 4. 目标检测：R-CNN / YOLO

### 4.1 Two-stage：R-CNN 系列
1. 用 Selective Search / RPN 提出候选框（region proposal）
2. 对每个框做分类 + 边框回归
- R-CNN → Fast R-CNN（共享卷积）→ Faster R-CNN（RPN 端到端）

### 4.2 One-stage：YOLO
把检测当成"单遍回归"：把图分成网格，每格预测边界框 + 类别概率，**快**。

```python
# YOLO 输出：网格 × 锚框 × (x,y,w,h,conf,class_probs)
pred = model(img)  # [B, S, S, B_anchors*(5+C)]
```
- 版本演进：YOLOv1(1506.02640) → v3 → v5(v8/v10/v11，ultralytics)。

### 4.3 评测指标（检测评测核心）
- **IoU（交并比）**：$\text{IoU}=\frac{|A\cap B|}{|A\cup B|}$，判定预测框是否命中。
- **mAP（mean Average Precision）**：不同 IoU 阈值（0.5、0.75、0.5:0.95）下的平均精度均值，是检测排行榜主指标。
- **评测注意**：IoU 阈值设置直接决定"算不算对"，多模态 Grounding 评测常用 IoU@0.5（见多模态笔记 §3）。

**论文**：R-CNN (arXiv:1311.2524)；Fast R-CNN (arXiv:1504.08083)；Faster R-CNN (arXiv:1506.01497)；YOLO (arXiv:1506.02640)
**代码库**：[detectron2](https://github.com/facebookresearch/detectron2)、[ultralytics](https://github.com/ultralytics/ultralytics)

## 5. 生成模型：GAN / VAE

### 5.1 GAN（生成对抗网络）
两个网络博弈：
- **生成器 G**：把噪声 $z$ 映射成假样本
- **判别器 D**：区分真假
$$
\min_G\max_D \mathbb{E}_{x\sim p_{data}}[\log D(x)]+\mathbb{E}_{z}[\log(1-D(G(z)))]
$$
- **评测视角**：GAN 的 mode collapse（模式崩溃）会导致生成多样性差 → 评测要同时看 FID（质量）与 IS/多样性；GAN 是早期 T2I（StyleGAN、Stable Diffusion 前时代）主力。

### 5.2 VAE（变分自编码器）
学一个潜空间：$q_\phi(z|x)$ 编码，$p_\theta(x|z)$ 解码，优化**变分下界 ELBO**：
$$
\mathcal{L}=\mathbb{E}_{q}[\log p_\theta(x|z)]-\mathrm{KL}(q_\phi(z|x)\,\|\,p(z))
$$
- 前半是重建损失，后半是正则（逼潜空间接近标准高斯）。
- **评测视角**：VAE 是 Diffusion 的前身，其"潜空间"思想被 SD（在 VAE 潜空间做扩散）继承。

**论文**：GAN (arXiv:1406.2661)；VAE (arXiv:1312.6114)
**代码库**：[diffusers](https://github.com/huggingface/diffusers)（含 VAE/DiT）、[torchgan](https://github.com/torchgan/torchgan)

## 6. Diffusion Models（DDPM）

### 6.1 核心思想
不用 GAN 的对抗，而是**逐步加噪→学去噪**：
- 前向：把数据 $x_0$ 按时间表逐步加高斯噪声到 $x_T\sim\mathcal{N}(0,I)$
- 反向：训练 $\epsilon_\theta$ 预测每一步加的噪声
$$
\mathcal{L}_{\text{simple}}=\mathbb{E}_{t,x_0,\epsilon}\big[\|\epsilon-\epsilon_\theta(x_t,t)\|^2\big]
$$
- 采样：从纯噪声出发，迭代去噪 $T$ 步得到样本。

### 6.2 CFG（Classifier-Free Guidance）
训练时随机丢条件，推理时
$$
\tilde{\epsilon}=\epsilon_\theta(x_t,\varnothing)+w\cdot(\epsilon_\theta(x_t,c)-\epsilon_\theta(x_t,\varnothing))
$$
$w$ 越大越贴合 prompt，但可能过饱和。**这是 T2I/T2V 评测必须统一的变量**（见扩散笔记 §6.1：CFG/步数/seed 必须公开）。

### 6.3 评测视角
- 采样步数、采样器（DDIM/Euler）、CFG、seed、分辨率 → 任一不同都导致分数不可比。
- 潜空间扩散（LDM）：先在 VAE 潜空间扩散，再用 decoder 解码 → 评测要分清"扩散质量"与"decoder 质量"。

**论文**：DDPM (arXiv:2006.11239)；Classifier-Free Guidance (arXiv:2207.12598)；LDM/Stable Diffusion (arXiv:2112.10752)
**代码库**：[diffusers](https://github.com/huggingface/diffusers)、[ComfyUI](https://github.com/comfyanonymous/ComfyUI)

## 7. DiT（Diffusion Transformer）

### 7.1 为什么出现
传统扩散用 U-Net 去噪。DiT 把 U-Net 换成 **Transformer**：把潜变量切成 patch，当成 token 序列做自注意力去噪。

$$
\text{DiT}: \text{patchify}(z)\xrightarrow{\text{Transformer blocks}}\epsilon_\theta
$$
- 验证了**扩散模型也遵循 scaling law**：模型越大、patch 越小，生成质量越高（Gflops 与 FID 强相关）。

### 7.2 与视频生成的渊源
DiT 的"时空 patch"思路是 Sora、OpenSora、Latte 等 **T2V/I2V** 模型的基础架构（见第 02 章 T2V 节）。

### 7.3 评测视角
- DiT 可扩展性意味着**同一架构不同尺寸**的横向评测（小/中/大）能看到 scaling 曲线，是评测报告的好素材。
- 视频 DiT 的评测要额外关注时序一致性（VBench 的 temporal 维度，见扩散笔记 §3.7）。

**论文**：DiT (arXiv:2212.09748)；Latte (arXiv:2401.03048)；Open-Sora (arXiv:2402.10029)
**代码库**：[diffusers DiT](https://github.com/huggingface/diffusers)、[Open-Sora](https://github.com/hpcaitech/Open-Sora)

## 8. CLIP / BLIP（多模态对齐）

### 8.1 CLIP：图文对比学习
用 4 亿图文对，训练时让"匹配的图文"特征相似、不匹配的远离：
$$
\mathcal{L}_{\text{contrastive}}=-\log\frac{e^{\langle I,T\rangle/\tau}}{\sum_{j}e^{\langle I,T_j\rangle/\tau}}
$$
- 得到**通用的视觉编码器 + 文本编码器**，可零样本分类（"a photo of a {class}"）。

### 8.2 BLIP：视觉语言预训练
在 CLIP 基础上加**三个预训练任务**：ITM（图文匹配）、ITG（图像描述生成）、IC（图文对比），并用**合成 caption 过滤噪声**，是后续 BLIP-2（Q-Former 连接 LLM）的基础。

### 8.3 评测视角（极重要）
- **CLIPScore**：图文一致性自动指标（见扩散笔记 §3.2），但有组合关系不敏感缺陷。
- **CLIP 是很多评测器的底座**：VQAScore 用 CLIP-FlanT5；很多 zero-shot 分类评测直接调用 CLIP。
- **评测注意**：CLIP 版本（ViT-B/L/H、openai/laion）不同，特征不同 → 报告必须写明用的是哪个 CLIP。
- BLIP-2 的 Q-Former 是 MLLM 连接视觉与 LLM 的常用结构（见第 02 章 MLLM 节）。

**论文**：CLIP (arXiv:2103.00020)；BLIP (arXiv:2201.12086)；BLIP-2 (arXiv:2301.12597)
**代码库**：[open_clip](https://github.com/mlfoundations/open_clip)、[transformers](https://github.com/huggingface/transformers)（BLIP/BLIP-2）

## 9. 原理 → 评测 checklist（面试可背）

把本章所有"评测视角"汇总成一张速查表：

| 模型 | 评测时必查的变量 |
|---|---|
| Transformer/LLM | chat template、解码参数、RoPE 外推、后端一致性 |
| BERT/embedding | 池化方式、MTEB 任务覆盖 |
| CNN/ResNet | ImageNet Top-1、作为 backbone 的一致性 |
| 检测(YOLO/RCNN) | IoU 阈值、mAP 计算口径 |
| GAN/VAE | 质量 vs 多样性、mode collapse |
| Diffusion | 步数/CFG/seed/采样器/分辨率 |
| DiT | 尺寸 scaling、视频时序一致性 |
| CLIP/BLIP | 模型版本、作为评测器的基准 |
