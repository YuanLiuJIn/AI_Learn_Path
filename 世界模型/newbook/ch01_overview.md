# Chapter 01：总览与核心思想

## 1.1 本系列要解决什么问题

学世界模型最典型的失败方式：一上来就读 DreamerV3 或 Sora，结果卡在三个地方——不知道"模型"在这里指什么、不知道"用模型"有哪几种方式、不知道论文里那些"看起来多余"的设计（KL 平衡、stop-gradient、短 rollout）到底在防什么。

本系列按 **基础概念 → 经典模型 → 相邻流派 → 对比融合** 的顺序，把这条线捋直。

## 1.2 世界模型是什么：三个核心能力

| 能力 | 含义 | 例子 |
|---|---|---|
| **预测未来** | 给定当前状态与动作，预测下一刻 | RSSM 的 $p(z_{t+1}\mid z_t,a_t)$ |
| **抽象表征** | 把高维观测压成低维、可用的内部状态 | VAE 编码、JEPA 嵌入 |
| **因果推理** | 理解"动作 → 后果"，而非仅相关 | 能区分"我推它"与"它自己动" |

三者中，**预测未来**是硬核心。数学上，世界模型学的是环境转移与奖励：

$$
p(s_{t+1}\mid s_t,a_t),\qquad p(r_t\mid s_t,a_t)
$$

注意它和策略 $\pi(a\mid s)$ 的分工：策略回答"该做什么"，世界模型回答"**如果我这么做，接下来会发生什么**"。

> 与 RL / 规划的关系：传统 model-free RL 直接试错，样本极贵；世界模型提供一台**便宜的模拟器**，让智能体在"梦里"大量练习，从而样本效率提升 10–100×。这就是全部动机。

## 1.3 三大流派对比

| | **MBRL / 潜在动力学** | **EBM / 扩散** | **JEPA / 表征预测** |
|---|---|---|---|
| 预测空间 | 隐状态 $z$ | 能量 / 像素分布 | 抽象表征 |
| 训练信号 | ELBO（重构+KL）+ 奖励 | 打分匹配 / 去噪 / 对比 | 表征间 L2 / 对比 |
| 代表 | PlaNet、Dreamer、MuZero | LeCun 2022、DIAMOND、Diffusion Forcing | I-JEPA、V-JEPA 2 |
| 优点 | 决策友好、样本高效 | 多模态、显式不确定性 | 不浪费容量在像素 |
| 缺点 | 压缩瓶颈、误差累积 | 采样慢、训练不稳 | 缺"可渲染性"、评估难 |
| 章节 | Ch02 | Ch03 | Ch04 |

一句话记忆：**MBRL 为了决策压缩世界，扩散为了渲染重建世界，JEPA 为了理解抽象世界。**

## 1.4 四条技术路线（更早的全局地图）

在三大流派之外，还有几条常被混淆的路线：

- **A. 潜在动力学 + RL**：PlaNet → DreamerV1/V2/V3、MuZero（本系列 Ch02 主线）
- **B. 表征预测式（JEPA）**：I-JEPA、V-JEPA 2（Ch04）
- **C. 生成式视频 / 交互环境**：Sora、Genie、GameNGen、Cosmos（Ch03、Ch05）
- **D. LLM 作为世界模型**：Othello-GPT、WebDreamer（Ch05 讨论）
