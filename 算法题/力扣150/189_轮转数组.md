# 189. 轮转数组（Rotate Array）

## 题目概述
给定整数数组 `nums`，将元素**向右轮转 k 个位置**（k 为非负数）。要求**原地**修改（进阶要求 O(1) 空间）。

示例：
- `nums = [1,2,3,4,5,6,7], k = 3` → `[5,6,7,1,2,3,4]`
- `nums = [-1,-100,3,99], k = 2` → `[3,99,-1,-100]`

性质：向右轮转 k 位，原下标 `i` 的元素去 `(i + k) % n`。

---

## 三个解法（进阶要求 ≥3 种）

### 解法一：额外数组（最直观，O(n) 空间）
新数组里直接放好每个元素的位置，再拷回：
```cpp
void rotate(vector<int>& nums, int k) {
    int n = nums.size();
    k %= n;                       // 关键：k 可能大于 n
    vector<int> tmp(n);
    for (int i = 0; i < n; i++)
        tmp[(i + k) % n] = nums[i];
    nums = tmp;
}
```
- 时间 O(n)，空间 O(n)。能过，但不符合进阶的 O(1) 原地要求。

### 解法二：三次反转（最优且优雅，O(1) 空间）★推荐
向右轮转 k 位 = 反转整个数组 → 反转前 k 个 → 反转后 n-k 个。
```
[1,2,3,4,5,6,7]  k=3
反转全部 → [7,6,5,4,3,2,1]
反转前3 → [5,6,7,4,3,2,1]
反转后4 → [5,6,7,1,2,3,4]  ✓
```
```cpp
void rotate(vector<int>& nums, int k) {
    int n = nums.size();
    k %= n;
    if (k == 0) return;
    reverse(nums.begin(), nums.begin() + k);
    reverse(nums.begin() + k, nums.end());
    reverse(nums.begin(), nums.end());
}
```
> 顺序提醒：先反转「前 k」和「后 n-k」两段，再反转「整体」。两段顺序可换，但整体反转必须最后（或最先，取决于约定）。本写法：先两段、再整体，等价于上面的推演（先整体、再两段），两种都对。
- 时间 O(n)，空间 O(1)（原地）。

### 解法三：环状替换 / 跳跃交换（O(1) 空间，理解略难）
把数组看成若干「环」，每个环上元素依次往后跳 k 步：
```cpp
void rotate(vector<int>& nums, int k) {
    int n = nums.size();
    k %= n;
    int count = 0;                 // 已就位元素总数
    for (int start = 0; count < n; start++) {
        int current = start;
        int prev = nums[start];
        do {
            int next = (current + k) % n;
            int temp = nums[next];
            nums[next] = prev;
            prev = temp;
            current = next;
            count++;
        } while (start != current);  // 回到环起点才换下一个环
    }
}
```
- 时间 O(n)，空间 O(1)。面试能讲清楚「为什么用环、count 怎么数」是加分项。

#### 核心思想（看懂这里就通了）
向右转 k 位 = 下标 `i` 的元素去 `(i+k)%n`。这是一个**置换**，可拆成 **gcd(n,k) 个互不相交的环**。沿每个环「接力」搬元素：从环起点 `start` 出发，把 `prev`（手里的待放值）放到 `next=(current+k)%n`，同时把 `next` 原值 `temp` 接过来当新 `prev` 继续跳，直到回到 `start`（本环结束），再处理下一个环。

#### 变量含义
| 变量 | 含义 |
|---|---|
| `prev` | 当前手里拿着、等待放下去的值 |
| `temp` | `next` 处原值，先存（马上被覆盖），变为下一个 `prev` |
| `current` | 当前所在下标 |
| `next` | `prev` 的目标下标 = `(current+k)%n` |
| `count` | 已就位元素总数；到 n 表示全部放完 |
| `do…while(start!=current)` | 回到环起点才结束本环 |

#### 完整推演：`nums=[1,2,3,4,5,6,7], k=3, n=7`（gcd=1，单环）
`start=0, prev=1`：
```
current  next  动作(把 prev 放入 next)         prev 接过的 temp   数组
  0       3     nums[3]=1, prev←原nums[3]=4    4     [1,2,3,1,5,6,7]
  3       6     nums[6]=4, prev←7              7     [1,2,3,1,5,6,4]
  6       2     nums[2]=7, prev←3              3     [1,2,7,1,5,6,4]
  2       5     nums[5]=3, prev←6              6     [1,2,7,1,5,3,4]
  5       1     nums[1]=6, prev←2              2     [1,6,7,1,5,3,4]
  1       4     nums[4]=2, prev←5              5     [1,6,7,1,2,3,4]
  4       0     nums[0]=5, prev←1             1     [5,6,7,1,2,3,4]
  current=0==start → 环结束
```
结果 `[5,6,7,1,2,3,4]` ✓（恰好右转 3 位）

#### 为什么需要外层 `for(start…)`（多环）
当 gcd(n,k)>1 时有**多个环**，单环只覆盖部分下标，必须换起点。如 `n=6,k=2`：gcd=2 → 2 环：
- 环1：`0→2→4→0`（覆盖 0,2,4）
- 环2：`1→3→5→1`（覆盖 1,3,5）
外层 `start` 从 0 走到 1（跳过已在环1处理的 2,4），`count` 累计到 6 停止。若只跑 `start=0` 会漏掉 1,3,5。

#### 一句话记忆
> 旋转 = 沿环接力搬元素：手里的值放到 `next`，把 `next` 原值接过来继续搬，回到起点换下一环；环数 = gcd(n,k)。

---

## 必须记住的知识点
| 点 | 说明 |
|---|---|
| **k 取模** | `k %= n` 必须先做！k 可能 > n（如 n=7,k=10 实际只转 3 位），不取模会越界或算错 |
| **原地 vs 额外数组** | 进阶要 O(1) 空间，解法二/三才是目标；解法一仅作起点 |
| **reverse 用法** | `std::reverse(begin, end)`，左闭右开，需 `<algorithm>` |
| **三次反转的对称性** | 「右转 k」=「整体反转 + 两段分别反转」，靠反转的对称性实现原地 |
| **环状替换的环数** | 环的个数 = gcd(n, k)，每个环长 = n/gcd，用 `count` 统计已放置元素避免重复 |

## 你的提交分析（2026-08-07）
```cpp
void rotate(vector<int>& nums, int k) {
    if(k<=0) { return; }
    reverse(nums.begin(),nums.end());
    reverse(nums.begin(),nums.begin()+k);   // 崩溃行
    reverse(nums.begin()+k,nums.end());
}
```
输入 `nums=[-1], k=2` → AddressSanitizer 报 `heap-buffer-overflow`（第 9 行 `swap` READ size 4）。

### 根因：没做 `k %= n`
- `n=1, k=2`，`if(k<=0)` 拦不住（2>0）。
- 第 8 行 `reverse(begin, end)`：n=1，只反转那一个元素，安全。
- 第 9 行 `reverse(begin, begin+2)`：`begin+2` 超出仅 1 个元素的数组（合法下标只有 0），`reverse` 内部 `swap` 读到下标 1 → 越界。所以崩在第 9 行而非第 8 行。

### 修复
```cpp
void rotate(vector<int>& nums, int k) {
    int n = nums.size();
    k %= n;                 // 关键：k 可能大于 n，先取模
    if (k == 0) return;     // 取模后为 0 直接返回（不写也安全，空区间 reverse 是 no-op）
    reverse(nums.begin(), nums.end());
    reverse(nums.begin(), nums.begin() + k);
    reverse(nums.begin() + k, nums.end());
}
```
- 本例 `2%1=0` → return，`[-1]` 不变，正确。
- `k%=n` 后 `k∈[0,n-1]`，`begin+k` 永远 ≤ `end`，不再越界。

### 记住
> 凡是用到 `k` 当下标/区间边界的轮转题，**第一行必须 `k %= n`**，否则 k>n 就越界。这是本题最高频的坑。

## 你的提交分析 2（2026-08-07，修正越界后重交）
```cpp
void rotate(vector<int>& nums, int k) {
    if(k<=0||k>nums.size()) { return; }   // ① 错：用「k>n 就返回」代替取模
    reverse(nums.begin(),nums.end());
    reverse(nums.begin(),nums.begin()+k);
    reverse(nums.begin()+k,nums.end());
}
```
输入 `nums=[1,2], k=7` → 输出 `[1,2]`，预期 `[2,1]`。

### 根因：`k>nums.size()` return 把合法轮转丢弃了
- `n=2, k=7`，`k>nums.size()` 成立 → 直接 return，啥也没做 → `[1,2]` 错。
- 转 7 位、数组长 2，转 2 位回到原样，故**转 7 位 ≡ 转 1 位（7%2=1）**。`k>n` 不是非法，而是「多转几圈」，应**取模折叠**而非丢弃。

### 修复
```cpp
void rotate(vector<int>& nums, int k) {
    int n = nums.size();
    k %= n;                 // 折叠回 [0, n-1]，k>n 也照常处理
    if (k == 0) return;
    reverse(nums.begin(), nums.end());
    reverse(nums.begin(), nums.begin() + k);
    reverse(nums.begin() + k, nums.end());
}
```
- 本例 `7%2=1` → 转 1 位 → `[2,1]` ✅
- `k%=n` 后 `k∈[0,n-1]`，`begin+k` 永远 ≤ `end`，越界与漏算同时解决。

### 两次提交对照
| 提交 | 写法 | 后果 |
|---|---|---|
| 1 | 缺 `k%=n` | `nums=[-1],k=2` 时 `begin+2` 越界崩溃 |
| 2 | `k>nums.size() return` | `nums=[1,2],k=7` 被错误丢弃，输出原数组 |
| 正解 | `k %= n` | 既越界不崩，又 k>n 正确折叠 |
