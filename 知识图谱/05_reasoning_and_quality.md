# 05. 知识推理与图谱质量评估

> 目标：理解知识图谱如何从已有事实推出新事实，以及如何评估图谱质量。

## 1. 什么是知识推理？

知识图谱里有显式知识：

```text
(张三)-[父亲]->(李四)
(李四)-[父亲]->(王五)
```

推理可以得到隐式知识：

```text
(张三)-[祖父]->(王五)
```

一句话：

> 推理就是根据已有实体、关系、规则和本体约束，推出图中没有直接写出的新知识。

## 2. 规则推理

规则推理用 if-then 规则。

例如：

```text
IF (A)-[父亲]->(B)
THEN (B)-[孩子]->(A)
```

```text
IF (A)-[位于]->(B) AND (B)-[位于]->(C)
THEN (A)-[位于]->(C)
```

规则推理适合：

```text
明确业务规则
关系可解释
需要高精度
```

缺点：

```text
规则需要人工设计
覆盖率有限
规则冲突需要处理
```

## 3. 本体推理

本体推理基于类层级和语义约束。

例如：

```text
外科医生 是 医生 的子类
医生 是 职业 的子类
张三 是 外科医生
```

可以推出：

```text
张三 是 医生
张三 是 职业相关实体
```

常见本体关系：

```text
subClassOf：子类关系
subPropertyOf：子属性关系
domain：关系主语类型约束
range：关系宾语类型约束
equivalentClass：等价类
disjointWith：互斥类
```

## 4. 路径推理

路径推理关注多跳关系链路。

例如金融风险：

```text
公司 A → 投资 → 公司 B
公司 B → 控制 → 公司 C
公司 C → 涉及风险事件 → 事件 E
```

可以判断：

```text
公司 A 可能间接暴露于事件 E 的风险。
```

路径推理适合：

```text
风控
推荐理由
因果链分析
供应链分析
科研知识发现
```

## 5. 链接预测

链接预测是判断图中缺失的边。

已知：

```text
(药物A)-[治疗]->(疾病X)
(药物A)-[相似药物]->(药物B)
```

模型可能预测：

```text
(药物B)-[可能治疗]->(疾病X)
```

常见方法：

```text
规则和路径特征
知识图谱嵌入
图神经网络
LLM 辅助判断
```

## 6. 约束校验

推理不只是“推出新知识”，也可以发现错误。

例如 Schema 约束：

```text
TREATS 的主语必须是 Drug，宾语必须是 Disease。
```

如果图中出现：

```text
(张三)-[TREATS]->(感冒)
```

就可能是错误，因为张三不是 Drug。

常见约束：

```text
类型约束
关系方向约束
唯一性约束
取值范围约束
互斥约束
时间一致性约束
```

## 7. 图谱质量为什么重要？

低质量图谱会导致：

```text
问答错误
推荐不可信
推理链错误
GraphRAG 引用错误
实体重复导致统计失真
关系方向错误导致路径错误
```

知识图谱系统的质量上限，往往不是模型决定的，而是数据质量决定的。

## 8. 图谱质量指标

### 8.1 准确性 Accuracy

知识是否正确。

```text
(巴黎)-[所属国家]->(法国)  正确
(巴黎)-[所属国家]->(德国)  错误
```

### 8.2 完整性 Completeness

重要知识是否覆盖。

```text
疾病是否覆盖主要症状？
公司是否覆盖主要股权关系？
论文是否覆盖引用关系？
```

### 8.3 一致性 Consistency

是否违反约束。

```text
一个人出生日期晚于死亡日期 → 不一致
某实体同时是“药物”和“疾病”，若本体规定互斥 → 不一致
```

### 8.4 唯一性 Uniqueness

是否有重复实体。

```text
北京大学、北大、Peking University 是否被拆成多个节点？
```

### 8.5 时效性 Timeliness

知识是否过期。

```text
公司高管、药品说明、政策法规、价格信息都可能变化。
```

### 8.6 可追溯性 Provenance

每条知识是否有来源。

```text
来源文档
抽取时间
抽取模型
置信度
人工审核状态
```

## 9. 图谱质量控制方法

```text
Schema 约束
规则校验
实体对齐
人工抽检
多来源交叉验证
置信度评分
冲突检测
版本管理
来源追踪
```

## 10. 一句话总结

> 知识推理让图谱不仅能存储已有事实，还能根据规则、本体和路径推出隐式知识；质量评估则保证这些知识可靠、可追溯、可维护。高质量知识图谱必须同时关注准确性、完整性、一致性、唯一性、时效性和来源可信度。
