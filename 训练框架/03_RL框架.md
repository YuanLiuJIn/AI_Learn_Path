# RL 训练框架（RLHF / GRPO / Agent RL）

> 这层用"奖励信号"进一步改模型行为，比 SFT 更强也更难。
> 接你 `AgentRl/` 专题：PPO/GRPO、Critic、多轮 Agent RL 都在这里落地。
> 关键区别：**PPO 需要 Critic（Value 模型），GRPO 去掉 Critic 用组内均值当 baseline**。

---

## 1. TRL（HuggingFace 官方）

### 特点

```text
- HuggingFace 官方，SFT / DPO / PPO / GRPO 全覆盖
- API 友好，教学和研究首选
- 适合：入门 RL、快速验证想法（你的 GRPO 第一步）
```

### 安装

```bash
pip install trl
# 通常需要 transformers / datasets / accelerate
pip install "trl[torch]"
```

### 最小可运行示例：GRPO

```python
from trl import GRPOConfig, GRPOTrainer
from datasets import load_dataset

# 奖励函数：回答里包含 "JSON" 就给正分（示意）
def reward_contains_json(completions, **kwargs):
    return [1.0 if "JSON" in c[0]["content"] else -1.0 for c in completions]

dataset = load_dataset("json", data_files="prompts.jsonl")["train"]

trainer = GRPOTrainer(
    model="Qwen/Qwen2.5-7B-Instruct",
    reward_funcs=reward_contains_json,
    train_dataset=dataset,
    args=GRPOConfig(
        output_dir="grpo_out",
        num_generations=4,      # 每组采样 4 个回答当 baseline
        max_completion_length=256,
        per_device_train_batch_size=4,
        learning_rate=1e-6,
        bf16=True,
    ),
)
trainer.train()
```

> GRPO 不需要单独 Critic 模型：同一 prompt 采样 num_generations 个回答，
> 用这组回答奖励的均值/标准差算 Advantage。这正是你 AgentRL 里学的核心。

### 最小可运行示例：DPO（无 Reward Model）

```python
from trl import DPOConfig, DPOTrainer

trainer = DPOTrainer(
    model="Qwen/Qwen2.5-7B-Instruct",
    train_dataset=load_dataset("json", data_files="prefs.jsonl")["train"],
    args=DPOConfig(output_dir="dpo_out", per_device_train_batch_size=4, bf16=True),
)
trainer.train()
```

## 2. veRL（ByteDance，混合控制器）

### 特点

```text
- 全称 HybridFlow，把 RL 拆成"生成（rollout）"和"训练（train）"两张计算图
- 生成侧可接 vLLM / SGLang，训练侧接 FSDP / Megatron
- 灵活度极高，尤其适合多模态 RL 和 Agent RL
- 适合：想做严肃多轮 Agent RL（你的 UE5 Agent 方向）
```

### 安装

```bash
pip install verl
# 或源码安装（推荐，方便看例子）
git clone https://github.com/volcengine/verl
cd verl
pip install -e ".[torch]"
```

### 最小可运行示例（GRPO，命令行）

```bash
# veRL 用 yaml 配置驱动主流程
python3 -m verl.trainer.main_ppo \
    data.train_files=gs_dataset \
    actor_rollout_ref.model.path=Qwen/Qwen2.5-7B-Instruct \
    actor_rollout_ref.rollout.name=vllm \
    actor_rollout_ref.rollout.n=4 \
    algorithm.adv_estimator=grpo \
    trainer.n_gpus_per_node=8 \
    trainer.total_epochs=1
```

> 真实使用建议从官方 `examples/ppo_trainer/` 里的 Qwen GRPO 配置改起，
> 把 reward 函数换成"测试用例 JSON 是否合法可执行"。

## 3. OpenRLHF

### 特点

```text
- 基于 Ray 分布式 + vLLM 推理，工程成熟
- 支持 PPO / GRPO / DPO，可训到 70B 级
- 适合：中大规模 RLHF，想少踩工程坑
```

### 安装

```bash
pip install openrlhf
# 需要 ray + vllm
pip install ray vllm
```

### 最小可运行示例（PPO）

```bash
# 用 Ray 启动 PPO（示意，参数来自官方 example）
ray start --head
openrlhf.cli.train_ppo_ray \
    --pretrain Qwen/Qwen2.5-7B-Instruct \
    --reward_pretrain Qwen/Qwen2.5-7B-Instruct \
    --dataset my_rlhf_dataset \
    --save_path output/rlhf \
    --micro_train_batch_size 4 \
    --train_batch_size 128 \
    --zero_stage 3 \
    --bf16
```

## 4. Slime

### 特点

```text
- 极简单控制器（single-controller）设计，代码清晰好读
- 适合：想真正读懂 RL 训练代码、自己改算法的人
- 适合：研究型学习（不是生产首选）
```

### 安装

```bash
git clone https://github.com/THUDM/slime
cd slime
pip install -e .
```

### 最小可运行示例

```bash
# Slime 用 bash 脚本驱动，例子在 examples/
bash examples/run_qwen.sh
# 脚本内部设置：模型路径、reward 脚本、rollout 配置、GRPO 参数
```

> 读 `examples/run_qwen.sh` 和 `slime/` 核心代码，能直观看到
> rollout → reward → advantage → actor update 的完整数据流。

## 5. AReaL（异步 Agent RL）

### 特点

```text
- 专为多轮 Agent RL 设计，异步推理提升吞吐
- 解决"多轮交互 + 长轨迹"导致 RL 训练极慢的问题
- 适合：你的 UE5 测试 Agent 这种"多轮生成 JSON + 环境返回状态"的场景
```

### 安装

```bash
git clone https://github.com/inclusionAI/AReaL
cd AReaL
pip install -e ".[dev]"
```

### 最小可运行示例

```bash
# 以官方 agent 示例为模板，把环境和 reward 换成你的测试执行器
bash examples/math/run_real.sh
# 关键配置：
#   max_turns        = 多轮上限
#   reward_fn        = 环境返回的最终奖励
#   rollout_backend  = 异步推理后端
```

## 6. 五者怎么选

| 维度 | TRL | veRL | OpenRLHF | Slime | AReaL |
|---|---|---|---|---|---|
| 定位 | 官方通用 | 混合控制器 | Ray 工程派 | 极简可读 | 异步 Agent |
| Critic | PPO 有/GRPO 无 | 同左 | 同左 | 同左 | 同左 |
| 规模 | 小~中 | 大 | 大 | 小~中 | 中~大 |
| 代码可读性 | 中 | 中 | 中 | 高 | 中 |
| 你用得到 | RL 入门 | Agent/多模态 RL | 中大规模 RLHF | 读源码学 | UE5 Agent RL |

---

## 一句话总结

> RL 框架用奖励改模型；GRPO 去掉 Critic 后训练更稳、更适合 Agent。
> 入门用 **TRL** 跑通 GRPO，想读懂原理看 **Slime**，做严肃多轮 Agent RL 上 **veRL / AReaL**——
> 你的 UE5 测试 Agent（多轮生成 JSON + UE 返回状态）正好是 AReaL 的天然场景。
