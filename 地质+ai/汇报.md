# Part 1 综述：我理解的"地质 + AI"

## 1.1 我的理解：地质 + AI 的本质是"稀疏观测下的反问题 + 可计算推断"

我对地质 + AI 的理解，可以压缩成四句话：

**第一，地质学的任务形态天生就是 AI 的战场。**
地质学面对的不是"图片里有几只猫"，而是：地表观测（遥感、地球化学、露头）+ 极稀疏的地下观测（钻孔、地震、重磁电）+ 强烈的时间压缩（亿年尺度用米级露头去推断）。这本质上是一个**观测极度稀疏、采样严重有偏、多尺度强耦合的反问题**。从这一角度看，Bergen et al., 2019（*Science*, "Machine learning for data-driven discovery in solid Earth geoscience"）把固体地球科学的 ML 机会定位得非常准：**地质数据天然是高维、非平稳、异构的，而地质推断天然是概率性的**——这恰是 ML 的主场，不是它的例外情形。

**第二，它对 AI 的真实需求不是"替代解释员"，而是三件事。**
1. **高维多源非线性融合**：岩性 + 构造 + 化探 + 遥感 + 重磁 + DEM 十几个图层如何联合决策，人力难以给出闭式规则（矿产远景预测 MPM 就是典型）。
2. **从海量无标注观测中学出可迁移表征**：一年的卫星影像、连续台站波形，绝大多数没有标签，自监督/基础模型正是为这种"数据多、标签少"的格局设计的（`近期研究/N8`、`综述/R9`）。
3. **把正演—反演—决策做成可微闭环**：传统反演（FWI、大地电磁、地统计模拟）迭代昂贵且有强非唯一性；一旦正演算子可微（Deepwave / PyLops / Devito），网络可以当代理模型、可以作先验、可以反传梯度（`近期研究/N4`、Schuster & Feng, 2024 PIML综述）。

   > **这句话的术语翻译（被问到时照此解释）**：**正演**＝给定地下模型 $m$ 算出观测 $d=F(m)$（如给定断层几何与物性，算重力/地震响应）；**反演**＝由观测反推模型 $\hat m=\arg\min\|F(m)-d\|$（解不唯一）；**决策**＝由 $\hat m$ 决定"下一步干什么"（布孔、开采方案、封存选址、风险分级）。**可微**＝三个环节处在同一张可求导的计算图里，于是**决策目标对观测方案与模型参数的梯度可以一路回传**；**闭环**＝梯度回流去改进反演先验、改进观测设计（主动采样）、甚至改进正演算子本身，而不是"正演→反演→决策→结束"的单向流水线。**价值一句话**：让地质模型从"只会算题/被动预测"变成"能对目标求导、可优化干预"。

**第三，也是最容易被忽视的一点：地质 AI 的瓶颈从来不在"模型够不够大"。**
学习路线里那句最重的原则，我在这里复述，因为它几乎决定了这一领域所有工作的成败：

> **地质 AI 的难点常常不是"模型够不够大"，而是空间泄漏、标签偏差、尺度不一致、物理不合理和外推失败。**

这五个词，每一个都对应着一批"指标很好但地质上一文不值"的论文。换句话说，在地质领域，**验证设计比网络结构重要，采样设计比优化器重要**。

**第四，它的正确定位必须是 AI4S，而不是 AI application。**
如果只是"用 UNet 做一次岩性分割"，它是 CV 的应用题；只有当 AI 的产出是**一条可被野外、钻探、物理实验或独立数据集证伪的地质认识**时，它才是 AI4S。这个区分直接决定了 Part 2 要讲的全部差异。

# Part 2 地质 + AI 的 AI4S 范式，与传统人工智能研究有什么不同？

一句话概括：**传统 AI 追求"在固定数据分布上的泛化分数"，地质 AI4S 追求"在物理约束下对未知地区的、可证伪的、有不确定性的推断"。**前者可以不问因，后者必须问因。

下面按 **数据 → 训练 → 评测** 三段拆开，每段结合实证论文。

## 2.1 数据：从"标注好的 i.i.d. 数据集"到"有偏、多尺度、无负样本的科学观测"

| 维度 | 传统人工智能 | 地质 + AI（AI4S） | 证据 / 论文依据 |
|---|---|---|---|
| 数据来源 | 网络爬取的大规模众包标注（ImageNet、COCO），i.i.d. 假设基本成立 | **仪器与野外观测**，获取成本极高（一口井、一次地震采集可达百万级），且**采样位置由道路、矿区、经费决定 → 系统性有偏** | 学习路线 §3.3"数据集卡片"要求必须记录偏差与采样年代 |
| 标签性质 | 客观、一致、可复核（"这是猫"） | **解释性标签**：同一条地震剖面不同解释员断层画法不同；地质图比例尺不同语义不同；年代、矿床类型依赖专家判断 | 这与 `近期研究/N8` 所呼吁的标准化评测同源 |
| 负样本 | 天然存在且大量 | **常常根本不存在**。矿产远景预测里"没发现矿"≠"没有矿"，只是没勘探/没暴露 | `近期研究/N7` DEEP-SEAM v1.0 明确走 **PU/半监督异常检测** 路线以避免伪负样本 |
| 样本平衡 | 数据量大、类相对平衡 | **极端不平衡**：矿点/滑坡/强震都是稀有事件（矿床在万级像元中占个位数量级） | `近期研究/N6` 在伊朗 Dehaq 铅锌矿区专门比较 SMOTE 与三种调参策略 |
| 空间 i.i.d. | 成立（图片之间无关联） | **完全不成立**：托布勒地理学第一定律，邻近样本高度自相关；同剖面相邻 patch 几乎重复 | 学习路线"10 大错误"第 1 条：随机切分导致分数虚高 |
| 模态与尺度 | 多为单一 RGB | **多模态多尺度异构**：Sentinel 10 m / Landsat 30 m / 地球化学点 / 1 m LiDAR / 米级岩芯 / 秒级波形，必须统一到同一空间网格 | 学习路线 §3.2：找矿项目要把地质图、构造、化探、遥感、重磁统一到同一网格并记录每层尺度和年代 |
| 增广 | 翻转、旋转、裁剪即有效 | **不能随意做**：地层有上下、方位角有产状意义、NE-SW 翻转改变构造语境；地震道翻转违反波场物理 | 这一点是"CV 直觉"最容易翻车的地方 |

**结论**：地质 AI 的第一性工作不是选模型，而是**建立数据集卡片与采样/切分协议**。做得好坏，直接决定后面所有指标的可信度。

## 2.2 训练：从"随机划分 + 堆参数"到"按地质单元划分 + 物理约束"

| 环节 | 传统 AI 做法 | 地质 AI4S 必须/正在做的 | 论文依据 |
|---|---|---|---|
| 训练/测试划分 | 随机 shuffle split | **空间分块 CV / leave-location-out / 按井切分 / 跨地质结构测试** | 学习路线 §9.1；`GeoFWI`（JGR:MLC, 2026-03）与 OpenFWI 强调"跨结构泛化" |
| 预处理泄漏 | 全量标准化即可 | 标准化、重采样、PCA 必须先 fit 在训练集，否则把测试区统计信息灌输给模型 | 学习路线"10 大错误"第 6 条 |
| 基线 | 直接上 SOTA 大模型 | **必须先有 RF/XGBoost/线性模型基线**，再谈深度学习 | 学习路线 §1.2 优先级 + 典型 RF-XGBoost 仍占方法维度 19.3% |
| 损失函数 | 交叉熵 / MSE | **数据项 + 物理残差项**（PDE 残差、波动方程、质量守恒）+ 不确定性校准 | PINN/ SciML 占 5.9%；`Ambient Noise FWI with Neural Operators`（JGR Solid Earth, 2025-10） |
| 标签效率 | 大数据监督 | **自监督预训练 + 冻结骨干 + 少量标签探测/微调**（ freeze & probe） | `近期研究/N2`：冻结约 97% decoder-only TCN，仅微调回归头实现跨实验构型预测实验室地震 |
| 先验注入 | 很少 | 把地质知识写进输入、结构与目标（波长自适应、尺度金字塔、时间/光谱编码） | `感知型基础模型速查表` 方向 1/2/4；DOFA（TPAMI 2025） |

**特别值得强调的一点（来自速查表的"真相提醒"）**：GraphCast、Pangu-Weather 这类模型常被描述为"物理的"，但它们的物理性来自**训练数据**（再分析场是数值模式的产物），而不是损失函数；**真正把物理写进目标的只有 NeuralGCM、PINN 这一支**。这条区分在地质领域更尖锐——因为地质数据的"物理来源"远不如再分析场干净。

## 2.3 评测：从"Accuracy/AUC"到"空间外推 + 物理一致性 + 不确定性 + 概率可靠性"

| 任务 | 传统 AI 指标 | 地质 AI4S 必须追加的指标 |
|---|---|---|
| 分类 | F1 / ROC-AUC / PR-AUC | 空间独立测试区、按地层/岩区分组表现、校准曲线 |
| 分割 | IoU / Dice | **边界误差**、对象级指标、跨传感器/跨地貌区表现 |
| 回归 | MAE / RMSE / R² | **空间残差图**、外推区误差、预测区间覆盖率 |
| 找矿远景 | PR-AUC / top-k capture | **面积—命中率曲线**、盲区测试、已知矿床留出 |
| 反演 | L1/L2 / SSIM | **物理一致性**、跨地质结构泛化、数据重建残差 |
| 基础模型 | 下游任务指标 | 冻结/微调成本、**少样本曲线**、跨区泛化 |
| 预报 | RMSE | **概率可靠性 + 告警式（alarm-based）评分** |

最典型的例子是地震预报：光给 RMSE 毫无意义。`近期研究/N9`（arXiv 2603.03079）对一个 b 值驱动的深度学习地震预报模型做了**概率 + 告警式双重评估**，结论是"b 值时空变化包含有限但持续的预报信号"——这个结论之所以可信，恰恰因为它用了 Molchan 式的告警评分而不是单一数值精度。

同样，`近期研究/N1`（Nature Communications, 2025）预测米尺度实验室地震时，除了 ML 预测的破坏时间，还**用速率—状态摩擦数值模型去解释模型到底追踪了什么**（蠕滑区剪应力演化）——这就是 AI4S 与传统 AI 评测观的分水岭：**不仅要准，还要知道它为什么准，准在哪个物理量上。**

> **小结 Part 2**：传统 AI 的闭环是 `数据 → 模型 → benchmark 分数`；地质 AI4S 的闭环是 `科学假设 → 受控采样 → 空间/物理双约束训练 → 独立地质证据检验 → 不确定性下的地质决策`。多出来的每一步，都是地质 AI 论文真正的价值所在，也正是它们的审稿难点。

| ③ | **地震监测、震源参数与地震学 AI** | 波形是天然海量无标注数据 → 相位拾取/事件检测/目录构建是"地学最成功的 AI 落地" | R4、R7、`近期研究/N1/N2/N3/N9` | 295 篇 **14.1%** |
| ④ | **地质灾害易发性与风险评价** | 表格型空间数据 + 树模型 → 概率图；核心难点是**正样本定义与空间泛化** | R1 | 290 篇 **13.8%** |
| ⑤ | **地球动力学、深部结构与行星/固体地球模拟** | 用 ML 替代昂贵正演、做代理模型、从地震波/地磁反演深部结构 | Bergen 2019、R1 | 221 篇 **10.5%** |
| ⑥ | **矿产资源勘查与成矿预测（含地球化学异常）** | **PU 学习 / 异常检测**：已知矿床极少，"未知"≠"负样本"；多源证据加权融合 | R3、R6、`近期研究/N6/N7` | 146 篇 **7.0%** |
| ⑦ | **地震勘探 / 测井 / 储层智能处理与反演** | 成像—反演作为逆问题，用 CNN/Transformer/神经算子做数据驱动映射或直接加物理约束 | R2、`近期研究/N4`、OpenFWI | 97 篇 **4.6%** |
| ⑧ | **地表过程、地貌演化与第四纪/沉积环境** | 时序遥感 + 地貌计量学 + 因果/过程模型 | R1 | 93 篇 **4.4%** |
| ⑨ | **地球化学分析、同位素与矿物学大数据** | 高维成分数据的判别、配分、源区识别，偏"表格 ML + 可解释" | R6 | 86 篇 **4.1%** |
| ⑩ | **岩石力学、工程地质与岩土智能建模** | 小样本力学实验 → 本构替代 + 位移/变形预测 | R1、R7 | 72 篇 **3.4%** |
| ⑪ | **通用模型 · A 语言知识型**（地质 LLM：GeoGPT / 元古 / OneStrata / 葱岭·智寻） | 把地学文献与图件知识压进语言模型，做检索、问答、抽取与编排；**不产生地质预测** | R1、*The Innovation Reviews* 2026-09 | ⑪⑫⑬ 合计 87 篇 **4.1%**（全样本 **9.5%**） |
| ⑫ | **通用模型 · B 感知表征型**（Earth Foundation Model：DOFA / Prithvi-EO-2.0 / TerraMind / Clay / Aurora） | 大规模自监督预训练得到统一表征，冻结迁移到下游；**目前唯一被实验证据支持的"通用"** | `近期研究/N8`、R9 | 同上（占其中大头） |
| ⑬ | **通用模型 · C 业务系统型**（AI-GeoMapping / AI-OreSeeking / GeoMap-Agent / Destination Earth / Autonomous GIS） | 把 A、B 与数值模拟串成工作流，做流程编排与人机协同 | 附录 ⑧、R1 | 同上（多为工程发布，部分不入期刊统计） |

> **⑪⑫⑬ 的说明**：这三类**不是三个并列的应用方向，而是原"方向 F（地学基础模型 / 多模态 / 大模型，4.1%）"内部的三种东西**——把它们并进同一张表，是为了避免把"懂地质的搜索写作工具""可迁移的遥感表征""流程编排平台"混为一谈。展开讨论见 **3.4**。

### （3）横切的方法范式（非互斥统计，n = 2,099）

| 方法 | 篇数 | 占比 | 说明 |
|---|---|---|---|
| 深度学习（CNN/GNN/U-Net/Transformer） | 970 | **46.2%** | 已成默认工具，不再是创新点 |
| 传统机器学习（RF/XGBoost/SVM/集成） | 406 | **19.3%** | 表格型、小样本主力，**永远要有 baseline** |
| 可解释 AI 与不确定性量化（SHAP/XAI/UQ） | 359 | **17.1%** | 几乎追平传统 ML，是地质界的"刚需" |
| 多源数据融合与联合反演 | 165 | 7.9% | 地学特有 |
| 自监督 / 弱监督 / 小样本 / 迁移 | 150 | 7.1% | 地质标签稀缺的必然出路 |
| 物理信息神经网络 / 科学机器学习 | 124 | **5.9%** | 高天花板，尚在小众增长期 |
| 地质大模型 / 多模态 / LLM | 87 | **4.1%** | 全样本 9.5%，说明**仍集中在方法刊，向地质业务渗透未完成** |
| 生成式（扩散 / GAN / 地统计模拟） | 75 | 3.6% | 主要用于增广与不确定性抽样 |

> **一个关键判断**：**大模型类在全样本（含方法类与综合顶刊）占 9.5%，在地质主体子集只有 4.1%**。这意味着"地质大模型"目前主要还是**计算机 / 方法学者的成果出口**，还不是地质学家的日常工具——既是现状，也是最大的机会窗口。三种类型的相应对照与时间线见 **3.4**。

## 3.2 各方向在解决什么问题、创新点在哪、还卡在哪（每类附 2 篇文献）

> 这一节替代原来的"哪些方向热、哪些方向好出论文"。**热度不是机会，热度是竞争强度**；真正决定一篇工作价值的是：它是否在解决一个真问题、它的创新是否可被复用、它留下的坑是否正好是你有资源去填的。以下按方向给出这三件事，并在每类末尾列 2 篇可直接引用的文献（占比为地质主体子集 n = 2,099 的全样本口径，见 3.1 的口径说明）。

**① 水文地质、地下水与环境地球化学 AI（20.9%）**
- **在解决什么**：观测极稀疏条件下，如何把地下水流与溶质运移方程、边界条件与稀疏水头/水质观测放在同一个可求导框架里，并对"能不能用于决策"给出带覆盖率的区间。
- **创新点**：① 从"每个参数组合重训一个 PINN"走向**元学习 / 预训练 PINN**（GPT-PINN 系列），把重复训练成本一次性摊掉；② 不确定性从启发式误差棒转向**有统计保证的共形预测区间**；③ 把守恒性、边界条件写进损失而非事后检查。
- **还卡在哪**：物理项与数据项的权重平衡仍靠调参；**外推区实验普遍缺失**（只在训练分布内比较就宣称"物理可靠"）；共形预测只保证**边际覆盖**，空间/时间分布漂移一旦破坏交换性假设，名义覆盖率就失真。
- **可引文献**：*Physics-informed neural networks enhanced by data augmentation: robust soil moisture estimation*（**J. Hydrology**, 2025-12）；*Uncertainty quantification of surrogate models using conformal prediction*（**ML: Science and Technology**, 2026-02）。

**② 地质遥感解译、岩性识别与智能地质填图（15.2%）**
- **在解决什么**：把"地表观测 → 岩性—构造语义"这一步做可靠，并让它能迁移到没有标签的新图幅、新地貌区。
- **创新点**：① 创新重心从"换骨干再刷 IoU"转向**样本生成**（MLS3 一类高质量光谱样本选择）——判断"瓶颈在标注不在网络"本身是正确的问题意识；② 把**因果推断 / 图注意力 / 对比学习**引入，针对"换井换区就失效"这一泛化病根；③ 显式处理采样点的空间依赖。
- **还卡在哪**：标签**同源于地质图**，存在"用图件验证图件"的循环风险；跨航带、跨季节、跨构造单元验证几乎缺位；**深度是这一类方法的天然边界**（地下没有地表光谱）。
- **可引文献**：*MLS3 机载 TASI 高光谱岩性填图样本生成*（**Remote Sensing**, 2024，甘肃北柳园）；*Interpretable regional-scale geological mapping using a contrastive graph attention network*（**Engineering Geology**, 2026-02）。

**③ 地震监测、震源参数与地震学 AI（14.1%）**
- **在解决什么**：① 海量连续波形的**检测—拾取—关联—定位**流水线自动化（这是全地学最成功的 AI 落地）；② 更难的追问——"AI 到底能不能预报"。
- **创新点**：① 从单任务检测走向**生成式基础模型统一预处理**（去噪、插值、低频外推一个模型包揽，扩散模型的概率本质自带 UQ）；② 评估范式本身成为贡献——把"能不能报"拉回"报得值不值"（**概率 + 告警式指标**、误报代价）；③ DAS 从"事后分析"推进到"在线监测"。
- **还卡在哪**：**实验室尺度 → 天然断层的尺度外推**是最强也最脆弱的一环；b 值预报结论只是"有限但持续"的弱信号，经不起多重检验；实时处理的误报代价在摘要层面未量化。
- **可引文献**：*A Generative Foundation Model for an All-in-One Seismic Processing Framework*（**Surveys in Geophysics**, 2025-11）；*b 值驱动深度学习地震预报的概率与告警式评估*（**arXiv** 2026，本地 `近期研究/N9`）。

**④ 地质灾害易发性与风险评价（13.8%）**
- **在解决什么**：从"灾后识别"转向"**灾前潜在识别**"，并把易发性图从"高/低二分"升级为"带可信度、阈值有依据"的决策依据。
- **创新点**：① **把"能不能迁"前置为"该不该迁"**——先做源域—目标域区域相似性评估，再做物理引导迁移；② **不确定性感知集成 + 动态阈值优化**，同时针对预测不确定性与分级阈值主观性两个真问题；③ 引入 InSAR / LiDAR 作为最有信息量的补充数据源。
- **还卡在哪**：灾害编录完整度直接决定上限；**相似 ≠ 可迁移**（编录口径与标签定义差异同样致命）；若拿不出校准曲线/覆盖率，"不确定性感知"容易沦为把集成方差当不确定性。
- **可引文献**：*Review article: Deep learning for potential landslide identification: data, models, applications, challenges*（**NHESS**, 2026-01）；*Uncertainty-aware ensemble learning and dynamic threshold optimization for landslide susceptibility mapping*（**Computers & Geosciences**, 2026-01）。

**⑤ 地球动力学、深部结构与行星 / 固体地球模拟（10.5%）**
- **在解决什么**：用代理模型替代昂贵的数值正演（地幔对流、动力学模拟），以及从地震层析、地磁重力场反演深部结构。
- **创新点**：把**贝叶斯反演 + 集合方法**与神经网络代理结合，用多物理场耦合约束先验；离"AI 方法"最远、离"地质科学问题"最近。
- **还卡在哪**：**代理模型在参数空间边缘极易失效，而地球动力学恰恰关心边缘（极端状态）**；本方向的代表论文在本地清单中**未单列**，说明 AI 渗透仍以方法迁移为主，尚未形成独立方法论脉络。
- **可引文献**：Bergen et al., 2019, *Machine learning for data-driven discovery in solid Earth geoscience*（**Science**）；R1（*The Innovation*，地球系统科学 AI 总论框架）。（本方向本地清单未单列代表论文，此为可引的相邻锚点。）

**⑥ 矿产资源勘查与成矿预测（含地球化学异常，7.0%）**
- **在解决什么**：在"已知矿床极少、未知区不等于无矿"的前提下，做出可用于圈定找矿靶区的矿化概率图。
- **创新点**：① **PU 学习 / 半监督异常检测**（少量正样本 + 大量未标注），从根上绕开伪负样本；② **把可解释做进流程**——SHAP 直接输出各勘查图层贡献度，方法在 GMD 这类模型发展刊上可复现；③ **无标签路线**（度量学习改造 VAE 潜空间）刚被打开；④ 多模态 LLM 做勘查数据整合开始出现。
- **还卡在哪**：无监督方法**没有客观真值**、异常阈值高度任意，"异常 = 矿"这一前提本身可疑；未标注/负样本的构造规则仍靠人工设定；多为单一成矿省验证；SMOTE 在空间数据上会生成破坏空间结构的伪样本；**空间自相关导致的信息泄漏难以排除**。
- **可引文献**：`近期研究/N7` *DEEP-SEAM v1.0*（**GMD**, 2026，半监督 DevNet + SHAP，南澳 Curnamona REE）；*A metric-learning enhanced VAE for unsupervised detection of geochemical anomalies*（**Ore Geology Reviews**, 2025-12，新疆哈图金矿带）。

**⑦ 地震勘探 / 测井 / 储层智能处理与反演（4.6%）**
- **在解决什么**：成像—反演这类**强不适定、非唯一性极强**的逆问题：如何降低正演成本、如何表达后验分布而不是给一个没有科学意义的最优解。
- **创新点**：① 用**神经算子替代波动方程正演**（快若干数量级），用自动微分替代伴随状态法，并借优化器缓解周期跳跃；② 把"为什么 X 比 Y 好"落在架构消融上（MLP → KAN 做投影层）；③ 数据与基准类贡献（GeoFWI / OpenFWI）补上了本方向长期缺统一基准的短板。
- **还卡在哪**：**合成—真实域漂移是致命问题**，"纯合成数据训练 + 纯合成数据汇报"极为常见；缺井震标定；**在合成模型上排名靠前不构成真实反演能力的证明**；加速比明确，但反演质量是否优于常规 FWI 往往没有定量结论。
- **可引文献**：*GeoFWI: A Large Velocity Model Data Set for Benchmarking FWI Using Deep Learning*（**JGR: Machine Learning and Computation**, 2026-03）；*Ambient Noise Full Waveform Inversion With Neural Operators*（**JGR: Solid Earth**, 2025-10）。

**⑧ 地表过程、地貌演化与第四纪 / 沉积环境（4.4%）**
- **在解决什么**：把亿年尺度的过程压缩到可观测的现代地貌—沉积记录上，做定量重建与时序推断。
- **创新点**：**地貌计量学 + 时序遥感 + 因果/过程模型**的组合，是少有的"AI 只是其中一环"的方向。
- **还卡在哪**：过程模型与统计模型耦合弱；时间尺度压缩使结论**几乎不可直接验证**；本方向在本地清单中亦**未单列代表论文**。
- **可引文献**：R1（*The Innovation*，地球系统科学 AI 总论）；`近期研究/N8`（Earth foundation model 的特征清单，可用于界定本方向所需的表征能力）。（同样属相邻锚点。）

**⑨ 地球化学分析、同位素与矿物学大数据（4.1%）**
- **在解决什么**：高维成分数据的判别、配分与源区识别；矿物重构 / 分类 / 分割三类任务。
- **创新点**：矿物识别已成熟到"**瓶颈从模型转到数据集与标注规范**"的阶段——这本身就是可写进综述的判断；方法上偏"表格 ML + 可解释"，与地质解释链路最近。
- **还卡在哪**：成分数据的闭合效应与对数比处理常被忽略；**标注规范与数据集不统一**导致结果不可比；小样本下的过拟合难以排除。
- **可引文献**：R8 *岩石矿物智能识别综述*（《成都理工大学学报》2025）；R6（地球化学大数据方向的综述依据）。

**⑩ 岩石力学、工程地质与岩土智能建模（3.4%）**
- **在解决什么**：小样本力学实验条件下，用本构替代模型做变形、位移与稳定性预测（含隧道开挖、边坡、注水响应）。
- **创新点**：把 **PINN 用于弹塑性无网格建模**，把物理方程直接写进求解器而不是事后校验；与工程地质的耦合让"物理引导迁移"有真实落点。
- **还卡在哪**：力学实验样本量天然极小；**跨岩性、跨工点泛化差**；物理项引入后训练不稳定、误差累积机制未充分刻画。
- **可引文献**：*Physics-informed neural network for elastic–plastic mesh-free modelling of tunnelling-induced deformation*（**Acta Geotechnica**, 2025-10）；*Region similarity assessment for empowering physics-informed transfer learning-based landslide susceptibility mapping*（**JRMGE**, 2026-09）。

**⑪⑫⑬ 地质通用模型（三种类型合计 4.1%，全样本 9.5%）**
- **在解决什么**：三个完全不同层次的问题——**知识层**（跨领域问答、跨证据组织）、**表征层**（把多源观测压成可迁移的统一表征）、**编排层**（把前两者与数值模拟串成可执行工作流）。
- **创新点**：① 感知表征型用**冻结骨干 + 轻量适配**在真实数据上验证了"可迁移"，是目前唯一被实验证据支持的"通用"；② *The Innovation Reviews*（2026-09）给出基础模型三条准入门槛（广泛预训练 / 超越单任务 / 有迁移适配证据）并否定"参数多、预报快即基础模型"，**把"评测标准化"首次系统化为研究议题**；③ 编排层让工具链与文献证据可追溯。
- **还卡在哪**：① "通用"缺可操作的度量与阈值（11 项特征只是规范清单）；② **地表通用 ≠ 地质通用**；③ **地下没有 ground truth**，"预训练该预测什么"本身没有共识；④ 算力与数据壁垒，个人难以从头预训练。展开见 **3.4**。
- **可引文献**：`近期研究/N8` *On the foundations of Earth foundation models*（**Communications Earth & Environment**, 2026）；*The Innovation Reviews* 地球系统科学基础模型综述（2026-09-21）。

## 3.3 方向 A–H 入场解剖：各需要什么、各有什么特点

### 方向 A｜矿产远景预测与地球化学异常识别（7.0%；"找矿 + AI"入口）

- **需要什么**：
  - **技术**：多源栅格化与空间对齐、类别不平衡/PU 学习、可解释性归因、**空间分块交叉验证**（严禁随机切分）。
  - **数据**：地质图 + 构造缓冲 + 遥感蚀变 + 重磁 + 化探（水系沉积物多元素）+ DEM + 已知矿点/矿床清单；**最难的是"负样本从哪里来"**。
  - **方法**：QGIS / GEE → sklearn（RF、XGBoost）→ PyTorch（AE / 图网络 / 半监督 PU）→ SHAP；评价用**面积—命中率（P-A）曲线 + 成功率/预测率曲线 + 盲区验证**。
- **核心特点**：① 典型 **PU / 极端不平衡**，"未知区"不能直接当负类；② 评价的核心是**面积—命中率与盲区**，单看 AUC 没有说服力；③ 地质解释性是硬约束，SHAP / 注意力归因几乎标配；④ 空间自相关会让随机切分的指标虚高（须按图幅或成矿区带切分）。
- **常踩的坑**：把"未标注"当负类 → 精度虚高；随机划分 → 信息泄漏；只报 AUC → 掩盖高假阳率；不做盲区验证 → 无法证明"真的能找新矿"。
- **代表工作**：`近期研究/N7` DEEP-SEAM v1.0（GMD 2026，半监督 DevNet + SHAP，南澳 Curnamona REE）；`近期研究/N6`（Sci Rep 2026，数据稀缺下 LightGBM+AdaBoost 集成 + SMOTE）；`Recent advances… deep learning as applied to geochemical mapping`（Earth-Science Reviews, 2025-11）；`metric-learning enhanced VAE for geochemical anomalies`（Ore Geology Reviews, 2025-12）。
- **机会点**：占比仅 7.0%，且**地球化学异常检测子方向仅 1.33%**；多模态 LLM 做勘查数据整合刚刚出现（`Ore Geology Reviews`, 2026-06）；**无标签路线**刚被打开（`Ore Geology Reviews`, 2025-12 度量学习 VAE）。

### 方向 B｜地震监测、震源参数与地震学 AI（14.1%）

- **需要什么**：
  - **技术**：连续波形处理（ObsPy）、GPU 推理、**概率预报评估能力**（不能只报命中率）、实时流式处理。
  - **数据**：连续波形 + 台站/目录元数据；公开目录（STEAD / INSTANCE 类）+ 公开台网（IRIS / EIDA）+ 实验室声发射数据 + DAS 阵列记录。
  - **方法**：检测 → 拾取 → 关联 → 定位 → 震级/震源机制的流水线；生成式基础模型做统一预处理；DAS 实时流处理与边缘部署。
- **核心特点**：① **数据最干净、最丰富**，是地质 AI 里 AI 成功率最高的分支；② 任务标准化程度高（检测、拾取、定位、震级、相位），因此**最容易被卷**；③ "AI 预测/预报"部分争议巨大，**必须配严格概率评估**（告警式指标、误报代价）；④ 实验室实验 → 天然断层的**尺度外推**是根本质疑点。
- **常踩的坑**：把"实验室样品失稳提前量"直接外推为"可预报天然地震"；把"检测性能提升"包装成"预测能力突破"；用单次成功案例代替统计检验。
- **代表工作**：`近期研究/N1/N2/N3`（实验室地震预测系列，Nature Comms / Comms Earth & Env / GRL）；`近期研究/N9`（b 值 DL 预报的概率与告警式评估）；`A Generative Foundation Model for an All-in-One Seismic Processing Framework`（Surveys in Geophysics, 2025-11）；`Real-Time Processing of DAS Data for Earthquake Monitoring`（SRL, 2026-03）。
- **机会点**：DAS（分布式声波传感）实时处理、跨台网/跨构造环境的泛化、预警大模型。

### 方向 C｜地质遥感解译、岩性识别与智能地质填图（15.2%）

- **需要什么**：
  - **技术**：影像预处理与大气校正、多尺度语义分割、野外/岩芯照片处理、**制图比例尺对齐**意识。
  - **数据**：Sentinel-2 / Landsat / 高光谱（USGS 光谱库）+ DEM / LiDAR（OpenTopography）+ 地质图标签 + 露头与钻孔影像。
  - **方法**：TorchGeo + 基础模型（Prithvi-EO-2.0 / TerraMind / DOFA）冻结微调；图网络处理采样点空间依赖；因果/对比学习提升可解释性。
- **核心特点**：① 遥感只在**裸露区**有效，覆盖受植被/风化/云雨限制；② 标签来自地质图，**比例尺与制图年代不一致**是最隐蔽的系统误差；③ "换数据集刷 IoU"是重灾区；④ 地下无标签、无真值，**深度是这一类方法的天然边界**。
- **常踩的坑**：用同一图幅像元随机切分 → 空间泄漏；把"地质图副本"当"独立真值"；跨构造单元直接迁移而不做分布外检验。
- **代表工作**：`近期研究/N5`（甘肃北柳园 TASI 机载高光谱岩性填图的 MLS3 样本生成方法）；`Geological information-driven deep learning for lithology identification from well logs`（Frontiers in Earth Science, 2025-09）；`Causal-Graph Lithology Classifier`（Marine and Petroleum Geology, 2025-10，用因果推断 + GNN）；`Interpretable regional-scale geological mapping using a contrastive graph attention network`（Engineering Geology, 2026-02）。
- **机会点**：**智能地质填图仅占 0.38%、岩性识别 1.24%、断层/构造要素识别 0.52%** ——三个并列洼地，恰恰是最贴近"地质填图主业"的方向。

### 方向 D｜地震勘探 / 测井 / 储层地球物理智能处理与反演（4.6%）

- **需要什么**：
  - **技术**：地球物理正演功底（波动方程、褶积模型、反演理论）+ 可微算子编程 + 较大算力。
  - **数据**：SEG-Y 数据体（F3 Demonstration、Volve）、井数据 LAS（lasio / welly）、合成速度模型库（OpenFWI、GeoFWI）。
  - **方法**：Deepwave / PyLops / DEVITO 做可微正反演；神经算子做正演代理；扩散/生成模型做插值与低频外推；用**多实现或后验分布**表达不确定性。
- **核心特点**：① 门槛最高（需要地球物理正演功底）；② **强不适定、非唯一性极强**，单点最优解没有科学意义；③ 合成—真实**域漂移（domain gap）**是致命问题；④ 评价必须问"是否守恒、是否与井吻合、是否可重复"。
- **常踩的坑**：纯合成数据训练、纯合成数据汇报；用一张剖面对比图代替统计评估；不做井震标定验证。
- **代表工作**：`GeoFWI: A Large Velocity Model Data Set for Benchmarking FWI`（JGR:MLC, 2026-03）；`Ambient Noise Full Waveform Inversion With Neural Operators`（JGR Solid Earth, 2025-10）；OpenFWI / E-FWI 基准；`EFKAN: KAN-integrated neural operator for magnetotelluric forward modeling`（Computers & Geosciences, 2026-02）。
- **机会点**：虚拟测井/孔渗 **0.67%（洼地）**、神经算子替代昂贵正演、不确定性反演。

### 方向 E｜地质灾害易发性与工程地质/岩石力学（13.8% + 3.4%）

- **需要什么**：
  - **技术**：空间统计与验证集设计、时序建模、物理约束（边坡稳定/Newmark 类）基础。
  - **数据**：DEM / LiDAR、地质图、降雨与触发因子、InSAR 形变、**灾害编录（历史滑坡清单）**；InSAR/LiDAR 是当前最有信息量的补充数据源。
  - **方法**：树模型 / U-Net 做易发性制图；LSTM / Transformer 做形变时序；PINN 或物理引导迁移做跨域；**不确定性量化 + 动态阈值**做预警。
- **核心特点**：① **最成熟、最容易上手**，也因此竞争最激烈（红海）；② 评价必须防止"同一滑坡体被随机切分到训练测试"；③ 位移预测/预警需要时序模型与物理引导；④ **数据不平衡 + 泛化差 + 成灾机制复杂**是综述公认的三大挑战。
- **常踩的坑**：负样本选址随意（把陡坡当负样本）；只报 AUC 不报空间外推；"易发性"与"危险性/风险"混用。
- **代表工作**：`Review article: Deep learning for potential landslide identification`（NHESS, 2026-01）；`Region similarity assessment for empowering physics-informed transfer learning-based landslide susceptibility mapping`（JRMGE, 2026-09）；`Uncertainty-aware ensemble learning and dynamic threshold optimization`（Computers & Geosciences, 2026-01）。
- **机会点**：**物理引导迁移（跨域）+ 不确定性感知阈值优化**是同类中学术含金量更高的写法。

### 方向 F｜地质通用模型：语言知识型 / 感知表征型 / 业务系统型（4.1%，全样本 9.5%）

> 本方向即 3.1 表中的 ⑪⑫⑬，**详细展开见 3.4**；此处只给入场视角。

- **需要什么**：
  - **技术**：分布式训练与自监督预训练经验、多模态对齐、参数高效微调（LoRA / Adapter / 冻结探测）。
  - **数据**：大规模无标注 EO 数据（HLS、Sentinel、ERA5、地形）+ 少量下游标注；**预训练算力**是硬门槛（个人通常只能做下游微调）。
  - **方法**：掩码重建（MAE）/ 对比学习做预训练；冻结骨干 + 轻量适配头做下游；**标准化评测协议**才是真正稀缺品。
- **核心特点**：① 创新集中在"**改哪一块**"——数据层 / 输入端 / 骨干 / 预训练目标 / 适配接口 / 评测（见速查表 6 模块）；② ①② 最卷，⑤⑥ 相对空白；③ **N8（Comms Earth & Env, 2026）提出理想地球基础模型应具备 11 项特征**，把"标准化评测"首次系统化为研究议题；④ 通用性的边界很清楚：**地表通用 ≠ 地质通用**。
- **常踩的坑**：只做"换骨干重训"式对标；不做跨传感器/跨区域外推验证；拿地表任务的增益宣称地下能力。
- **代表工作**：Prithvi-EO-2.0（IEEE TGRS 2026）、`A Billion-Scale Foundation Model for Remote Sensing Images`（IEEE JSTARS 2026）、TerraMind（ICCV 2025）、`N8 On the foundations of Earth foundation models`。
- **机会点**：⑤ **参数高效适配 + ⑥ benchmark/评测** 是低竞争高价值区；"小模型+好表征目标"的路线正在被验证（见 Part 4）。

### 方向 G｜水文地质 / 环境地球化学 AI（20.9%，当前最热）

- **需要什么**：
  - **技术**：地下水流 / 溶质运移方程基础、PDE 约束建模、UQ 统计（覆盖率、校准曲线）。
  - **数据**：稀疏观测井水位/水质、抽水试验、降雨与补给、区域地质与含水层参数（**观测极稀疏是本质特征**）。
  - **方法**：PINN 与多物理 PINN（元学习/预训练 PINN）、神经算子代理、集成学习 + 共形预测（CP）做区间估计。
- **核心特点**：属于 PDE 约束问题的代表，极适合做"**小模型 + 强物理**"；热度最高说明竞争不小，但**差异化落地点是物理正确性与不确定性量化（UQ）**；③ 评价要问"守恒性、边界条件、外推区表现"，而非只报 RMSE。
- **常踩的坑**：无物理约束的纯数据拟合被当作"PINN 成果"；训练域外的外推被当作预测能力；不给预测区间却宣称可用于决策。
- **代表工作**：`Physics-informed neural networks enhanced by data augmentation`（J. Hydrology, 2025-12）；`Multi-Physics GPT-PINN for reactive solute transport`（GRL, 2026-02）；`Uncertainty quantification of surrogate models using conformal prediction`（ML: Science and Technology, 2026-02）。

### 方向 H｜地球动力学、深部结构与行星（10.5%）

- **需要什么**：
  - **技术**：数值模拟/正演能力（地幔对流、地球动力学模拟）+ 强物理一致性约束 + 高性能计算。
  - **数据**：地震层析/接收函数、地磁与重力场、古地磁、矿物物理实验约束。
  - **方法**：代理模型（用神经网络替代昂贵数值模拟）、可外推先验、多物理场耦合、贝叶斯反演与集合方法。
- **核心特点**：离"AI 方法"最远、离"地质科学问题"最近，**最易产出高影响力成果**，但需要扎实的地球动力学背景；② 本方向在文献清单中**未单列代表论文**，说明当前 AI 渗透仍以方法迁移为主，尚未形成独立方法论。
- **机会点**：代理模型 + 可外推先验 + 多物理场耦合；叠加 Part 4 的"what-if"推演是它最自然的进化方向。

## 3.4 地质通用模型：地学大模型 / 地学基础模型（方向 F 展开）

> **名词澄清（重要）**：按你给出的定义，本报告统一把 `GeoAGI` 读作 **Geography Artificial General Intelligence（地理通用人工智能）**，即"面向地理/地学领域的通用人工智能"。三点必须讲清：
>
> 1. **作为英文缩写，"GeoAGI" 不是学术界的通行写法**：截至 2026-09-23 检索不到以此命名的模型、论文或项目。这一方向的**同行评议正式提法是 Autonomous GIS（自主 GIS）**——见第 ⑧ 条文献，其概念框架为 **5 个自主目标 + 5 级自主性 + 5 项核心功能 + 3 个运行尺度**，并以 4 个概念验证型 GIS 智能体演示地理空间数据检索、空间分析与制图。**汇报里要讲"地理 AGI 分级"，就引这一篇，不要引营销文章。**
> 2. 中文圈另有"**地理通用人工智能（GAI）**"一说（宣称 2024 年底提出：神经符号融合 + 动态 MoE + 可微分逻辑约束）。我两轮检索**均未能定位其原始出处**（本次检索该提法返回的全部是与地理无关的神经符号 AI 通稿），**判定为不可溯提法：建议不用，被问到时按"来源不明"处理**。
> 3. 三个词必须分开用：**GeoAI**＝地理空间人工智能（技术总称）；**Autonomous GIS**＝自主 GIS（学术议程）；**GeoAGI**＝你使用的说法，语义上对应 Autonomous GIS 的终局目标。
> 4. **GIS ≠ 遥感（勿混，这是本节最易答错的点）**：GIS 管的是空间数据的**管理、分析、制图**（矢量/栅格/属性表、叠加、缓冲区、选址、工作流），遥感是**观测数据源**（传感器获取地表电磁波信息，产出影像/点云）。第 ⑧ 条文献属 **GIS 侧**（用 LLM 自动生成并执行地理处理工作流），**不是遥感基础模型**，引用时不得混为一谈。地质调查中的典型串联是：**遥感找线索 → GIS 集成分析 → 野外验证**；对应到本节的类型划分，遥感基础模型在 **B 类（感知表征型）**，Autonomous GIS 在 **C 类（业务系统型）**。
>

### 3.4.1 先分清："地质通用模型"混着三种完全不同的东西

| 类型 | 代表 | 本质能力 | 通用性到底"通用"在哪 | 现状判断 |
|---|---|---|---|---|

### 3.4.3 "通用"的判定标准：三条件 + 地质四道硬检验

**基础模型的三条准入门槛（The Innovation Reviews, 2026-09-21）**：
1. 做过**广泛预训练**；2. 具备**超越单一任务**的能力；3. 有**迁移或下游适配证据**。
该综述明确否定了"参数多、预报快就叫做基础模型"这一流行判断——这一条直接击穿了国内大量"XX 地质大模型"的宣传口径。

**地质专属的四道硬检验**（与前四部分呼应）：
1. **跨域外推**：跨构造单元、跨气候带、跨传感器、跨制图年代的表现，而不是同区随机切分；
2. **物理一致性**：守恒（质量/能量/动量）诊断、外推区是否产生非物理图案；
3. **概率可信**：校准曲线、预测区间覆盖率、告警式评分（Molchan 式）；
4. **专家盲测**：让地质学家在不知道模型输出的前提下做判读对比。

> 一句话：**"通用"要用"跨域外推 + 物理一致 + 概率可信 + 专家认同"四张证据来证明，而不是用某个下游任务的 IoU。**

### 3.4.4 为什么地质的"通用"比气象 / 遥感难得多

该综述提炼的**五类共性挑战**，在地质上每一条都被放大——这正是本地统计里"地质大模型"只占 4.1%（87 篇）、而全样本占 9.5% 的结构性原因：

| 五类共性挑战 | 气象 / 遥感为什么能缓解 | 地质版本被放大成什么 |
|---|---|---|
| ① 海量观测未必可训练 | 再分析场、卫星序列连续、网格规整 | 钻孔稀疏、化探点位随道路与矿区分布，**采样有偏且不可补齐** |
| ② 跨模态表征难以复用 | 影像与数值场共享经纬网格 | 岩芯照片、地震剖面、地球化学点、地质图比例尺各不相同，**没有共享坐标系** |
| ③ 统计拟合可能违背物理 | 有守恒律与数值模式做"物理裁判" | 地质过程时间长、不可重复，**物理裁判本身靠假设**，且非唯一性极强 |
| ④ 平均误差难衡量科学可信度 | 极端天气可用 FSS / 概率评分 | 矿床、滑坡、强震都是稀有事件，**RMSE 与 AUC 都不对应科学价值** |
| ⑤ 数据与算力壁垒 | 公共再分析数据 + 大规模算力 | 大量数据涉密 / 涉商业，**跨机构共享困难**；个人难以预训练 |

**再加一条地质独有的、也是最重要的**：
> **地下没有 ground truth。** 气象有再分析场当"标准答案"，遥感有地面实测标定；而地质的深部结构只有解释模型——于是"预训练该预测什么"**本身没有共识**。这就是"地质通用模型"最大的理论缺口，也恰恰是它必须转向世界模型（预测**状态转移**而不是预测标签）的动因。

### 3.4.5 我的判断：可行形态是"分层通用"，不是"一个模型包打天下"

| 层 | 是否已通用 | 现有选项 | 建议 |
|---|---|---|---|
| **感知层**（影像/时序表征） | ✅ 已通用 | DOFA、Prithvi-EO-2.0、TerraMind、Clay | **直接用 + 冻结迁移**，性价比最高 |
| **知识层**（文献/图件/证据组织） | 🟡 正在通用 | GeoGPT、元古、OneStrata、GeoMap-Agent | 解决"证据可追溯"，不解决"预测" |
| **过程层**（地下结构与动力学） | ❌ 远未通用 | PINN、神经算子、代理模型、世界模型 | **领域专用 > 通用**，这是 AI 做不掉的硬骨头 |
| **决策层**（工作流/智能体） | 🟡 形式通用 | AI-GeoMapping、AI-OreSeeking、GeoGPT 平台 | 编排能力通用，**可信度受制于下三层** |

> **结论：通用的是表征与知识，不能通用的是过程与机理。** 宣称"一个通用地质大模型解决所有地质问题"目前没有证据支持；相反，把通用的感知层 / 知识层与专用的物理层、评测层拼起来，才是现阶段唯一可验证的路径。

### 3.4.6 与 Part 4 的接口：地质通用模型的下一站不是"更大"，而是"可干预"

- **现状缺口**：地学大模型基本是**被动问答 + 被动预报**，既没有 action，也没有物理残差——正是 M-JEPA 与 Earth System World Model 两篇所指出的"被动模拟器"问题。
- **三条改造**：
 1. 预训练目标从"重建/判别/下一词"换成**表征预测**（JEPA 式潜变量 rollout）；
 2. 用 **transition-action pretraining**，把"自然观测到的地质状态变化"当作免标注的动作监督（无需人工标注干预）；
 3. 把**物理残差项**写进损失（速查表判断：纯掩码/对比是红海，物理残差是唯一还有大空间）。
- **形态建议**：`知识层（GeoGPT 类）+ 感知层（冻结 EO 骨干）+ 推演层（世界模型）` 三段式，而不是继续堆参数。
- **评价建议**：用 Part 2 的 AI4S 评测体系，而不是通用 QA benchmark——**GeoMap-Bench 这类基准是必要的，但远不足以证明"通用"**。

### 3.4.7 对选题与投稿的三条启示

1. **不要做"又一个地质大模型"**：该类别在地质主体子集仅 4.1%（87 篇）、算力壁垒高、且"通用"证据难做。真正的空白在**基准与评测体系、参数高效下游适配**（速查表 ⑤⑥ 两个模块，卷度最低）。
2. **有独家数据时，"领域适配"远比"从零预训练"划算**：冻结通用骨干 + 物理约束头 + 少量标签探测（本地文献 N2 已验证：冻结约 97% 参数只调回归头即可跨构型泛化）。
3. **投稿分层**：方法层 → AIES / JGR:MLC / MLST / C&G；地球系统基础模型总论 → *The Innovation* / *Nature MI* / *Comms Earth & Env*（本地 N8 已在此刊）；工程系统类 → 中文核心刊与行业发布，注意**这类成果不进入 Crossref 期刊统计**（本地 83 刊样本未覆盖），做国内外对比时需手工补充。

### 3.4.8 GeoAGI（地理 AGI）的分级：权威框架 + 地质映射

**先说权威框架**：同行评议中对应的正式议程是 **Autonomous GIS（自主 GIS）**——*Annals of GIS* 2025（第 ⑧ 条文献，16 位作者含 Janowicz、Song Gao、Wenwen Li、Zhu A.-X.、Shekhar），框架为 **5 个自主目标 + 5 级自主性 + 5 项核心功能 + 3 个运行尺度**，并用 4 个概念验证型 GIS 智能体演示数据检索、空间分析与制图。→ **要给"地理 AGI 分级"，引这一篇；各级具体定义需查原文正文（摘要未展开，勿凭推测引用）。**

**再看能力—证据视角的映射**：把 AGI 的通行分级（任务专用 → 跨任务通用 → 自主科学发现）翻译到地质：

| 级别 | 判别标准 | 地质现状 | 卡在哪 |
|---|---|---|---|
| **L1 任务专用** | 单任务、同分布、有标签 | 已大规模实现（滑坡易发性、岩性填图、MPM、断层识别） | 已不是问题 |
| **L2 跨任务通用** | 一个骨干跨 ≥5 类任务，且跨区外推不崩 | **仅感知层达到**（DOFA / Prithvi-EO-2.0 / TerraMind / Aurora） | 过程层没有共享表征 |
| **L3 自主科学发现** | 能自己提出假设、设计观测、检验并修正 | 只有局部 demo（智能体 + 工具链编排） | 无 ground truth、无实验闭环、不可重复 |
| **L4 自主干预决策** | 在真实勘查/工程中给出可执行且可追责的 what-if | 尚未出现 | 缺 action 与物理一致性（见 3.4.6） |

**判断**：地学 AGI 的现实路径不是"再训一个更大的地学大模型"，而是 **L2 的感知/知识通用层 + L1 的过程专用模型 + L3 的智能体编排** 三者组合——因为地质的核心瓶颈是"**没有 ground truth、实验不可重复**"，这恰好命中 AGI 定义中最难满足的一条，而不是算力不足。任何宣称 L4 的说法，都应先要求它给出 3.4.3 的四张证据。

**可引的外部锚点**：昆士兰大学团队的地学能源 AGI 综述（*Gas Science & Engineering*, 2024；arXiv:2406.00594）在摘要中指出，AGI 将深刻影响上游地热与油气行业——这是目前把 AGI 与地质/能源行业正式挂钩的少数同行评议文献，可作为"地学 AGI"这一提法的学术出处（注意：该文面向油气·地热上游，**不是固体矿产与基础地质**，引用时勿越界）。


## 3.5 代表论文逐篇解剖（问题 / 方法 / 特点 / 未解决 / 存疑）

> **阅读约定**：N1–N9、R1–R9 的 PDF 均在本地 `docs/` 下，以下判断以原文摘要与方法段为依据；**标 ⚠️ 的是本文的批判性判断（作者未自述）**，汇报时建议明确区分"作者结论"与"我们的疑问"。

#### A 类论文｜矿产远景预测与地球化学异常

**N7 DEEP-SEAM v1.0（GMD 2026，南澳 Curnamona REE）**
- **问题 / 方法**：REE 勘查正样本极少下的矿化概率填图；DevNet 半监督异常检测（少量正样本 + 大量未标注样本）建立多源勘查数据 → 矿化概率映射，再用 SHAP 做事后解释。
- **显著特点**：**把"可解释"做进流程**（SHAP 直接输出各勘查图层贡献度），开源可复现，且发表在国际模型发展刊（GMD）——"方法可复现"是被认可的。
- **未解决**：未标注/负样本的构造规则仍靠人工设定；仅单一成矿省验证；半监督相对"朴素正样本加权"的增益无充分消融。
- ⚠️ **存疑**：SHAP 给的是**统计贡献度，不是地质成因证据**；面积—命中率提升可能主要来自新增先验图层，而非模型能力。

**N6 数据稀缺下的集成机器学习（Sci Rep 2026，伊朗 Dehaq 铅锌矿）**
- **问题 / 方法**：数据稀缺 + 类别不平衡下的 MPM；对比 LightGBM+AdaBoost 与 SVM+高斯朴素贝叶斯两种集成，网格/随机/贝叶斯三种调参 + SMOTE。
- **显著特点**：**态度诚实**——作者明确强调概率校准与可复现性比"边际精度提升"更重要（AUC 0.90–0.95），这是本方向少见的自我约束。
- **未解决**：SMOTE 在空间数据上会生成破坏空间结构的伪样本；单一研究区、样本量小；无盲区/新区验证。
- ⚠️ **存疑**：AUC 0.90–0.95 难以排除**空间自相关导致的信息泄漏**；重采样的增益能否跨矿区复现未知。

**ESR 2025-11 综述《深度学习用于地球化学填图》（Xu、Zuo、Kreuzer 等）**
- **问题 / 方法**：回答"DL 在化探填图能做什么、卡在哪"；把 2019–2025 五类算法（DBN / RNN / CNN / AE / GAN）归类，并提出两种新架构——**图自监督学习**（图表示 + Transformer + 知识节点）与**图强化学习**（GCN + 地质规则奖励函数）。
- **显著特点**：**点名三大瓶颈**（复杂空间异质性表征不足、训练样本不足、地质约束未系统整合），并把解法收敛到"图表示 + 知识嵌入"一条线上，是该团队路线的最新纲领性表述。
- **未解决**：两种新架构仅案例验证，无跨区域基准；"知识节点""奖励函数"如何标准化构建，缺少可操作规程。
- ⚠️ **存疑**：以"图 + 知识约束"同时解决三个瓶颈偏乐观；强化学习依赖可交互环境，在**静态填图**任务中是否必需存疑。

**OGR 2025-12 度量学习增强 VAE（新疆哈图金矿带）**
- **问题 / 方法**：无标签条件下识别化探异常；以度量学习改造 VAE 潜空间，使异常与背景更可分。
- **显著特点**：走**无监督/自监督**路线，直接绕开"负样本从哪来"这一全领域痛点。
- **未解决**：无监督方法**没有客观真值**，只能与已知矿点做弱验证；异常阈值选择高度任意。
- ⚠️ **存疑**："异常 = 矿"这一前提本身可疑；潜空间可分性提升能否转化为**真实找矿发现**，摘要层面无法确认。

#### B 类论文｜地震监测、震源参数与地震学 AI

**N1 米尺度实验室地震预测（Nat Comms 2025）**
- **问题 / 方法**：对米尺度岩石摩擦实验的声发射目录构建"事件网络表示"，用随机森林/深度学习预测破坏时间；再用速率—状态摩擦数值模型解释模型追踪的是蠕滑区剪应力演化。

- **未解决**：迁移范围限于同实验室、同摩擦体系；未测试跨设备、跨机构、跨岩石类型。

**N9 b 值驱动深度学习地震预报的概率与告警式评估（arXiv 2026）**

- ⚠️ **存疑**：地学任务普遍存在**空间/时间分布漂移**，一旦交换性假设（exchangeability）被破坏，名义覆盖率会失真，直接套用需谨慎。

#### H 类｜地球动力学与深部结构

- **证据状态**：本地文献清单（R1–R9、N1–N9）中**未收录该方向的代表论文**。这本身是一个可汇报的结论：AI 在地球动力学/深部结构仍以**方法迁移**为主，尚未形成独立的方法论脉络，可引的坐标只有 R1 总论框架与代理模型（surrogate）类工作。
- **因此**：该方向的"未解决/存疑"应从**代理模型的可外推性**切入——数值模拟的代理模型在参数空间边缘极易失效，而地球动力学问题恰恰关心边缘（极端状态）。

# Part 4 最新 AI 技术：世界模型与 Jev（TypeSafe AI 公司的快速判断模型）能否融入地质 + AI？

## 4.1 先纠正一个提法：不是"神经网络过时"，而是"判别式拟合范式退居其次"

近两年 AI 界的实际变化，更准确地说是三句话：

1. **CNN / U-Net / RF 仍是工程主力，不会消失**——本地统计中深度学习占方法维度 **46.2%**、传统 ML 占 **19.3%**，它们是"地质 AI 的水泥"。
2. **被质疑的是"从像素/从单个标签做端到端判别"这一范式本身**：它在域内很准，在域外（换个地区、换个年代、换个传感器）就崩——而这恰恰是地质最需要的那个能力。
3. **新一代范式有三个关键词**：
 - **Joint-Embedding Predictive Architecture（JEPA）**：不在像素空间预测未来，而在**表征空间**预测未来；用 EMA 目标编码器避免表征坍缩；用自回归潜变量 rollout 做多步滚动预测（LeCun 一脉，2025 年 V-JEPA 2 把视频版推向可用）。
 - **World Model（世界模型）**：在 JEPA 之上再加一个关键 Missing piece ——**动作/干预（action）**。它不只是"预测会发生什么"，而是"**如果我做了 X，会发生什么**"（what-if），因此可以用于规划与决策。
 - **Decision Model（决策模型）**：不再生成一段文字，而是直接输出**带校准概率的类型化判断**。2026-09 发布的 **Jev**（TypeSafe AI）是当前代表：它把"做判断"从生成式大模型里**拆出来单独训练**，并以**概率校准**（说 0.8 把握，长期就该有约 80% 命中）为第一优化目标（详见 4.3）。

一句话：**从"识别"到"预测"，再到"干预与推演"，最后落到"带把握的判断"。**

## 4.2 本地两篇论文已经把这条线打进了地球科学

### （1）M-JEPA：不学降水，却比学降水的模型更会报降水
`Tracing the Unlabeled Storm: Cross-Variable Transfer in a Lagrangian Atmospheric JEPA Framework`（arXiv 2608.22358，IIT Delhi）核心设计与结论：

- **核心难题**：降水是稀疏、零膨胀、重尾变量，直接从降水数据学习表征效果不佳；而连续的**外向长波辐射（OLR）** 等代理变量更连贯地表达了同一物理过程。
- **做法（cross-variable proxy learning）**：在**拉格朗日 patch**（跟随移动的对流包体）上预训练多尺度 JEPA；整个过程**降水从未作为监督信号出现**。之后冻结骨干，仅训一个轻量读出去做日降水预报。
- **结果**（关键）：
 - 直接拿降水训练的同架构模型，CRPS 比该方案**差 36%**（7.52 vs 5.54 mm/day）→ 证明学到的是**可迁移的物理结构**而不是任务捷径；
 - 冻结表征的 15.4M 参数模型在**单张消费级 GPU**上，CRPS 6.81 mm/day 略优于 51 成员的 ECMWF 业务集合（6.89），Brier skill +0.05 vs −0.04，**优势集中在暴雨阈值和细尺度**；
 - 作者同时坦白局限：**rollout 存在动力学阻尼，第 5 个 lead 后饱和**，长生命系统的衰减预测偏弱 → 需要更稠密（时间/垂直层/空间）的代理信息。

**地质启示（我认为最重要的一条）**：地质里大量变量正是"降雨型"的——稀疏、零膨胀、重尾（矿点分布、断层迹线、滑坡编录、钻井取心）。**不要对着稀疏目标硬学，先让模型在连续代理场上学会动力学，再把表征迁移到稀疏目标**；且必须用**冻结骨干 + 对照组**（random-init、目标-only 两个 control）来证明你学到的是物理而不是巧合。

### （2）Earth System World Model：把"what-if"带进地球数字孪生
`Earth System World Model for What-If Simulations: A Case Study for Terrestrial Ecosystems`（arXiv 2609.08855，SIGSPATIAL '26）核心设计与结论：

- 指出现有 ML 模拟器（emulator）**本质是被动预报器**：在给定强迫下复现轨迹，**不支持用户注入干预**。作者比喻为"早期视频生成器——能生成高保真像素流，但不能交互"。
- 提出 **action-conditioned 世界模型框架**，两个关键组件：
 - **transition-action pretraining**：把"自然观测到的状态变化"当作**免标注的动作监督**，从而无需人工标注干预也能学可控状态转移；
 - **masked response learning**：在部分状态被编辑、部分变量未观测的情况下推断其耦合响应，从而学到变量间的耦合依赖。
- 效果：在 6 个全球区域、多个林龄上保持竞争力的长程模拟精度，**同时支持结构性干预（如 Reforest / Logging）并产生连贯的多变量响应**；目标是通往"交互式 science-ready surrogate / 地球数字孪生"。

**地质启示**：地质学天然就是一个"干预科学"——开采、注水、注 CO₂、开挖边坡、断层再活动、剥蚀—沉积、岩浆侵位，本质上都是地球系统状态上的 action。因此：

| 地质what-if场景 | 可类比状态编辑 | 需要的模型能力 |
|---|---|---|
| 盆地的埋藏史/热演化反事实（假如剥蚀 2 km） | 状态分量的结构性编辑 | 耦合响应 + 长程 rollout |
| 断层滑动/地震级联的情景推演 | action-conditioned rollout | 潜变量自回归 + 物理一致性 |
| 矿山边坡开挖、注水的稳定性响应 | 用户注入干预 | 局部编辑 → 全场连贯响应 |
| CO₂ 地质封存的水—力—化耦合 | masked response | 多物理变量耦合推断 |
| 找矿决策："若在此处布设钻孔/加装激电" | 观测 action（信息获取） | 主动采样 / 贝叶斯实验设计 |

## 4.3 第三条线：决策模型（Jev）——"判断"正被从生成里拆出来

前两条线回答"世界如何演化"和"干预会怎样"，第三条线回答"**此刻该判什么、有多大把握**"。它在 2026 年 9 月同样被推到了台面上。

**Jev 是什么**：TypeSafe AI（旧金山，2024 年创办，创始人 Diogo Almeida 为 GPT-4 论文共同作者、前 OpenAI 研究员）于 **2026-09-15** 发布的首款模型。它自我定位不是"又一个对话模型"，而是 **System One 决策模型**——**不生成任何文本**，接收结构化 **state**（字符串 / JSON / 数组）+ 一组**带类型的问题**，直接返回**带校准概率的类型化判断**。官方定义：*a frontier-intelligence function call*。

**它只支持三类原语**（同一次请求可混用，对同一份 state 并行独立评估）：

| 原语 | 做什么 | 返回什么 |
|---|---|---|
| **Choice** | 从预定义选项中选一个（最多 255 项） | 各选项概率分布 + 整体置信度 |
| **Score** | 在自定义有序量表上打分 | 分值（可为小数）+ 档位图例 + 概率 + 置信度 |
| **Noul** | 是 / 否 判断 | 布尔概率 |

两条有工程含义的性质：**① 并行求值**——增加问题几乎不增加响应时间，也不会出现"上下文漂移"；**② 结构即契约**——输出空间被问题定义死，模型**不可能**返回列表之外的值（这是它宣称"零幻觉"的技术来源）。

**它唯一的技术主张是 RLCD（校准决策强化学习，Reinforcement Learning for Calibrated Decisions）**，这也是本报告认为最值得地质界注意的一点：

| 训练范式 | 奖励信号 | 解决了什么 | 没解决什么 |
|---|---|---|---|
| RLHF | 人类偏好 | 输出流畅、讨喜 | 置信度没有任何保证 |
| RLVR | 可验证正确性（数学、代码跑通） | 客观对错 | **只告诉你对不对，不告诉你模型有多确定** |
| **RLCD**（Jev） | **真值 + Brier Score 类概率校准指标** | **"说到做到"：说 0.8 把握，长期就该约 80% 命中** | 需要真值标注；**OOD 下能否守住未知** |

**为什么把它归到 Part 4 这条线**：三者是互补关系，不是替代关系——**JEPA 管"世界怎么演化"，World Model 管"如果我做 X 会怎样"，Jev 管"现在该怎么判、有多大把握"**。"判断"被从生成式大模型里拆出来单独训练、并以**概率校准**为第一优化目标，这个**分工思想**比 Jev 这个产品本身更值得注意。

**地质启示（两条）**：

1. **地质工作的本质正是带不确定性的判别决策**——有没有矿、是不是滑坡、这个蚀变异常真不真、这条测井分几层、这个样品要不要复检、这条告警要不要上报。而当前地质 AI 的通病恰恰是**输出的概率从未被校准过**：模型说"80% 有矿"，没人知道这 80% 是不是真的 80%。若这条线成立，它补的正是地质最缺的那一环。
2. **但现在在地质里还接不上**：Jev 只吃结构化 state，而地质输入以图件、报告、剖面等**非结构化**数据为主——**必须先有 B 类（感知表征）编码器把地质数据压成向量或结构，才谈得上用它**。反向也说明一件事：**感知层是决策层在地质落地的前置条件。**

若要在汇报里提它的应用面，落点应是**高频、重复、目前靠人写规则或靠大模型慢推理的判断分支**：岩性 / 岩相判读与分级（Choice、Score）、蚀变强度分级（Score）、矿化潜力打分（Score）、样品是否需复检（Noul）、异常是否上报（Noul）、图件与报告质检（Choice）。**它的可复现性与审计风险见 4.5。**

## 4.4 落到地质 AI：一个可执行的三层融合路线

**Layer 1（表层替换，短期可做）**——把预训练目标从"重建/判别"换成"**表征预测**"。
在高光谱/地震 waveform/重力场这类连续场上做 JEPA 式潜变量预测，下游迁移到你真正关心的稀疏目标（岩性、矿化、断层）。这是对现有工作流改动最小、论文增量最清晰的一层。**注意**：评价必须沿用 M-JEPA 的严谨协议 —— 冻结骨干 + 两个对照组 + 物理诊断（CKA 相似度、功率谱、FSS）。

**Layer 2（中层升级，中期）**——给模型加"动作"，做 **Action-Conditioned Geoscience Surrogate**。
采用 Earth System World Model 的 transition-action 思路：**不需要人工标注干预数据**，把"自然发生的地质状态变化本身"当作 action 监督（例如：一次开采活动前后的 InSAR 时序、一次地震前后的应力/孔压场、剥蚀前后的地貌）。这能把传统的被动模拟器升级为支持决策的 what-if 模型——**transition-action pretraining 这一条尤其适合地质，因为地质恰恰没有带干预标签的数据集。**

**Layer 3（深层重构，长期）**——从"预测器"走向"可交互的科学推理伙伴"。
合并三条线索：① JEPA 表征 + 冻结迁移；② 物理残差/可微正演做硬约束（`近期研究/N8` 呼吁的 11 项特征中的"物理一致性/能效/可解释"）；③ LLM/多模态做地质知识与跨源证据的组织层（`Ore Geology Reviews` 2026-06 已出现用多模态 LLM 整合巴基斯坦矿产资源数据的尝试）。

## 4.5 但必须讲清楚的风险与边界（这部分建议在汇报时直说）

1. **JEPA 在连续平滑场上成功 ≠ 在地质上能立刻成功**。气象有海量连续代理场；地质的数据是**离散、多年代混合、强非平稳**的。M-JEPA 自己就承认 rollout 会阻尼饱和——地质系统的时间跨度还要再长好几个量级。
2. **世界模型的"干预有效性"需要物理校验，不能靠漂亮 rollout**。大规模状态转移模型在像素上"看起来合理"不等于质量守恒/动量守恒成立；所以地质世界模型必须保留 ④ 预训练目标里的**物理残差项**（这也是速查表判定"纯掩码/对比是红海，物理残差是唯一还有大空间"的原因）。
3. **不要为了追新名词丢掉基本功**。近一年数据说明：**可解释性与不确定性量化占 17.1%，几乎追平传统 ML**——这说明地质界当前最焦虑的并不是"模型不够新"，而是"结论不敢用"。任何把 JEPA/世界模型引进地质的工作，只要没回答好"它在野外/钻井上能否被验证"，就依然只是一篇方法学论文。
4. **决策模型类"新物种"目前只有叙事、没有一手证据**（对应 4.3）。Jev 发布仅数日，**不开源权重、未发技术论文、架构未披露**，社区只能靠输入输出反推；其"校准"在 **OOD 极端场景**下是否守得住仍是黑盒，而地质恰恰全程 OOD（跨构造单元、跨年代、跨传感器）。同时官方"零幻觉"指的是**输出不越出 schema**，**不等于内容正确**——**类型安全 ≠ 语义正确**。更关键的是它**只给概率、不给理由**，一旦误判无法追溯——而地质的结论是要画上地图、写进储量报告、签上名字的：**"不可追溯的高置信度"在地质里不是优势，是风险。** 因此这一条线在地质中的正确读法是"**方向信号 + 待验证假设**"，而不是可落地组件。

## 结语：可以用在汇报结尾的三句话

1. **地质 + AI 的本质问题不是"AI 能不能分类岩石"，而是"在观测稀疏、采样有偏、标签昂贵的条件下，能不能给出一个在空间上外推得动、在物理上说得通、在不确定性下可决策的地质结论"。**
2. **与传统 AI 的分界线在于：数据是解释性的、训练必须受空间与物理双重约束、评测必须以独立地质证据和概率可靠性为准绳。**
3. **"神经网络过时"说对了一半：作为判别式拟合器的神经网络正在被"表征预测（JEPA）+ 可干预世界模型"所取代；而它在地质上的真正落地形式，应当是"连续代理场学动力学 → 迁移到稀疏地质目标 → 支持 what-if 推演"的完整链条。**
