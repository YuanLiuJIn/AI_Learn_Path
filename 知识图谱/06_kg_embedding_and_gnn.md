# 06. 知识图谱嵌入与图神经网络

> 目标：理解 TransE、RotatE、ComplEx、R-GCN 等模型如何把图谱转成向量，并用于链接预测、相似度计算和推理。

## 1. 为什么知识图谱也需要 Embedding？

知识图谱是离散结构：

```text
(姚明)-[效力球队]->(火箭队)
(火箭队)-[所属联盟]->(NBA)
```

机器学习模型更擅长处理连续向量。

所以需要把实体和关系映射到向量空间：

```text
实体：姚明 → [0.12, -0.33, ...]
关系：效力球队 → [0.44, 0.08, ...]
实体：火箭队 → [0.55, -0.20, ...]
```

这叫 Knowledge Graph Embedding，简称 KGE。

## 2. KGE 解决什么任务？

### 2.1 链接预测

判断缺失关系。

```text
(药物A, 治疗, ?)
```

模型给出候选疾病排序。

### 2.2 实体补全

```text
(?, 出生地, 上海)
```

找可能出生在上海的人。

### 2.3 关系预测

```text
(阿司匹林, ?, 发热)
```

预测关系可能是“缓解”或“治疗”。

### 2.4 相似实体检索

```text
找和某药物相似的药物
找和某论文主题相近的论文
```

## 3. TransE：关系是平移

TransE 的核心假设：

```text
head + relation ≈ tail
```

例如：

```text
姚明 + 效力球队 ≈ 火箭队
巴黎 + 所属国家 ≈ 法国
```

打分函数：

\[
score(h, r, t) = -||h + r - t||
\]

越接近，三元组越可信。

优点：

```text
简单
高效
容易理解
适合一对一关系
```

缺点：

```text
不擅长一对多、多对一、多对多
不擅长复杂关系模式
```

## 4. DistMult：关系是维度加权

DistMult 使用双线性打分：

\[
score(h,r,t) = h^T diag(r) t
\]

直觉：

```text
关系 r 决定哪些维度更重要。
```

缺点：

```text
天然对称，不擅长反对称关系。
```

例如：

```text
(张三, 父亲, 李四)
```

不等于：

```text
(李四, 父亲, 张三)
```

DistMult 很难表达这种方向性。

## 5. ComplEx：用复数表达非对称关系

ComplEx 把实体和关系放到复数空间。

复数有实部和虚部，可以表达非对称模式。

适合：

```text
反对称关系
有方向的关系
更复杂的关系组合
```

## 6. RotatE：关系是旋转

RotatE 的核心思想：

> 在复数空间中，关系 r 表示从 head 到 tail 的旋转。

```text
head ⊙ relation ≈ tail
```

它能表达多种关系模式：

```text
对称关系
反对称关系
逆关系
组合关系
```

例如：

```text
父亲 和 孩子 是逆关系
位于 + 位于 可以组合成更长路径关系
```

RotatE 是理解关系模式建模的重要 KGE 模型。

## 7. 负采样：模型怎么训练？

真实三元组是正样本：

```text
(巴黎, 所属国家, 法国)
```

构造负样本：

```text
(巴黎, 所属国家, 德国)
(巴黎, 出生地, 法国)
(北京, 所属国家, 法国)
```

训练目标：

```text
正样本分数高
负样本分数低
```

## 8. KGE 的局限

```text
只利用三元组结构，文本语义用得少
对新增实体不友好
可解释性弱于规则推理
对图谱质量敏感
复杂约束难表达
```

所以现代系统常结合：

```text
文本 Embedding
图结构 Embedding
规则推理
GNN
LLM 判断
```

## 9. 图神经网络 GNN

GNN 的核心思想：

> 一个节点的表示，来自自己和邻居的信息聚合。

```text
节点 A 的新表示 = 聚合(自身表示, 邻居1, 邻居2, 邻居3)
```

多层 GNN 可以看到多跳邻居：

```text
1 层：一跳邻居
2 层：两跳邻居
3 层：三跳邻居
```

## 10. R-GCN：关系感知的 GNN

普通 GNN 没有区分边类型。

知识图谱里边类型很重要：

```text
出生地
任职于
治疗
引用
投资
```

R-GCN 为不同关系类型使用不同的变换。

```text
节点表示 = 按关系类型分别聚合邻居，再融合
```

适合：

```text
实体分类
链接预测
关系图表示学习
```

## 11. KGE vs GNN

| 维度 | KGE | GNN |
|---|---|---|
| 核心 | 三元组打分 | 邻居信息聚合 |
| 优点 | 简单高效，适合链接预测 | 能利用局部结构和节点特征 |
| 缺点 | 结构利用有限 | 训练更重，规模化更难 |
| 代表 | TransE、ComplEx、RotatE | GCN、GraphSAGE、GAT、R-GCN |

## 12. 一句话总结

> 知识图谱嵌入把实体和关系映射到向量空间，用于链接预测、实体补全和相似度计算。TransE 把关系看作平移，RotatE 把关系看作复数空间旋转，GNN 则通过邻居聚合学习节点表示。实际系统通常把规则推理、KGE、GNN 和文本语义结合使用。
