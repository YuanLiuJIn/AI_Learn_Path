# 380. 常数时间插入、删除和获取随机元素（Insert Delete GetRandom O(1)）

## 题目
实现 `RandomizedSet` 类：
- `RandomizedSet()` 初始化。
- `bool insert(int val)`：val 不存在则插入并返回 true；否则 false。
- `bool remove(int val)`：val 存在则移除并返回 true；否则 false。
- `int getRandom()`：等概率随机返回集合中的一项（调用时集合非空）。
- 要求三个函数**平均 O(1)**。

## 关键性质 / 难点
- 单一结构做不到三项全 O(1)：`unordered_map` 查/插/删 O(1) 但不能随机取；`vector` 能按下标随机取但中间 `erase` 是 O(n)。
- **配合**：`vector<int> nums` 存元素（随机取 O(1)）；`unordered_map<int,int> pos` 存 `值->nums 下标`（查/插/删 O(1)）。
- **remove 核心技巧**：要删 `val`（在 `nums[idx]`），把 `nums` 末尾元素 `last` 换到 `idx`，再 `pop_back`；同时更新 `pos[last]=idx`，删 `pos[val]`。这样就避免了 vector 中间删除的 O(n) 移动。

## 解法：vector + unordered_map（★）
```cpp
class RandomizedSet {
    vector<int> nums;
    unordered_map<int, int> pos;   // val -> index in nums
public:
    RandomizedSet() {}

    bool insert(int val) {
        if (pos.count(val)) return false;     // 已存在
        pos[val] = nums.size();               // 新下标 = 当前末尾
        nums.push_back(val);
        return true;
    }

    bool remove(int val) {
        if (!pos.count(val)) return false;     // 不存在
        int idx = pos[val];
        int last = nums.back();
        nums[idx] = last;                      // 末尾元素补到 idx
        pos[last] = idx;                       // 更新被移动元素的下标
        nums.pop_back();                       // O(1) 删末尾
        pos.erase(val);
        return true;
    }

    int getRandom() {
        return nums[rand() % nums.size()];     // 按下标等概率取
    }
};
```
> `getRandom` 用 `rand()` 在 LeetCode 能过；`rand()%n` 对大 n 有轻微偏差，面试可改用 `mt19937` + `uniform_int_distribution`（见下）。

### 更好的随机（面试加分）
```cpp
class RandomizedSet {
    vector<int> nums;
    unordered_map<int, int> pos;
    mt19937 rng{random_device{}()};
public:
    RandomizedSet() {}
    // insert / remove 同上
    int getRandom() {
        uniform_int_distribution<int> dist(0, (int)nums.size() - 1);
        return nums[dist(rng)];
    }
};
```

## 推演（题目示例）
操作序列：`insert(1), remove(2), insert(2), getRandom, remove(1), insert(2), getRandom`
- `insert(1)`：pos={1:0}, nums=[1] → true
- `remove(2)`：2 不在 pos → false
- `insert(2)`：pos={1:0,2:1}, nums=[1,2] → true
- `getRandom`：返回 nums[0] 或 nums[1]，即 1 或 2
- `remove(1)`：idx=0, last=2 → nums[0]=2 → nums=[2]; pos[2]=0; pop→nums=[2]; erase(1)→pos={2:0} → true
- `insert(2)`：2 已在 pos → false
- `getRandom`：nums=[2] → 2

## 易错点（写代码时注意）
1. **remove 不能 `nums.erase(nums.begin()+idx)`**：那是 O(n) 移动，且破坏 O(1) 要求。必须用「末尾交换 + pop_back」。
2. **交换后务必更新 `pos[last]`**：只删 `pos[val]` 不更新末尾元素的新下标，下次操作 `last` 会用到错误下标 → 数据错乱。
3. **val 恰为末尾元素时的自交换**：`idx == nums.size()-1` 时 `last==val`，`nums[idx]=last` 是自赋值无害，`pos[last]=idx` 再 `pos.erase(val)` 顺序正确（先更新后删，因 last==val 时更新后会被删，vector 已 pop）。无需特判。
4. **等概率靠 vector 下标**：每个元素在 `nums` 中只占一个下标，`rand()%size` 每个下标等概率 → 每个元素等概率。若用 map 遍历随机则非均匀且慢。
5. **`rand()` 需 `#include <cstdlib>` 且通常配合 `srand`（LeetCode 自带）；用 `mt19937` 需 `#include <random>`**。
6. **重复 `insert`/`remove` 返回 false**：靠 `pos.count(val)` 判断存在性，别只查 `nums`（O(n)）。

### ① 致命：成员声明在构造函数里（局部变量 vs 类成员）
`vector<int> nums;` 写在构造函数体内 = 构造函数的**局部变量**，构造结束即销毁；而成员函数里用的 `nums`/`pos` 是**类成员**，类体根本没声明 → 编译「未声明标识符」。
正确：成员声明在类体顶部：
```cpp
class RandomizedSet {
    vector<int> nums;              // 成员
    unordered_map<int, int> pos;   // 成员
public:
    RandomizedSet() {}             // 构造函数只做初始化，不负责声明
    ...
};
```
### ② 拼写 `unorderd_map` → `unordered_map`
### ③ 拼写 `pushback` → `push_back`（vector 成员带下划线）
### ④ `nums.pushback();` 应为 `nums.pop_back();`（删末尾、无需参数）
### ⑤ `round()` → `rand()`：round 是 <cmath> 四舍五入；随机数是 <cstdlib> 的 rand()
### 结论
insert/remove/getRandom **逻辑全对**（顺序、更新、判重都正确），纯被 5 个拼写/声明问题卡住。修正即通过。
