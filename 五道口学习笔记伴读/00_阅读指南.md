> 这个文件夹有 **650+ 个 notebook、7 个一级目录**，原始结构是按"主题"堆的，没有告诉你要**按什么顺序看**。本指南把它重组为一条**按依赖关系排好的学习动线**，并标注每个阶段去哪个子目录读。

> 伴读说明：本文件夹（`五道口学习笔记伴读`）与原始库 `modern_genai_bilibili` 配套使用——指南负责"去哪看、按什么顺序"，各 `0x_*.md` 负责把核心原理讲透。

## 0. 先理解 up 主的设计哲学（很重要）

README 里写得很清楚，整个系列有三个坚持：

1. **原理先行**：优先讲"一般、底层、不会很快过时"的概念，而非追热点工具。
2. **三条主线**：`Modern Agents` / `Agentic RL Post-training` / `LLMs 基础与训练`。
3. **更新优先级**：基本概念/原理 > 通用实用技术/工具 > 应用/项目。

所以：**不要一上来就读 agents/ 或 llms/ 里最花哨的项目**，先打数学 + PyTorch + 核心概念的底子，否则后面全是"知其然不知其所以然"。

## 2. 推荐学习动线（按依赖关系）

```
Phase 0  数学 + PyTorch + 核心概念   ← 必看，打底
   │
Phase 1  LLMs 基础（架构/训练/多模态/可解释）
   │
Phase 2  Agents 基础（prompt→context→rag→tools→multi-agent）
   │
Phase 3  Agentic RL 后训练（RL基础→PPO→GRPO→verl→落地）
   │
Phase 4  工程素养（环境/docker/python/leetcode）
```

**为什么是这个顺序**：LLM 是 Agent 的"身体"，Agent 是 LLM 的"用法"，Agentic RL 是让这两者"变强"的后训练手段。数学/PyTorch 是所有东西的地基。工程素养随时补，不阻塞主线。

## 3. 每个 Phase 具体读什么（精确到子目录）

### Phase 0 · 数学与 PyTorch 基石
- 数学：`math/basics`、`math/matrix`（eigen/谱范数/SVD→LoRA）、`math/bayesian`、`math/calculus`、`math/markovian`、`math/graph`、`math/manifold`
- 采样与搜索：`math/` 里的 sampling（MC / importance sampling / MCMC）、search（AlphaGo / 树搜索）— 对应 README 的"三种方法范式"
- PyTorch：本库没有独立 PyTorch 文件夹，原理散在 `math/pytorch` 和各处代码；见伴读 `01_数学与PyTorch基石.md`
- 核心概念：README 的 core concepts（KL、on/off-policy、MC vs TD、bias-variance）+ 伴读 `02_核心概念.md`

### Phase 1 · LLMs 基础 → `llms/`
1. `llms/架构/`（最大，45 文件）：先 `transformer-auto-regressive.ipynb`、`prefill-decode.ipynb`、`pd-分离.ipynb`，再进 `attention/`（qkv → gqa → mla → linear_attn → dsa）、`moe/`、`optimizers/`、`pe/`、`tokenizers/`、`connection/`

3. `llms/多模态/`（29 文件）
4. `llms/可解释性/`

### Phase 2 · Agents 基础 → `agents/`
**严格按这个顺序**（从原子能力到系统）：
1. `agents/prompts/`（提示词基础）
2. `agents/context-engineering/`（21 文件，上下文工程——2024-2025 的核心范式）

## 5. 给"从零开始"者的 4 周速通建议

- **第 1 周**：Phase 0。数学扫一遍（重点 matrix/SVD/LoRA、sampling/IS），PyTorch 计算图与梯度流，核心概念（KL、on/off-policy）。
- **第 2 周**：Phase 1 LLMs 架构（transformer → attention 变体 → moe → prefill/decode），Phase 2 Agents 前半（prompts → context-engineering → rag）。
- **第 3 周**：Phase 2 后半（tools/mcp → reasoning/tree_search → multi-agents），开始 Phase 3 的 `deep_RL/` 地基。
- **第 4 周**：Phase 3 主线（PPO → GRPO → verl → training_practices 调参笔记），其余按需补。
