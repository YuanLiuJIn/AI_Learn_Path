# 大模型评测核心论文阅读路线

> 本路线整理自一份业界评测论文精选清单（共 24 篇，按分类组织），并结合本资料库已有的笔记与 PDF 重新编排，形成一条「由方法论到基准、再到工程工具」的渐进阅读路径。
>
> 趋势判断：评测重心已从单纯的「知识问答」转向**深度推理、超长上下文、多模态融合、以及中文语境精准对齐**——阅读顺序据此安排。

## 一、三条主线（分类总览）

| 主线 | 解决的问题 | 代表论文 |
|---|---|---|
| A. 综述与方法论 | 怎么科学地评测（底层逻辑、偏差控制、未来趋势） | 2303.18223 / 2307.03109 / 2211.09110 / 2411.15594 |
| B. 基准与数据集 | 能力「刻度」怎么定（推理/代码/Agent/多模态/中文/人类偏好） | MMLU / HumanEval / SWE-bench / AlignBench / Chatbot Arena |
| C. 专项领域与工程化工具 | 可信度、Agent、框架怎么落地 | TrustLLM / AgentBench / OpenCompass 2.0 |

阅读总原则：**先看方法论（A）→ 再按主攻方向选基准（B）→ 最后落到工具与闭环（C）**。

## 二、主线 A：综述与方法论

### A1. *A Survey of Large Language Models*（2303.18223）
- 内容：权威综述，覆盖模型架构、预训练、对齐、评估方法全链路。
- 价值：建立「模型怎么来 → 该怎么评」的整体地图。
- 本库对应：`核心能力图谱/01_模型架构与基本原理.md`、`07_训练与微调实操.md`、`doc/Survey_of_LLMs.pdf`
- 阅读重点：第 3–5 章（架构/预训练/对齐）、第 7 章（评估体系框架）。

### A2. *A Survey on the Evaluation of Large Language Models*（2307.03109）
- 内容：提出 **3W 评测体系**——**What to evaluate（评什么）/ Where to evaluate（在哪评，即数据集）/ How to evaluate（怎么评，即方法）**。
- 价值：这是评测岗的「元框架」，面试可用 3W 组织任何评测方案。
- 本库对应：`核心能力图谱/02_各模态评测与体系建设.md`、`doc/Survey_on_Evaluation_of_LLMs.pdf`
- 阅读重点：3W 框架定义、评测偏差（位置/长度/自我增强）小节。

### A3. *Holistic Evaluation of Language Models (HELM)*（2211.09110）
- 内容：用**统一场景 × 指标**矩阵做整体评测，定义 7 大指标族（准确性、校准性、鲁棒性、公平性、偏见、毒性、效率）。
- 价值：学会「用一组成正交指标而非单点分数」刻画模型。
- 本库对应：`06_数据化思维与基础评估指标.md`、`doc/HELM_Holistic_Evaluation.pdf`
- 阅读重点：指标族定义、场景×指标矩阵设计。

### A4. *A Survey on LLM-as-a-Judge*（2411.15594）
- 内容：系统梳理 AI 自动评分技术的核心挑战——位置偏差、冗长偏差、自我偏好、评分标准不统一。
- 价值：做自动评测/判别模型时的「避坑手册」。
- 本库对应：`05_Agent工具链与竞技场数据飞轮.md`（判别模型/裁判模型）、`核心能力图谱/02_各模态评测与体系建设.md`（判分方法）、`doc/Survey_LLM_as_a_Judge.pdf`
- 阅读重点：偏差类型表、缓解策略（Swap、Reference、Fine-tuned Judge）。

## 三、主线 B：基准与数据集

### B1. 逻辑、数学与深度推理
#### *MMLU: Measuring Massive Multitask Language Understanding*（2009.03300）
- 内容：57 学科、约 1.6 万道多选题，模型的「高考」基准，测知识与推理广度。
- 价值：知识类能力刻度标杆；理解「覆盖度」如何设计。
- 本库对应：`语言模型评测/学习笔记.md`、`08_常见评测数据集与方法.md`、`doc/MMLU.pdf`
- 阅读重点：学科覆盖设计、Few-shot 评测协议。

### B2. 代码、长文本与 Agent
#### *HumanEval*（2107.03374）
- 内容：164 道手写编程题，用**单元测试通过率（pass@k）**评测代码生成，代码评测鼻祖。
- 价值：理解「可执行判分」范式；pass@k 指标公式。
- 本库对应：`08_常见评测数据集与方法.md`、`doc/HumanEval.pdf`
- 阅读重点：pass@k 定义、功能正确性 vs 文本匹配。

#### *SWE-bench*（2310.06770）
- 内容：基于真实 GitHub Issue + PR，要求模型生成补丁并通过仓库既有测试，端到端工程能力评测。
- 价值：从「单函数」到「真实仓库」的评测跃迁，是 Agent/工程智能体评测核心集。
- 本库对应：`04_分阶段端到端评测.md`、`05_Agent工具链与竞技场数据飞轮.md`、`doc/SWE_bench.pdf`
- 阅读重点：测试驱动评测设计、Resolve Rate 指标。

### B3. 多模态与中文对齐
#### *AlignBench*（2311.18743）
- 内容：中文对齐权威榜单，多维度（逻辑推理/语言/知识/创作/数学/代码）用 LLM-as-Judge 打分。
- 价值：中文语境评测范式样本，理解「对齐」如何可量化。
- 本库对应：`多模态模型评测/学习笔记.md`、`08_常见评测数据集与方法.md`（中文集 C-Eval/CMMU/SuperCLUE 同列）、`doc/AlignBench.pdf`
- 阅读重点：多维度对齐设计、中文能力分层。

### B4. 动态与人类偏好
#### *Chatbot Arena*（2403.04132）
- 内容：基于用户**对战（side-by-side）+ Elo 评分**的开放式人类偏好排行榜，动态更新。
- 价值：理解竞技场机制、Elo/Bradley-Terry 建模、众测闭环。
- 本库对应：`05_Agent工具链与竞技场数据飞轮.md`、`doc/Chatbot_Arena_Open_Platform_for_LLM_Evaluation.pdf`
- 阅读重点：Battle data 收集、Elo 计算、Bootstrap 置信区间。

## 四、主线 C：专项领域与工程化工具

### C1. *TrustLLM*（2401.05561）
- 内容：可信度评测框架，覆盖**真实性、安全性、公平性、隐私、鲁棒性、机器伦理** 6 大维度。
- 价值：把「可信 AI」拆成可测维度，是安全/合规评测的抓手。
- 本库对应：`02_各模态评测与体系建设.md`（维度拆解）、`06_数据化思维与基础评估指标.md`、`doc/TrustLLM.pdf`

### C2. *AgentBench*（2308.03688）
- 内容：首个 AI Agent 综合评测基准，覆盖操作系统/数据库/知识图谱/网页/卡片/家居/LLM 等 8 类环境。
- 价值：理解 Agent 评测的「环境×任务」设计。
- 本库对应：`05_Agent工具链与竞技场数据飞轮.md`、`04_分阶段端到端评测.md`、`doc/AgentBench.pdf`

### C3. OpenCompass 2.0（评测框架，非论文）
- 内容：集成 **100+ 数据集**的开源评测框架，统一协议跑多模型、多数据集对比。
- 价值：企业选型与日常评测的工程底座，理解「框架如何把方法论落地」。
- 本库对应：`03_自动化评测工具开发.md`、`语言模型评测/README.md`（OpenCompass/harness）
- 链接：https://github.com/open-compass/opencompass

## 五、按场景的阅读建议（直接采用清单原建议）

| 你的目标 | 推荐路径 | 对应本库动作 |
|---|---|---|
| **学术调研 / 写综述** | A1 → A2 → A3 → (B 推理基准 MMLU) → A4 | 先建立框架，再深入基准 |
| **企业选型 / 日常评测** | C3（工具）→ B4（人类偏好 Arena）→ A4（Judge）→ B 对应方向集 | 先能跑，再对齐人偏好 |
| **做自动评测 / 判别模型** | A4 → C3 → B4 | 偏差控制 + 工具 + 偏好闭环 |
| **做 Agent / 工具链评测** | C2（AgentBench）→ B2（SWE-bench/HumanEval）→ C1（可信度） | 环境→任务→信任 |
| **中文场景对齐评测** | B3（AlignBench）→ `08章`中文集 → A2（3W） | 中文维度 + 数据集 |
