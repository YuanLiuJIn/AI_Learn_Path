# 02. AgentEvolver 详解：自助式进化三引擎

> 论文：AgentEvolver (阿里通义实验室，2025.11)
> 开源：github.com/alibaba/AgentEvolver
> 核心突破：14B 自进化模型的任务完成率从 29.8% 提升至 74.2%，超越 32B 静态模型

---

## 1. 核心问题：为什么传统 Agent 训练效率低？

```text
传统 RL 训练 Agent（如 GRPO）的三个痛点：

痛点 1：任务稀缺
  训练需要大量任务
  但人工设计任务成本高、覆盖不全
  导致 Agent 只会处理"见过的任务类型"

痛点 2：探索低效
  面对新任务时随机尝试
  大量尝试都是无用功
  样本利用率极低

痛点 3：奖励模糊
  传统奖励只在任务完成时给一个 0/1
  无法区分"哪一步做对了、哪一步做错了"
  导致训练信号稀疏、收敛缓慢
```

---

## 2. AgentEvolver 的三大机制

```text
┌──────────────────────────────────────────┐
│              AgentEvolver                 │
│                                          │
│  ① 自我提问（Self-Questioning）           │
│     自己给自己出题                         │
│     不需要人类设计训练任务                  │
│                                          │
│  ② 自我导航（Self-Navigation）            │
│     从过往经验中找"怎么做的参考"            │
│     不盲目探索，先找相似案例                │
│                                          │
│  ③ 自我归因（Self-Attribution）           │
│     每一步都给反馈，不只在终点给分           │
│     精细化告诉模型"这一步为什么对/错"       │
└──────────────────────────────────────────┘
```

---

## 3. 自我提问：自动生成训练任务

```text
核心思想：
  不需要人类给 Agent 设计任务
  Agent 自己根据已有能力生成合适的训练题

怎么做：

Step 1：分析当前能力
  Agent 回顾自己完成的最近 N 个任务
  分析："我在搜索类任务上成功率 85%，但在推理类只有 45%"

Step 2：生成针对性任务
  基于薄弱环节自动出题：
  "你擅长搜索？那我考你一个需要多步推理的搜索题"
  自动生成任务的难度梯度：
    太简单 → 没用
    太难 → 学不会
    刚好在能力边界 → 最佳学习区

Step 3：任务多样化
  不只是"换个参数"，而是"换个题型"
  比如从"找文档"升级到"对比两份文档的差异"
```

---

## 4. 自我导航：经验复用

```text
核心思想：
  面对新任务时，不要从零探索
  先去经验库里找"最相似的过往任务"

怎么做：

Step 1：经验编码
  每完成一个任务 → 记录完整轨迹：
    {任务描述, 操作序列, 成功/失败, 关键决策点}
  所有记录存入经验库（向量数据库）

Step 2：相似任务检索
  新任务来了 → 向量检索最相似的过往任务
  → 直接参考成功的操作序列
  → 避开失败的操作模式

Step 3：轨迹引导
  不是完全照抄过往经验
  而是："上次类似任务，前两步是检索+分析，
        第三步是关键决策。前两步可以直接复用，
        第三步根据当前情况调整。"
```

---

## 5. 自我归因：精细化反馈

```text
核心思想：
  不只在任务结束时给一个 0/1
  每一步都给细粒度的质量评估

对比：

传统奖励（终点奖励）：
  Step 1: 搜索 "X" → 无反馈
  Step 2: 分析 → 无反馈
  Step 3: 搜索 "Y" → 无反馈
  Step 4: 回答 → 答对了！奖励 +1
  问题：前三步谁有用、谁浪费？不知道。

AgentEvolver 的自我归因：
  Step 1: 搜索 "X"
    → 归因：搜索关键词精准，结果高度相关 → +0.3
  Step 2: 分析
    → 归因：分析逻辑正确，抓住了关键信息 → +0.3
  Step 3: 搜索 "Y"
    → 归因：这步搜索是多余的，前两步已经够了 → -0.1
  Step 4: 回答
    → 归因：答案完整准确 → +0.4

  效果：模型每一步都知道"这一步对不对/好不好"
        训练信号密集 3-5 倍，收敛速度快得多
```

## 6. 效果数据

```text
实验设置：
  基座模型：14B 参数
  任务类型：多步推理、信息检索、工具调用组合

结果：
  初始状态（SFT 后）：任务完成率 29.8%
  AgentEvolver 进化后：任务完成率 74.2%（+149%）
  
  对比：直接用 32B 模型的任务完成率低于 74.2%
  
  含义：
    一个会自进化的 14B"小模型"
    通过自我练习 + 自我反思
    超越了不会自进化的 32B"大模型"
```

## 7. 和 GRPO 的本质区别

```text
GRPO（我们之前详细讨论过）：
  给 Agent 任务 → 生成 N 个候选序列 → 奖励打分 → 优化
  解决的是"同一任务，哪个策略更好"的问题

AgentEvolver 在 GRPO 之上新加了：
  ① 自动生成任务（不需要人喂任务）
  ② 经验复用（不需要盲目探索）
  ③ 精细归因（每一步都有质量信号）

GRPO = 学会"怎么做更好"
AgentEvolver = 学会"给自己出题 + 从经验学 + 精细反思"
```

## 8. 一句话总结

> AgentEvolver 让 Agent 变成了"会自学的学霸"：自己给自己出题（自我提问）、翻以前的笔记参考（自我导航）、每道题分析每一步的得失（自我归因）。14B 的学霸超越了 32B 的普通人。
