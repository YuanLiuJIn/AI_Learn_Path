# 55. 跳跃游戏（Jump Game）

## 题目概述
数组 `nums`，`nums[i]` 表示在下标 `i` 最多能往前跳 `nums[i]` 步。初始在下标 0，判断能否到达**最后一个下标**。

示例：
- `[2,3,1,1,4]` → 0→1→4，**true**
- `[3,2,1,0,4]` → 必卡在下标 3（跳 0 步），到不了 4，**false**

---

## 你的代码与错误
```cpp
bool canJump(vector<int>& nums) {
    if(nums[0]=0){return false;}            // ① 赋值=、逻辑错、污染数组
    for(int zero=0;zero<nums.size();zero++)
    {
        if(nums[zero]==0)
        {
            for(int i=0;i<zero;i++)
            {
                if(nums[i]!=zero-i)         // ②③ 条件错、运算符错
                {return true;}
                else {return false;}        // ④ 内层首轮就 return，只看 i=0
            }
        }
    }
    // ⑤ 缺结尾 return
}
```

### ① `nums[0]=0` 是赋值不是比较，还污染数组
- `=` 是赋值：把 `nums[0]` 改成 0，表达式返回 0 → `if` 判假、不进块，等于**悄悄改坏数据**又没起到判断作用。应为 `==`。
- 即便改 `==` 逻辑也错：`nums=[0]`（长度 1，起点即末尾）应返回 **true**，不能一刀切 false。

### ②③ 越零条件写错
从 `i` 跳过位于 `zero` 的 0，需 `i + nums[i] > zero`（落点严格超过 0），即 `nums[i] > zero - i`。你写 `nums[i] != zero - i`：运算符（`!=`）与方向（`>`）都错。

### ④ 内层循环首轮就 return，只看 i=0
`if...return true; else return false;` 在 `for(i=0;...)` 第一轮即返回，后面 `i=1,2,...` 永不检查 → 遇到 0 只看了下标 0 能否跳过，漏掉更靠后的起跳点。

### ⑤ 缺结尾 return
数组无 0（全正数）时循环走完无任何 return → 走到非 void 函数末尾 = 未定义行为/编译告警。每个分支都要有返回值。

---

## 正确解法（贪心）

### 解法一：前向贪心（推荐）
维护「当前能到达的最远下标 `maxReach`」：
```cpp
bool canJump(vector<int>& nums) {
    int n = nums.size();
    int maxReach = 0;
    for (int i = 0; i < n; i++) {
        if (i > maxReach) return false;          // 连 i 都到不了
        maxReach = max(maxReach, i + nums[i]);   // 更新最远可达
        if (maxReach >= n - 1) return true;      // 已能到末尾
    }
    return true;
}
```
- 时间 O(n)，空间 O(1)。

### 解法二：后向贪心（更精炼）
从末尾倒推目标点 `last`，能跳到 `last` 就把目标前移到 `i`：
```cpp
bool canJump(vector<int>& nums) {
    int last = nums.size() - 1;
    for (int i = nums.size() - 2; i >= 0; i--)
        if (i + nums[i] >= last) last = i;
    return last == 0;
}
```
- `[2,3,1,1,4]`：`last` 4→1→0，返回 true。
- `[3,2,1,0,4]`：`last=4` 前面无人能跳到 → 停在 4，返回 false。

## 需要补的知识点
| 点 | 说明 |
|---|---|
| `=` vs `==` | 赋值是语句/表达式返回值，比较才是判断；条件里用 `==` |
| 非 void 必返回 | 所有分支（含循环正常结束）都要有 return |
| 贪心可达性 | 维护最远可达下标，不必模拟每一步 |
| 越零条件 | 跨过 0 需 `i+nums[i] > zero`（严格超过） |
