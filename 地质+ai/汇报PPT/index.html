PART 1 · 三个问题
07 / 28

三个结构性问题，决定了「换范式」不是追新名词

01 · 观测稀疏且有偏
单井成本百万级，采样点由道路、矿区、经费决定，不是由地质问题决定。

因此「数据越多越好」在这里不成立——先要问清数据是怎么被选出来的。

2,099
02 · 空间 i.i.d. 不成立
托布勒地理学第一定律：近处相似。随机切分让测试集与训练集空间相邻，分数虚高。

正确做法是空间分块 CV、leave-location-out、按井切分——代价是精度数字会掉。

17.1%
03 · 端到端判别在域外就崩
换地区、换年代、换传感器即失效——因为模型学的是这张图的纹理，不是支配它的过程。

这也是为什么「泛化」在本领域需要用跨构造单元、跨年代来定义，而不是随机留出。

46.2%

PART 2 · 三条改法
10 / 28
可操作的三条改法

把三个环节换掉，其余照旧

01
验证方式：空间分块替代随机切分

留出整块空间单元、留下整口井。GeoFWI 用留出井位做检验，得到的分数才是可迁移能力的下限。

02
损失函数：数据项 + 物理残差

PDE 残差、守恒律、边界条件当正则；同时输出校准过的概率，而不是一个点估计。PINN / SciML 目前占 5.9%。

03
训练方式：冻结骨干 + 轻量适配

基础模型权重公开，冻结约 97% 参数、只训回归头即可迁移——单卡可复现，是个人研究者最现实的入口。

PART 2 · 预训练目标速查
11 / 28
六个模块 · 从最卷到最空

哪一格已经做烂，哪一格还有空间

01
数据层 最卷

谁掌握图文 / 多模态数据集，谁就定义了这个领域的入口。

02
输入端 最卷

时间、光谱、尺度、传感器编码——遥感的专属主战场，已充分竞争。

03
骨干网络 大厂占坑

GraphCast、Pangu、Aurora 已占位；个人很难在此建护城河。

04
预训练目标 有空

掩码重建、对比学习、模态对齐已经做烂；物理残差是唯一还有大空间的一格。

05
适配接口 相对空白

LoRA、Prompt 在地学还没做透；已有工作证明冻结骨干即可迁移。

06
评测体系 刚起步

缺统一的划分协议、诊断指标与泄漏审计——是低竞争、高价值的切入面。

PART 2 · 可微闭环
12 / 28
正演 → 反演 → 不确定性 → 决策

把地质链路做成一个可微闭环

01 · 正演
d = F(m)：从模型参数生成合成观测，可微、可批量、可加速。
02 · 反演
m̂ = arg min ‖F(m) − d‖：数据项之外加物理残差与先验正则。
03 · 不确定性
输出后验或误差条：没有不确定性的反演结果无法进入决策流程。
04 · 决策与观测设计
决定下一个钻孔打在哪：主动采样、贝叶斯实验设计，再回到正演。
工具已经就位：Deepwave、PyLops、Devito 提供可微正演算子；N4 走端到端成像，Ambient Noise FWI 直接用神经算子替代正演——个人研究者可以站在这些算子上做方法创新。

PART 3 · 通用模型
15 / 28
所谓「方向 F」，其实是三种不同的东西

把它们混为一谈，是最常见的一类误读

A · KNOWLEDGE
语言知识型

把地学文献与图件知识压进语言模型，做检索、问答、抽取与编排。
不产生地质预测，本质是懂地质的检索写作工具。
GeoGPT · 元古 · OneStrata · 葱岭·智寻

B · REPRESENTATION
感知表征型

大规模自监督预训练得到统一表征，冻结后迁移到下游任务。
目前唯一被实验证据支持的「通用」。
Aurora · TerraMind · Prithvi-EO-2.0 · DOFA · Clay

C · WORKFLOW
业务系统型

把 A、B 与数值模拟串成工作流，做流程编排与人机协同。
能力上限由下两层决定，多是工程发布、部分不入期刊统计。
AI-GeoMapping · Autonomous GIS · Destination Earth

PART 3 · B 类展开
16 / 28
Earth Foundation Model · 感知表征型

它到底在干什么：五个环节

01 · 输入
海量无标注影像：光学、SAR、DEM、时序，不需要任何标签。
02 · 自监督预训练
掩码重建、对比学习、时序对比——目标函数里没有地质标签。
03 · 通用表征
得到一套公开权重：把任意影像压成可复用的特征表示。
04 · 迁移方式
冻结探测（只训线性头）或 LoRA / Adapter 轻量适配。
05 · 下游任务
地物分类、变化检测、灾害痕迹识别、形变与蚀变信息提取。
冻结线性探测是验证表征质量的硬证据：骨干完全不动还能达标，才说明表征本身有用。但它学的是地表纹理与光谱统计，不认识岩性成因——地表通用，不等于地下通用。
PART 3 · 判据
17 / 28

「通用」要拿证据证明，不是靠 IoU 数字

01
跨域外推

跨构造单元、跨年代、跨传感器、跨分辨率——同一套表征能否守住精度。

02
物理一致性

守恒量诊断、功率谱、外推区不出现非物理图案。

03
概率可信

校准曲线、可靠性图、Molchan 图：说 80% 把握就该有 80% 命中。

04
专家盲测

与地质学家的独立判断对照，看一致性究竟有多高。

基础模型的三道门槛：广泛预训练（覆盖多任务多模态）、超越单任务（不是某个任务的专用网络）、有迁移适配证据（冻结或轻量适配即可达标）。目前只有 B 类同时满足。

C · 遥感填图 15.2%

D · 勘探反演 4.6%
合成数据训练 ≠ 真实反演能力

合成分布与真实地下存在域差距，缺井震标定这一环，指标无法外移。

E · 地灾易发性 13.8%
随机切分让指标虚高

F · 通用模型 4.1%
通用边界止于地表

地下没有真值、没有共享坐标系；Prithvi-EO-2.0 一类覆盖的是地表观测。

G 水文地质 / 环境地球化学 20.9% 是当前最热，H 地球动力学与深部结构 10.5% 最靠近地质机理、也最容易被一区接受；上面六类共同的存疑都落在域外——跨尺度、跨域、无真值、切分方式。
PART 3 · 存疑清单
19 / 28
8 条存疑 · 汇成 4 类 · 主动交代边界

论文各自成立，但几乎都在「域外」处存疑

01
跨尺度外推 B · N1 / N2 / N3

实验室破裂实验与天然断层差数个数量级；「追踪剪应力演化」目前属事后解释，外推能力未被验证。

02
跨域泛化 D · GeoFWI / N4 / EFKAN

合成数据训练的模型与真实地下存在域差距、缺井震标定；SHAP / KAN 给的是贡献度与结构许诺，不是因果证据。

03
无真值可依 A · OGR VAE / F · N8

无监督化探异常没有真值、阈值任意；基础模型的「通用」边界是地表观测，地下既无真值也无共享坐标系。

04
切分与标签有偏 A / C / E 共性

空间自相关下随机切分造成信息泄漏、AUC 虚高；图件标签与验证标签同源，结论被自己的假设托住。

这组整理的意义只有一句：汇报时说明「我们知道边界在哪」，比列举准确率更有说服力。

平台发布、行业系统

一条保守但可靠的顺序

在表征空间预测未来不重建像素，只预测被预测变量的表示——避开把算力花在雨滴纹理上。
World Model
如果我做 X，会发生什么引入 action 才能回答 what-if：水库蓄水、注采、开挖——地质本就在做这些提问。
Decision Model
输出带校准概率的类型化判断Jev 走「判断」而非「生成」：结构即契约，输出不越出 schema。
三者的分工，比任何一个产品本身都更值得注意：JEPA 管世界怎么演化，世界模型管干预的后果，决策模型管此刻该判什么。

Layer 1 换目标 → Layer 2 加动作 → Layer 3 做伙伴

可执行的三层融合路线

LAYER 01 · 短期
表层替换：把预训练目标从「重建 / 判别」换成表征预测
在连续场上做 JEPA 式潜变量预测，下游迁移到稀疏地质目标（岩性、矿化、断层）；评价沿用 M-JEPA 协议：冻结骨干 + 两个对照组 + 物理诊断。
CKA · 功率谱 · FSS
LAYER 02 · 中期
中层升级：给模型加「动作」，做 Action-Conditioned Surrogate
不需要人工标注干预数据，把自然发生的地质状态变化本身当作 action 监督：开采前后的 InSAR 时序、地震前后的应力 / 孔压场、剥蚀前后的地貌。
what-if · 支持决策
LAYER 03 · 长期
深层重构：从「预测器」走向可交互的科学推理伙伴
三条线索合并：JEPA 表征 + 冻结迁移｜物理残差 / 可微正演做硬约束｜LLM 与多模态做地质知识与跨源证据的组织层。
表征 + 物理 + 知识
三层的顺序不能颠倒：没有 B 类感知层把地质数据压成向量，决策层在地质里就没有接口——感知层是决策层落地的前置条件。

三条边界 · 也是三条自检项

别把别的领域的成功直接搬到地质

边界一 · 领域差异
连续场成功 ≠ 地质成功

视频与机器人世界的连续场预测，误差几个数量级地优于离散 token 预测；但地质目标是稀疏的、带噪的、多解的——指标好看不等于地质可用。

01
边界二 · 物理约束
干预有效性必须物理校验

JEPA 至今没有在各领域都经过充分验证的干预有效性方案；物理残差项因此不能省——它是模型在无标签处学习物理一致性的唯一接口。

02
边界三 · 基本功
别为追新名词丢掉基本功

2024 年可解释性与不确定性量化占 17.1%，几乎追平传统机器学习的 20.3%；在稀疏观测下给出可信区间，比再涨一个准确率点更有价值。

03
Jevons 那条「神经网络已过时」是方向信号，不是可落地的组件：只给概率、不给理由、缺少一手实验证据——对地质而言，不可追溯的高置信度本身就是风险。

TAKEAWAYS
03 RULES
01

三条边界要写进方法里

解释性数据、空间 + 物理双约束、以独立地质证据与概率可靠性为准绳——不是口号，而是三个可检查的环节。

02

落地形态是分层通用，不是「一个模型包打天下」

冻结骨干 + 轻量适配是个人研究者最现实的入口；感知层是决策层落地的前置条件，业务系统型则是现阶段唯一有公开证据的类别。

03

「神经网络过时」说对了一半

判别式拟合确实退居其次，真正的形态是：连续代理场学动力学 → 迁移到稀疏地质目标 → 支持 what-if 推演与决策。
