# 121. 买卖股票的最佳时机（Best Time to Buy and Sell Stock）

## 题目概述
数组 `prices`，`prices[i]` 是第 i 天价格。只能「某天买、未来某天卖（卖在买之后）」，求最大利润；无利润返回 0。

示例：
- `[7,1,5,3,6,4]` → 买 day1(1) 卖 day4(6) → 利润 **5**
- `[7,6,4,3,1]` → 一直跌 → **0**

---

## 你的代码与错误
```cpp
int maxProfit(vector<int>& prices) {
    int tmp=0;int max =0;
    for(int slow=0;slow<prices.size();slow++)
    {
        for(int fast=0;fast<prices.size();fast++)   // ① fast 从 0 开始
        {
            if (prices[fast]<prices[slow]){continue;}
            tmp = prices[fast]-prices[slow];
            if(max<tmp){max =tmp;}
        }
    }
    return max;
}
```

### ① 核心 bug：fast 允许 < slow（先卖后买，时间颠倒）
- 题意「买在 slow、卖在 fast 且 fast 是未来」，但内层 `for(fast=0;...)` 让 `fast` 可小于 `slow` → 先卖后买，非法。
- `if(prices[fast]<prices[slow]) continue;` 只挡「卖价<买价」（利润为负），**没挡「fast 在 slow 前且价格更高」**，后者是虚假正利润。

#### 反例（你的代码答错）
`prices = [100, 1, 50]`
- 正确（先买后卖）：买 day1(1) 卖 day2(50) → **49**。
- 你的代码：`slow=1`(价1) 时 `fast=0`(价100)，`100>=1` 不跳过 → `tmp=100-1=99`（day0 卖、day1 买，时间颠倒）→ 返回 **99** ❌。

### ② 次要：`max` 变量名易与 `std::max` 冲突
`int max=0;` 能编译，但若后续写 `max(max, tmp)` 会与 `std::max` 歧义。建议改名 `maxPro`/`ans`。

---

## 正确解法

### 解法一：双重循环，fast 从 slow+1 起（O(n²)，仅保证正确）
```cpp
int maxProfit(vector<int>& prices) {
    int maxPro = 0;
    for (int slow = 0; slow < prices.size(); slow++)
        for (int fast = slow + 1; fast < prices.size(); fast++) {  // ✅ 只在买入后卖
            int tmp = prices[fast] - prices[slow];
            if (tmp > maxPro) maxPro = tmp;
        }
    return maxPro;
}
```

### 解法二：一次遍历，维护历史最低价（O(n) ★推荐）
```cpp
int maxProfit(vector<int>& prices) {
    int minPrice = INT_MAX, maxPro = 0;
    for (int p : prices) {
        minPrice = min(minPrice, p);        // 更新历史最低买入价
        maxPro = max(maxPro, p - minPrice); // 用今天价算利润并更新最大
    }
    return maxPro;
}
```
- 时间 O(n)，空间 O(1)。`n<=10^5` 解法一会 TLE，解法二安全。

---

## 需要补的知识点
| 点 | 说明 |
|---|---|
| **时间约束** | 「卖在买之后」= 内层 fast 必须从 slow+1 起，不能全范围扫 |
| **O(n²) 风险** | `n<=10^5` 时双重循环会超时，需 O(n) 一次遍历 |
| **最低价思维** | 最大利润 = `当前价 - 历史最低价`，边走边维护 minPrice |
| **变量命名** | 避免用 `max`/`min` 作变量名，防止与 `std::max` 冲突 |

见开头代码。核心 bug：内层 `fast` 从 0 起，允许先卖后买，guard 只挡负利润未挡时间颠倒，反例 `[100,1,50]` 返回 99（应为 49）。修复：fast 从 `slow+1` 起（解法一），或改用一次遍历维护最低价（解法二）。另建议 `max` 改名避免与 `std::max` 冲突。

## 你的提交分析 2（2026-08-07，改一次遍历后重交）
```cpp
int maxProfit(vector<int>& prices) {
    int minp=INT_MAX;int maxp=0;int tmp=0;int fin =0;
    for(int p:prices) {
        minp=min(minp,p);
        maxp=max(p,maxp);
    }
    return maxp;
}
```

### Bug 1：返回的是「最高价」不是「利润」
`return maxp;` 返回数组最高价；题目要求**差价（利润）**。即便顺序对也应返回 `maxp - minp`，不是 `maxp`。
- 例 `[1,2]`：`minp=1,maxp=2`，返回 2；正确应为利润 1。

### Bug 2（更要命）：全局最低价/最高价各自独立，丢了时间顺序
分开维护 `minp`（全局最小）与 `maxp`（全局最大）→ 要求「先买后卖」时最低价必须在最高价**之前**，但全局统计不保证这点。
- 例 `[7,6,4,3,1]`（一直跌）：`minp=1, maxp=7`，返回 7；正确应为 **0**（不能先卖后买）。
- 例 `[100,1,50]`：全局 max=100(day0)、全局 min=1(day1)，返回 100；正确 49。

### 正确写法：利润相对「运行中的最低价」算
```cpp
int maxProfit(vector<int>& prices) {
    int minp = INT_MAX, maxPro = 0;
    for (int p : prices) {
        minp = min(minp, p);            // 历史最低买入价（一定在今天或之前）
        maxPro = max(maxPro, p - minp); // 今天卖出利润，取最大
    }
    return maxPro;                      // ✅ 返回利润
}
```
- `minp` 是「到今天为止」最低价 → `p - minp` 天然满足先买后卖。
- 一直跌时每天 `p-minp<=0`，`maxPro` 保持 0，正确。
