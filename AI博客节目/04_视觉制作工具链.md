# 视觉制作工具链

## 推荐工具

### 代码驱动动画（核心工具）

| 工具 | 语言 | 适合场景 | 学习成本 |
|---|---|---|---|
| **Manim** | Python | 数学公式推导、矩阵动画、向量空间可视化 | 中 |
| **Motion Canvas** | TypeScript | 架构图、流程图、对比动画、时间线动画 | 中 |
| **Remotion** | React/TS | 片头片尾模板、字幕样式、批量视频生成 | 低 |

### 传统剪辑软件

| 工具 | 用途 | 价格 |
|---|---|---|
| **DaVinci Resolve** | 最终合成、调色、音频处理、Fusion 特效 | 免费 / Studio $295 |
| **DaVinci Resolve Python API** | 自动化剪辑、批量加字幕、渲染 | 需 Studio 版 |
| **OBS Studio** | 录屏、录 PPT、录游戏 | 免费 |

### AI 辅助工具

| 工具 | 用途 |
|---|---|
| **Whisper** | 自动生成字幕（本地运行，免费） |
| **Edge TTS / ElevenLabs** | AI 配音 |
| **LLM** | 生成初稿脚本、翻译、摘要 |

## 工作流建议

```text
1. 写脚本（Markdown）
   LLM 辅助生成初稿 → 人工修改 → 标注每一段的视觉需求

2. 做 PPT 大纲（Keynote / PowerPoint）
   快速确认每期的内容框架和视觉风格

3. 做动画
   公式推导 → Manim
   架构图/流程图 → Motion Canvas
   片头片尾 → Remotion

4. 录屏（OBS）
   代码演示
   项目演示（UE5）

5. 录音
   专业麦克风 + Audacity 降噪

6. 生成字幕（Whisper）
   自动生成 SRT 字幕

7. 合成（DaVinci Resolve）
   所有素材合成 + 调色 + 音频处理

8. 渲染输出
   1080p / 4K，H.264
```

## 第一期制作建议

从方向一第 4 期（Attention 机制）开始：

```text
原因：
  1. Attention 是大模型的心脏
  2. 有极好的视觉表达空间（QK^T 动画、softmax 热力图）
  3. 容易做 Hook："它"指的是书还是桌子？
  4. 和方向二的 Transformer 论文精读可以复用大量素材
```
