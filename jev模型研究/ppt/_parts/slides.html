官方定义：a frontier-intelligence function call，即「前沿智能的函数调用」

01
WHAT IT IS
官方定义
a frontier-intelligence function call（前沿智能的函数调用）：输入非结构化状态，输出带类型的概率判断。
02
INPUT
输入
一个共享 state（字符串 / JSON / 数组）+ 若干 typed questions，一次请求可混用三类原语。
03
OUTPUT
输出
类型化值 + 概率分布（Choice / Score 另给 confidence），无字符串输出。
04
三类原语 01
Choice
在你给的封闭选项里选一项（最多 255 项），返回完整概率分布。
05
三类原语 02
Score
按你自定义的有序量表打分，返回分值 + 落入的档位。
06
三类原语 03
Noul
是 / 否 二值判断，返回一个 0–1 的概率。
技术优势 01 · 并行求值
技术优势 02 · 问题互相隔离
技术优势 03 · 结构即契约

05 / 06 · REFLECTIONS

边界 · 迷雾 · 可做

01 / LIMITS
能力边界
只给判断不给理由 → 不可审计、不可追溯
问题之间无共享推理 → 不能让 Q2 依赖 Q1 的结论，没有链式判断
不做扩展推理 → 单个问题不能是「长链思考」，只能是 gut-check 级判断
WHERE IT STOPS
02 / MISSING
官方隐藏了什么？
架构细节 → 只说「new model architecture + parallel sampler」，无规模、无 tokenizer、无数据来源
confidence 的确切定义 → Choice 同时返回 probabilities 和 confidence，但 confidence 是 max p、熵还是二阶量——未定义；你无法设阈值，也就无法做置信度门控
WHAT'S MISSING
03 / TAKEAWAY
我们能用来做什么？
参考架构，改进地质或者定制软件的 confidence，解决黑盒问题
参考 DeepSeek 加上多模态组件，增强 VLA 判断功能
WHAT WE CAN TAKE
边界决定能不能用 · 迷雾决定敢不敢信 · 可做决定从哪一步开始
