## 1. Forward KL vs Reverse KL（最常被搞混）

这是理解"为什么 RLHF 会 mode collapse、为什么 SFT 不会"的关键。

```
D_KL(P ‖ Q) = Σ P(v) [log P(v) − log Q(v)]   ← Forward KL (P 在前)
D_KL(Q ‖ P) = Σ Q(v) [log Q(v) − log P(v)]   ← Reverse KL (Q 在前)
```

### 1.1 监督学习用 Forward KL，RL 用 Reverse KL
- **监督学习（SFT）≈ 最小化 `D(P‖Q)`**：P 是数据分布，从 P 采样来拟合 Q。P 有质量的地方 Q 必须都覆盖 → **mode-covering**（覆盖所有模式，但可能模糊/平均）。
- **最大熵 RL ≈ 最小化 `D(Q‖P)`**：Q 是策略，从 Q 采样去靠近"真分布/最优分布" P。Q 只在自己有质量的地方拟合 P → **mode-seeking**（聚焦最高概率模式，但容易塌缩到一个 mode）。

```python
# 库里 kl_数值内涵.ipynb 的代码骨架
log_q = log_softmax(logits, dim=-1)        # 模型分布 Q
log_p = log_softmax(ref_logits, dim=-1)    # 参考分布 P
kl = F.kl_div(log_q, log_p, reduction="none", log_target=True)
# 注意：F.kl_div(input=log_q, target=log_p) 算的是 D(P‖Q)（forward）
# 单位：nats/token，是对词表空间求和，不取平均
```

### 1.2 为什么要关心
- **Align tax（对齐税）**：RLHF 用 reverse KL 倾向 mode-seeking，输出多样性下降（熵降低）→ 模型变"死板"，损失通用创造力。这正是 `rft.ipynb` 里讲的灾难性遗忘/对齐税的来源。
- **KL 惩罚项**：PPO 的 `L = E[r − β·log(π_θ/π_ref)]`，KL 项约束策略别偏离参考太远，正是为了**对抗 reverse KL 的过度 mode-seeking**。

## 2. On-policy vs Off-policy

| | 采样策略 = 更新策略？ | 样本可复用？ | 代表 |
|---|---|---|---|
| **On-policy** | 是 | 否（更新后旧样本失效） | 原始 PG、PPO（广义 on-policy） |
| **Off-policy** | 否（用回放池 μ 采样） | 是 | Q-learning、DQN |

**重要性采样是桥梁**：off-policy 训练必须用 IS 权重 `π/μ` 纠正"行为策略≠目标策略"的偏差（连回 `01` 的 IS）。
- 库里：`deep_RL/onpolicy_offpolicy.ipynb`、`online_offline.ipynb` 专门讲这套。

## 3. MC vs TD（值函数估计的两极）

| | 估计方式 | 偏差 | 方差 | 代表 |
|---|---|---|---|---|
| **MC（蒙特卡洛）** | 用整轮真实 return `G_t` | 低（无偏） | 高（整轮运气） | REINFORCE |
| **TD（时序差分）** | 用 `r + γV(s')` Bootstrap | 高（有偏） | 低（单步） | Q-learning、SARSA |

- **Bias-Variance 权衡**：MC 无偏但高方差（训练抖）；TD 低方差但有偏（依赖 V 的近似）。
- **GAE（PPO 用的优势估计）** = MC 与 TD 之间的插值：用 `(γλ)` 折扣把多步 TD 误差累加，在偏差/方差间取平衡（你之前看 PPO 论文时的 `A_t` 就是它）。
- 库里：`deep_RL/mc_td.ipynb` 专门讲。

## 4. Bias-Variance Analysis（贯穿一切的分析框架）

任何估计量都在"偏差 ↔ 方差"之间权衡：
- 想降方差 → 引入偏差（如 TD 的 bootstrap、baseline、GAE）
- 想降偏差 → 忍受高方差（如 MC、无 baseline 的 PG）

**实战落点**（库里 `training_practices/`）：
- `entropy.ipynb`：策略熵过低 = 确定性过强 = reverse KL mode collapse 的信号。RL 训练要保熵（entropy bonus）维持探索。
- `kl_数值内涵.ipynb` / `review_kl.ipynb`：KL 怎么算、forward/reverse 数值差异、KL 惩罚的实操。
- `训推mismatch.ipynb`：训练时（有 sampler/temperature）和推理时（greedy）分布不一致 → 部署性能下降。这是 RL 后训练最隐蔽的坑之一。

## 5. 一张总图

```
核心概念
├─ KL: Forward(SFT, mode-covering) vs Reverse(RL, mode-seeking)
│       └─ PPO 的 KL 惩罚 = 对抗 reverse KL 的塌缩
├─ On/Off-policy: 样本能否复用 → IS 权重桥接
├─ MC vs TD: 无偏高方差 vs 有偏低方差 → GAE 插值
└─ Bias-Variance: 一切估计的权衡主线
        └─ entropy / kl / 训推mismatch 都是它的具体表现
```
