# 27 移除元素

> 标签：数组、双指针、原地修改
> 难度：简单
> 核心考点：变量作用域（累计计数）、返回值含义、快慢指针原地过滤

---

## 1. 题目要点回顾

- 给定数组 `nums` 和值 `val`，**原地**移除所有等于 `val` 的元素。
- 元素顺序可改变；只需保证 `nums` 的前 `k` 个是「不等于 val」的元素（`k` 之后的内容无所谓）。
- 返回 `k`（不等于 val 的元素个数）。
- 评测机只检查 `nums[0..k-1]` 排序后是否与预期一致，所以前 k 个**顺序任意**。

---

## 2. 你的代码逐行纠错

```cpp
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        vector<int>finnums(nums.size());
        int count =0;
        for(int i=0;i<nums.size();i++)
        {
            if (nums[i]!=val) {int j =0;finnums[j]=nums[i];j++;}  // ①
            else {count++;}
        }
        for(int i =0;i<nums.size()-count;i++)
        {
            nums[i]=finnums[i];
        }
        return count;                                            // ②
    }
};
```

### ① `int j = 0;` 写在 `if` 块里（致命）
- 每次进入 `if` 都会**重新声明**一个局部 `j` 并初始化为 0，所以 `j` 永远是 0，所有保留元素都堆到 `finnums[0]`，后面的 `j++` 也在局部变量上、本轮结束即销毁。
- **修复**：`j` 声明在循环**外面**，只初始化一次：`int j = 0;`

### ② `return count`（返回值取反）
- 题目要求返回 **k = 不等于 val 的元素个数**；你统计的 `count` 是「等于 val 的个数」，正好相反。
- **修复**：返回保留元素个数 `return j;`（或 `nums.size() - count`）。

### 顺带：用了额外数组，不是「原地」
- 题目明确要求**原地**。开 `finnums` 是 O(n) 额外空间，能过但不最优。真正原地只需两个指针（见解法二）。

---

## 3. 需要补的知识点

| 点 | 说明 |
|---|---|
| **变量作用域** | 循环/分支内 `int j=0` 是「每次新建」，想累计要在外部声明 |
| **返回值含义** | 看清题目要返回什么（这里是「保留数」不是「删除数」） |
| **快慢指针** | 原地过滤数组的通用套路：fast 遍历，slow 收集有效元素 |
| **原地写回安全性** | `nums[slow] = nums[fast]` 中 `slow <= fast`，不会提前覆盖未读数据 |

---

## 4. 正确解法

### 解法一：修你的思路（直接写回 nums，无需额外数组）
```cpp
int removeElement(vector<int>& nums, int val) {
    int j = 0;
    for (int i = 0; i < nums.size(); i++) {
        if (nums[i] != val) nums[j++] = nums[i];  // 直接写回，因为 j <= i 不会覆盖未读元素
    }
    return j;
}
```
- 时间 O(n)，空间 O(1)。

### 解法二：原地双指针 / 快慢指针（最优，推荐）
```cpp
int removeElement(vector<int>& nums, int val) {
    int slow = 0;                       // slow 指向下一个该放保留元素的位置
    for (int fast = 0; fast < nums.size(); fast++) {
        if (nums[fast] != val) {
            nums[slow++] = nums[fast];  // 不等于 val 就搬过来，slow 前移
        }
        // 等于 val 就跳过（fast 继续走，slow 不动）
    }
    return slow;                        // slow 就是保留下来的元素个数 k
}
```

**推演** `nums=[0,1,2,2,3,0,4,2], val=2`：
- fast 扫到非 2 的元素依次搬到 slow 位置，最终前 5 个为 `[0,1,3,0,4,...]`，返回 `slow=5`。
- 顺序与示例 `[0,1,4,0,3]` 不同没关系（题目前 k 个可任意顺序，评测会先排序再比较）。

### （拓展）交换版：减少写操作
若「顺序可改变」且想尽量减少赋值次数，可把保留元素与末尾交换、收缩右边界：
```cpp
int removeElement(vector<int>& nums, int val) {
    int i = 0, n = nums.size();
    while (i < n) {
        if (nums[i] == val) {
            nums[i] = nums[n - 1];  // 用末尾元素覆盖
            n--;                     // 右边界收缩
        } else {
            i++;
        }
    }
    return n;
}
```
- 最坏仍是 O(n)，但等于 val 的元素只被写一次（原数组写法中会被重复搬运）。

---

## 5. 一句话总结

> 这题用「快慢指针」原地过滤：fast 遍历，slow 收集不等于 val 的元素，返回 slow。你这次的 bug 是 **`j` 声明在分支内导致每次归零** 和 **返回值取反（返回了删除数而非保留数）**。
