# 238. 除自身以外数组的乘积（Product of Array Except Self）

## 题目
- 返回 `answer`，其中 `answer[i] = nums 中除 nums[i] 外所有元素的乘积`。
- **不能用除法**，O(n) 时间。
- 进阶：O(1) 额外空间（输出数组不算额外空间）。
- 提示：`2 <= n <= 10^5`，`-30 <= nums[i] <= 30`，`answer[i]` 保证在 32 位范围内。

## 为什么不能用「总乘积 ÷ nums[i]」
1. 题目明令**禁止除法**。
2. 更根本：`nums` 里可能有 **0**（示例 2 有 0）。若 `nums[i]==0`，除零崩溃；若其他位置有 0，除法结果也全错。

## 核心思路：前缀积 × 后缀积
```
answer[i] = (nums[0..i-1] 的乘积) × (nums[i+1..n-1] 的乘积)
           = 前缀积(left)        × 后缀积(right)
```
- 空区间（i=0 的前缀、i=n-1 的后缀）乘积定义为 **1**。

## 解法一：left/right 两个数组（直观，O(n) 时间 O(n) 空间）
```cpp
vector<int> productExceptSelf(vector<int>& nums) {
    int n = nums.size();
    vector<int> left(n, 1), right(n, 1), ans(n);
    for (int i = 1; i < n; i++)
        left[i] = left[i - 1] * nums[i - 1];   // i 左侧累积
    for (int i = n - 2; i >= 0; i--)
        right[i] = right[i + 1] * nums[i + 1]; // i 右侧累积
    for (int i = 0; i < n; i++)
        ans[i] = left[i] * right[i];
    return ans;
}
```

## 解法二：答案数组复用 + 一个后缀变量（★进阶，O(1) 额外空间）
第一遍从左往右把 `ans[i]` 写成前缀积；第二遍从右往左用变量 `suffix` 记录右侧累积并乘进去。
```cpp
vector<int> productExceptSelf(vector<int>& nums) {
    int n = nums.size();
    vector<int> ans(n, 1);
    int prefix = 1;
    for (int i = 0; i < n; i++) {
        ans[i] = prefix;        // 先存 i 左侧乘积
        prefix *= nums[i];      // 再更新左侧累积
    }
    int suffix = 1;
    for (int i = n - 1; i >= 0; i--) {
        ans[i] *= suffix;       // 乘上 i 右侧乘积
        suffix *= nums[i];      // 再更新右侧累积
    }
    return ans;
}
```
> 输出数组 `ans` 不计入额外空间 → 满足进阶要求 O(1)。

## 推演：`nums=[1,2,3,4]`，n=4（解法二）
| i | ans[i]=prefix(左) | prefix 更新 | ans[i]*=suffix | suffix 更新 | 最终 |
|---|---|---|---|---|---|
| 0 | 1 | 1×1=1 | 1×24=24 | 4 | 24 |
| 1 | 1 | 1×2=2 | 12×2=24 | 12 | 12 |
| 2 | 2 | 2×3=6 | 2×4=8 | 4 | 8 |
| 3 | 6 | 6×4=24 | 6×1=6 | 1 | 6 |
输出 `[24,12,8,6]` ✓

## 推演：`nums=[-1,1,0,-3,3]`（含 0，验证除法不可用）
- ans[0] = 1×0×-3×3... 左空=1，右=1×0×(-3)×3=0 → 0
- ans[2] = (-1)×1 × (-3)×3 = 9
- 结果 `[0,0,9,0,0]` ✓（含 0 也能正确算，除法方案做不到）

## 易错点（写代码时注意）
1. **别用总乘积除法**：禁止 + 遇 0 崩溃。有 0 时除法方案直接失效。
2. **空区间乘积 = 1**：`left[0]=1`、`right[n-1]=1`，是累乘的起点。
3. **循环方向别混**：前缀从左往右（i 从 1 或 0 起步），后缀从右往左（i 从 n-2 或 n-1 起步）。
4. **解法二的更新顺序**：先「存/乘」再「更新累积」——`ans[i]` 用的是**更新前**的 prefix/suffix（不含 `nums[i]` 自己）。
5. **n=2 边界**：`answer[0]=nums[1]`，`answer[1]=nums[0]`，两解法天然正确。
6. **int 溢出**：题目保证 answer 在 32 位范围，但累乘中间值用 `int` 即可（LeetCode 保证），保守可转 `long long`。
