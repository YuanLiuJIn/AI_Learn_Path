# 122. 买卖股票的最佳时机 II（Best Time to Buy and Sell Stock II）

## 题目概述
数组 `prices`，每天可**决定买和/或卖**，任一时点**最多持 1 股**，可在**同一天**多次买卖。求最大总利润。

与 #121 的区别：#121 只能交易 **1 次**；本题可交易 **多次**。

示例：
- `[7,1,5,3,6,4]` → 买 day1(1) 卖 day2(5) 赚 4；买 day3(3) 卖 day4(6) 赚 3 → **7**
- `[1,2,3,4,5]` → 赚所有上涨 → **4**
- `[7,6,4,3,1]` → 全跌 → **0**

---

## 思路速记（贪心）
因为能多次交易，任何一段「从低到高」的上涨都可以单独吃成一笔利润。最优 = **把所有相邻上涨段都吃到** = 把每一对 `prices[i] > prices[i-1]` 的正差价累加。

`[7,1,5,3,6,4]` 相邻差：`(1-7)=-6`、`(5-1)=+4`、`(3-5)=-2`、`(6-3)=+3`、`(4-6)=-2` → 取正：`4+3=7` ✓

## 为什么正确（等价性）
- 任意合法的「不重叠买卖对」总利润 = 各对 `(卖出-买入)` 之和；每对内部的利润又等于其内部相邻正差价之和。
- 贪心「取所有相邻正差价」相当于把每个上涨日 `i` 单独做一次「day(i-1) 买、day(i) 卖」——这些单日交易**不重叠**（在 day i 先卖后买，题目允许同日多次买卖且卖后不持股），故合法。
- 所有利润都来自价格上涨，逐段吃光即达到理论上限 → 最优。

---

## 正确解法

### 解法一：相邻正差价累加（贪心，O(n) ★推荐）
```cpp
int maxProfit(vector<int>& prices) {
    int profit = 0;
    for (int i = 1; i < prices.size(); i++) {
        if (prices[i] > prices[i - 1])
            profit += prices[i] - prices[i - 1];
    }
    return profit;
}
```
- 时间 O(n)，空间 O(1)。

### 解法二：谷-峰法（等价写法）
找每个「谷」买入、紧接着的「峰」卖出，累加每段；数学上等价于解法一。
```cpp
int maxProfit(vector<int>& prices) {
    int profit = 0, i = 0, n = prices.size();
    while (i < n - 1) {
        while (i < n - 1 && prices[i] >= prices[i + 1]) i++;  // 找谷
        int valley = prices[i];
        while (i < n - 1 && prices[i] <= prices[i + 1]) i++;  // 找峰
        int peak = prices[i];
        profit += peak - valley;
    }
    return profit;
}
```

## 需要补的知识点
| 点 | 说明 |
|---|---|
| 与 #121 区别 | #121 单笔 → 维护运行最低价；#122 多笔 → 累加所有正差价 |
| 贪心合法性 | 单日「买 i-1、卖 i」不重叠，同日可买卖，故合法 |
| 边界 | 一直跌 → 0；长度为 1 → 0（循环不进） |
| 不要想复杂 | 不用真的模拟买卖，直接把正差价加起来即可 |
