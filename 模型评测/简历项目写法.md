# 模型评测岗 · 简历项目写法

> 用途：把前面四个方向的学习产出（评测集、Pipeline、实验报告）包装成简历可写的「项目经历」。
> 设计原则：**每条项目都对齐 JD 高频关键词**（指标体系 / Benchmark 建设 / 自动化 Pipeline / 标注规范 / 能力边界分析 / LLM-as-Judge）。
> 文中 `{ }` 是占位符，填你真实跑出来的数字，**不要编造**。

---

## 0. 写在最前：简历项目的「对齐公式」

大厂 JD 反复要这四件事，你的项目描述里必须一一命中：

| JD 原话 | 简历里要体现 | 在哪份笔记里有素材 |
|---|---|---|
| 指标体系制定 / 多维度评测 | 你设计了哪几个维度、为什么这么拆 | 各方向 §2 维度体系 |
| 评测数据集 / Benchmark 建设 | 自建了多少题、覆盖什么、怎么做质量校验 | 各方向 §5 构建实操 |
| 自动化评测 Pipeline / 平台 | 用 Python 搭了什么可复跑的流程 | 各方向 §6 工程化 |
| 明确能力边界 / 指导训练迭代 | 你的评测结论如何反推到模型改进 | 各方向 §7 结果分析 |
| 评测平台 / 评测体系工程 | 多模态覆盖、标准规范、离线+实时双模、人机协同复检、能力基线、数据飞轮 | 项目六 + `09_评测体系建设实践与进阶.md` |

**黄金结构（STAR 压缩版）**：
`目标（解决什么评测空白）→ 方法（维度设计+指标+判分）→ 工程（可复跑 Pipeline）→ 结论（量化发现+业务价值）`

## 2. 项目二：多模态评测集 + 视觉冗余量化

> 对齐：阿里/腾讯多模态评测岗、「评测数据体系 + 自动化合成管线」。
> 素材来源：`多模态模型评测/学习笔记.md` §3 + §5 + §8 阶段 3/6。

**项目名**：中文多模态评测集构建及视觉依赖性量化分析

**角色**：评测集构建 / 幻觉专项评测
**周期**：{2} 个月

**做了什么**
- 自建 {150} 道中文垂类多模态题（票据识别 / 图表理解 / UI 操作），每题标注能力维度、是否依赖视觉、图像类型；
- 实现 MMStar 的「纯文本消融」实验：去掉图片后用纯 LLM 作答，量化视觉冗余率（ML 泄露指标），剔除 {18%} 不依赖视觉的无效题；
- 用 CircularEval（N 选项循环移位）检验选项偏置，暴露并修正 {位置偏好} 问题；
- 对 POPE 三种负采样（random/popular/adversarial）做幻觉专项评测，报 Accuracy + F1 + Yes-ratio 三件套；
- 把评测集接入 VLMEvalKit，支持 Qwen-VL / InternVL 一键横向对比，输出 MG（多模态增益）指标证明分数是「真视觉能力」。

**量化成果**
- 发现主流模型在 {adversarial} 采样下幻觉率较 random 高 {12} 个百分点，给出可落地的训练数据改进建议；
- 评测集视觉冗余率从公开榜单的 {~30%} 压到 {<5%}，区分度显著提升。

**面试可深挖**：怎么判断一道多模态题「真的需要看图」？→ 纯文本消融 + 纯图消融 + CircularEval 三道关（笔记 §5.3）。

## 3. 项目三：生成模型多指标自动评测平台

> 对齐：字节「自动化评测 Pipeline」、扩散/视觉生成评测岗。
> 素材来源：`扩散模型评测/学习笔记.md` §3 + §6 + §8 阶段 3/6。

**项目名**：文生图/视频多指标自动评测 Pipeline 与指标可信度校准

**角色**：评测工程 / 指标设计
**周期**：{2} 个月

**做了什么**
- 统一评测配置（采样步数 / CFG / seed / 分辨率 / prompt 改写策略）并公开，消除跨模型不公平；
- 搭建插件化打分器：FID（强制用 clean-fid 修正 resize 实现差异）+ CLIPScore + VQAScore + GenEval + HPSv2 并行打分；
- 实现 GenEval 的检测器驱动客观评测，输出 {6} 类组合性成绩（单/双物体、计数、颜色、位置、属性绑定），定位模型在「位置/属性绑定」维度崩溃；
- 做关键实验：收集 {N} 个模型 × {M} 个 prompt 的人评，算自动指标与人评的 Spearman ρ（VQAScore 系统级 ρ = {0.78}），决定哪些指标可替代人评做日常回归；
- 输出 CFG 扫描 trade-off 曲线（横轴 CFG，纵轴 VQAScore vs FID），比单点分数信息量大得多。

**量化成果**
- 发现旧 FID 脚本因 resize 实现差导致数字偏差 {3.2} 分，统一到 clean-fid 后评测结果厂内对齐；
- VQAScore 在组合式 prompt 上相关性显著优于 CLIPScore，推动其成为日常一致性门禁指标。

**面试可深挖**：FID 有哪些坑？→ 样本量/resize 实现/参考集依赖/对一致性无感/跨论文不可比（笔记 §3.1，六坑全背）。

## 4. 项目四：语音模型评测体系与全双工对话方案

> 对齐：语音评测岗、语音助手方向。
> 素材来源：`语音模型评测/学习笔记.md` §3 + §5 + §7 + §8。

**项目名**：TTS/语音助手评测体系建设与鲁棒性衰减分析

**角色**：评测方案设计 / 人评规范
**周期**：{2} 个月

**做了什么**
- 建立 zero-shot TTS 客观四件套评测（WER/CER + SIM + UTMOS + CMOS），复刻 Seed-TTS 标准脚本 seed-tts-eval；
- 实现文本归一化（标点/数字/繁简），量化归一化对 WER 的影响（{未归一化 WER 高 8 个点}）；
- 组织小规模 MOS/CMOS 人评（{15} 标注员 × 每条 {5} 人评，含锚点样本），算 UTMOS 与人工 CMOS 的 Spearman，验证自动指标能否做日常门禁；
- 借鉴 VoiceBench 做系统性扰动设计（加噪/混响/口音/语速），画 SNR {20→0}dB 的鲁棒性衰减曲线，定位短板人群；
- 设计「全双工语音对话评测」空白方案：定义首包延迟 / 打断响应 / 轮次自然度指标 + 标注规范。

**量化成果**
- 发现 TTS 模型 MOS 高但 WER 高 =「好听但读错」，推动业务同时卡 MOS 与 WER 双门禁；
- 噪声下 WER 从 {4%} 升到 {21%}，明确远场场景不可用，反推 {降噪/前端} 优化优先级。

**面试可深挖**：WER 能 > 100% 吗？为什么要加权？→ 插入错误使分母被夸大 + 长音频按词数加权平均（笔记 §3.1）。

## 5.5 把现有项目「平台化升级」的 4 个抓手

> 下面项目六来自一篇「业界评测平台架构」实践文章的去标识化提炼，其核心思想可回灌到项目一至五，让简历从「我做了几个评测」升级为「我搭了一套可复用的评测体系」。

1. **标准对齐**：把维度/Rubric 显式「对标行业评测规范」，写明哪些维度对应哪类标准——面试官看重"可审计、可复现"。
2. **双模评测**：给每个项目补一句"支持离线评测（答案预导入）+ 实时交互（多轮对话）两种模式"，覆盖更多接入态。
3. **复检机制**：自动化判分后加"关键样本人工复检 + 人机一致率红线"，呼应 `09_评测体系建设实践与进阶.md` 的自动化闭环。
4. **价值闭环**：每个项目补一句"评测结论 → 样本归因 → 数据飞轮反哺训练 / 能力基线监控"，把评测从成本中心说成驱动中心。

## 6. 项目六（平台向 · ★平台/体系岗主打）：统一大模型评测平台从 0 到 1

> 素材来源：`09_评测体系建设实践与进阶.md`（9.1 体系方法论 / 9.5 自动化闭环 / 9.6 成熟度模型）、平台实践文章（去标识化）。

**项目名**：多模态统一大模型评测平台（覆盖文/图/视频，接 CI 与训练闭环）

**角色**：平台架构 / 评测体系设计
**周期**：{6} 个月

**做了什么**
- 对标行业评测标准规范，设计**多模态统一接入层**：覆盖文生文/图/视频、图生文等 {10}+ 模态，抽象统一推理接口接入 {100}+ 主流模型，屏蔽各模型 API / 采样参数差异；
- 搭建**数据集管理中心**：内置 {10 万}+ 专业评测集，支持业务方自定义数据上传、版本锁定与溯源，解决"资产分散、重复造轮子"；

- **人机协同评测 + 复检机制**：自动化 LLM-as-Judge 跑量，人工背靠背标注兜底高精度，关键样本进入"审核复检"流程，人机一致率纳入质量红线；
- 落地**五大评测路径**（全资源就绪 / 无数据集调用公开集 / 离线答案导入 / 多轮对话 / 全自动化），并打通**价值闭环**：高频自动评测做能力基线监控 → 样本归因定位缺陷 → 数据飞轮反哺训练；资源隔离 + 权限管控做业务安全屏障。

**量化成果**
- 平台周级评测覆盖 {X} 个模型 × {Y} 个数据集，评测提效 {4–8} 倍（参考一线自动化实践）；
- 通过基线监控拦截 {N} 次模型退化，归因报告驱动训练侧补充 {XX} 数据；
- 自定义维度标签机制让业务方自助搭建评测，需求响应周期从 {周} 缩到 {天}。

**面试可深挖**：离线评测为什么重要？→ 未接入模型无法实时调用时，用"答案预导入 + 统一判分"保持横向可比；多模态统一接入层最难的是哪块？→ 把异构输出（文本/图像/视频/音频）归一为可判分的统一结构（笔记 09 章）。
