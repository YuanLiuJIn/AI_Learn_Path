# 134. 加油站（Gas Station）

## 题目
- 环形路上 n 个加油站，`gas[i]` 第 i 站可加汽油，从 i 开往 i+1 消耗 `cost[i]` 升。
- 油箱无限大，初始为空。找到一个起点能绕一圈，返回起点编号，否则 -1。
- **保证解唯一**。提示：`1 <= n <= 10^5`。

## 关键观察
- 定义 `diff[i] = gas[i] - cost[i]`：在第 i 站加完油、开到 i+1 后的净增油。
- **必要条件：总净油 `sum(diff) >= 0`**，否则一定无解。
- **有解则解唯一**（题目保证）。

## 解法一：一趟贪心（★推荐，O(n) 时间 O(1) 空间）
从「累计净油首次为负的下一站」出发：
```cpp
int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
    int total = 0, cur = 0, start = 0;
    for (int i = 0; i < gas.size(); i++) {
        total += gas[i] - cost[i];   // 全程总净油
        cur += gas[i] - cost[i];     // 从 start 起的累计净油
        if (cur < 0) {               // 从 start 出发到不了 i+1
            start = i + 1;           // 换起点（唯一正确的下一候选）
            cur = 0;
        }
    }
    return total >= 0 ? start : -1;
}
```
- 为什么对：若存在解，从 0 到某处首次累计为负时，前面这段不可能作为解的开头，只能从 i+1 重新试；而题目保证解唯一，最终 start 即答案。

## 解法二：双向扩展双指针（用户思路，O(n)）
`st`/`ed` 维护环形连续区间，`rem` 为区间净油量：
- `rem >= 0`：够开 → 右扩 `ed`；
- `rem < 0`：不够 → 起点左移 `st`；
- 直到 `st == ed`（区间绕满整环），`rem >= 0` 返回 `st`，否则 -1。
```cpp
int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
    int n = gas.size();
    int st = 0, ed = 0;                 // 环形区间起止
    int rem = gas[0] - cost[0];         // 区间 [st..ed] 净油量
    do {
        if (rem >= 0) {
            ed = (ed + 1) % n;
            rem += gas[ed] - cost[ed];
        } else {
            st = (st - 1 + n) % n;
            rem += gas[st] - cost[st];
        }
    } while (st != ed);
    return rem >= 0 ? st : -1;
}
```

## 推演：`gas=[1,2,3,4,5], cost=[3,4,5,1,2]`
`diff = [-2,-2,-2,3,3]`，贪心版：
| i | diff | cur | cur<0? | start |
|---|---|---|---|---|
| 0 | -2 | -2 | 是 | 1 |
| 1 | -2 | -2 | 是 | 2 |
| 2 | -2 | -2 | 是 | 3 |
| 3 | 3 | 3 | 否 | 3 |
| 4 | 3 | 6 | 否 | 3 |
total=0≥0 → 返回 **3** ✓

## 推演：`gas=[2,3,4], cost=[3,4,3]`
`diff=[-1,-1,1]`：i=0→start=1；i=1→start=2；i=2 cur=1。total=-1<0 → 返回 **-1** ✓

## 易错点（写代码时注意）
1. **`start = i + 1` 而不是 `i`**：cur<0 说明从 start 到 i 都不行，新起点是 i+1（i 本身也不够油）。
2. **别忘 `total >= 0` 判无解**：cur 归零不代表可行，最终要靠总净油判。
3. **解法二环形下标**：`(st - 1 + n) % n` 要 `+n` 防负数。
4. **解法二循环终止 `st != ed`**：别写成 `s`（拼写）或 `rem`（判据用错）。
5. **n=1 边界**：单个站 `gas[0]-cost[0]>=0` 返回 0，否则 -1，两解法天然正确。

## 贪心解法详解（2026-08-11 追问）
### 概念
`diff[i] = gas[i] - cost[i]`：第 i 站加油开往 i+1 的**净变化**。绕一圈成功 ⇔ 全程每刻油箱 ≥ 0。
| 变量 | 含义 |
|---|---|
| `total` | 全程总净油（无关于起点），最后判无解 |
| `cur` | 从候选起点 `start` 起的累计净油，判断能否撑下去 |
| `start` | 当前候选起点，撑不下去就换 |

### 关键引理（为什么能跳到 i+1）
从 `start` 出发 `cur` 在 **i 处首次变负** ⇒ `[start, i]` 整段都不能作为可行起点：
- start 到 i 中途 `cur≥0`，故对任意 `j∈[start,i)`：从 start 到 j 油箱非负。
- 从 j 出发开到 i 的油 = `cur_final − 前缀(j−1)`；`cur_final<0` 而 `前缀(j−1)≥0` → 从 j 连 i 都到不了。
- 所以整段排除，直接换 `start=i+1`，一个解都不漏。

### 为什么 total≥0 就返回 start
被跳过的每段总和为负（每段都在 cur<0 处切断），`total≥0` 保证剩下从 start 绕一圈的路径处处非负 → 必能走通；`total<0` 则任何起点都亏 → -1。

### 本质视角：前缀和最低点
设 `S[i]=Σdiff[0..i]`（S[-1]=0）。算法等价于「找前缀和最小值的**后一个位置**」作起点——以最低点为起点后，所有前缀和垫高到 ≥0，油箱处处非负。示例 1 前缀和 `[-2,-4,-6,-3,0]`，最低 -6 在 i=2 → 起点 3 ✓。这也说明不能从「第一个正 diff」出发。

### start 的变化（走帧示例 1，2026-08-12 追问）
`cur` 是「从当前 start 开始」的账：start 一变，cur 清零重记。
| 帧 | i | start | cur(从start到i) | cur<0? | start变化 |
|---|---|---|---|---|---|
| 初始 | — | 0 | 0 | — | — |
| 1 | 0 | 0 | -2 | 是 | 0→1 |
| 2 | 1 | 1 | -2 | 是 | 1→2 |
| 3 | 2 | 2 | -2 | 是 | 2→3 |
| 4 | 3 | 3 | +3 | 否 | 保持3 |
| 5 | 4 | 3 | +6 | 否 | 保持3 |
结束 total=0≥0 → 返回 start=3 ✓
- start 每次 cur<0 就跳到 i+1（跳着换，因 [start,i] 整段已证全废）。
- 最终停在「最后一个失败点的下一站」，之后曲线永远 ≥0。
- 图视角：cur 见底归零 = 在折线最低点剪断重新起笔，start 就是剪断点之后的位置。

### 易错
- `start = i+1` 不是 `i`（i 也在废区间里）。
- 换起点后 `cur` 归 0。
- 判无解用 `total` 不是 `cur`。
