# 模型评测 · 核心能力图谱

> 本目录把 JD 中明确列出的 **9 条能力要求**逐条展开为详细章节，作为「模型评测工程师」系统学习的底座。
> 每章都遵循「原理 → 训练目标 → 评测视角 → 关键论文/代码库」的写法，让原理知识直接服务于评测工作。

## 一、9 条要求 → 章节映射

| # | JD 原文要求 | 对应章节 | 文档 |
|---|---|---|---|
| 1 | LLM、T2I、T2V、I2V、MLLM 模型评测工作和评测体系建设 | 各模态评测 + 体系建设 | `02_各模态评测与体系建设.md` |
| 2 | 评测相关自动化评测工具开发及维护 | 自动化工具工程 | `03_自动化评测工具开发.md` |
| 3 | 算法手段，对基座大模型和 AI Native 应用分阶段、端到端评测 | 分阶段端到端评测 | `04_分阶段端到端评测.md` |
| 4 | Agent 工具链、对战平台、模型竞技场、效果判别模型、应用数据飞轮 | Agent 与竞技场生态 | `05_Agent工具链与竞技场数据飞轮.md` |
| 5 | Transformer、Bert、DiT、CLIP、CNN、GAN、VAE、Diffusion 等基本原理 | 模型架构原理 | `01_模型架构与基本原理.md` |
| 6 | 数据化思维，ACC/AUC/F1/recall 等指标计算与数据分析结论 | 基础指标与数据分析 | `06_数据化思维与基础评估指标.md` |
| 7 | 熟悉常见架构，能训练/微调常见 CV、NLP、LLM、MLLM 模型 | 训练与微调实操 | `07_训练与微调实操.md` |
| 8 | 常见评测数据集与方法：C-Eval、CMMU、MT-bench、MINT、SuperCLUE 等 | 评测数据集方法 | `08_常见评测数据集与方法.md` |
| 9 | 熟悉 Bert、CLIP、BLIP、ResNet、VGG、RCNN、Yolo 等算法原理及训练实操 | 模型架构原理（CV/多模态） | `01_模型架构与基本原理.md` |

## 二、阅读顺序建议

```
01 模型原理（地基，不懂架构就无法设计评测维度）
  ↓
06 基础指标（所有评测的通用语言）
  ↓
08 常见数据集方法（先看别人怎么评）
  ↓
02 各模态评测与体系建设（把 01/06/08 落到 5 类模型）
  ↓
03 自动化工具 + 04 端到端评测 + 05 Agent 竞技场（工程化与进阶）
  ↓
07 训练微调实操（能训练才能设计「评测→训练」闭环）
  ↓
09 评测体系建设实践与进阶（综合一线实战：体系搭建/度量难题/预训练评测/自动化提效/Agent评估）
```
