# 00. 知识图谱学习路线

> 目标：先建立全局地图，再按“表示 → 构建 → 存储 → 推理 → 应用”逐层深入。

## 1. 知识图谱的五层结构

```text
第一层：知识表示
  问题：知识如何变成图？
  关键词：实体、关系、属性、三元组、RDF、属性图、本体、Schema

第二层：知识构建
  问题：图谱从哪里来？
  关键词：NER、关系抽取、事件抽取、实体对齐、知识融合、人工标注、LLM 抽取

第三层：图存储与查询
  问题：图谱如何存、如何查？
  关键词：图数据库、RDF Store、Neo4j、JanusGraph、SPARQL、Cypher

第四层：推理与表示学习
  问题：图谱如何补全、推理、计算相似度？
  关键词：规则推理、本体推理、路径推理、TransE、RotatE、R-GCN、GNN

第五层：应用系统
  问题：知识图谱如何服务真实业务？
  关键词：知识问答、推荐、风控、搜索、GraphRAG、Agent Memory
```

阅读：

```text

```

---

### 阶段四：理解“图谱如何推理和学习”

阅读：

```text
05_reasoning_and_quality.md

```

重点理解：

```text
规则推理：A 是 B 的父亲 → B 是 A 的孩子

路径推理：A 投资 B，B 控制 C → A 间接影响 C

GNN：在图结构上传播信息
```


## 3. 推荐实践路线

```text
实践 1：用 Neo4j 建一个电影知识图谱
实践 2：从医疗问答数据构建疾病-症状-药品图谱
实践 3：用 SPARQL 查询一个 RDF 小图谱
实践 4：训练 TransE 做链接预测
实践 5：实现一个 Text2Cypher 知识问答系统
实践 6：构建一个 GraphRAG 文档问答系统
实践 7：做一个专业领域知识图谱项目，如论文推荐、医疗问答、金融风控或城市设施图谱
```

## 4. 一句话总结

> 知识图谱的学习路线是：先学图怎么表示，再学知识怎么抽取和融合，再学图怎么存储查询，接着学推理和表示学习，最后把它接入问答、搜索、推荐、GraphRAG 与 Agent 系统。
