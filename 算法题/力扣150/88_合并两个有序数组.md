# 88 合并两个有序数组

> 标签：数组、双指针、排序
> 难度：简单
> 核心考点：归并（merge）思想 + C++ 语法细节 + 原地双指针（从尾合并）

---

## 1. 题目要点回顾

- `nums1` 长度固定为 `m + n`，前 `m` 个是有效元素，后 `n` 个是占位 `0`（**必须忽略**）。
- `nums2` 长度为 `n`，全部有效。
- 要求把 `nums2` 合并进 `nums1`，结果仍按非递减排序，且**直接改 `nums1`**（不返回）。
- 边界：`m`、`n` 可能为 0（如 `m=0` 时 `nums1` 实际为空数组；`n=0` 时 `nums2` 为空）。

一句话理解：**在 `nums1` 末尾预留的空位里，把两个有序数组合并成一个有序数组。**

---

## 2. 你的代码逐行纠错

你写的代码：

```cpp
class Solution {
public:
    void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
        vector<int>& nums3;                                  // ①
        int a,b,i = 0;                                       // ②
        for(i<m+n;i++)                                       // ③
        {
            if(nums1[a]==0){nums3[i]=nums2[b];b++;continue;} // ④
            if(nums2[b]==None){nums3[i]=nums1[a];a++;continue;} // ⑤
            if(nums1[a]<nums2[b])
            {nums3[i]=nums2[b];b++;}                         // ⑥
            else{nums3[i] = nums1[a];a++;}                   // ⑦
        }
        nums1=nums3;
    }
};
```

### ① `vector<int>& nums3;`
- **错误**：C++ 中「引用 `&`」**必须在声明时初始化**，不能写一个悬空引用。这里你其实是想新建一个临时数组来存结果，应该写：
  ```cpp
  vector<int> nums3(m + n);   // 新建一个长度为 m+n 的 vector（值类型，不是引用）
  ```
- **知识点**：引用是「别名」，必须绑定到一个已存在的对象；想新建容器就直接声明对象本身。

### ② `int a,b,i = 0;`
- **错误**：只有 `i` 被初始化为 0，`a` 和 `b` 是**未初始化的垃圾值**。C++ 不会自动赋 0。
- **正确**：`int a = 0, b = 0, i = 0;`

### ③ `for(i<m+n;i++)`
- **错误**：`for` 的结构是 `for(初始化; 条件; 步进)`。你写成了：
  - 第一部分 `i<m+n` 是一个**比较表达式**（结果被丢弃，没有初始化任何东西）；
  - 第二部分 `i++` 被当成循环条件，它永远非 0（即「真」），结果是**死循环**直到整数溢出。
- **正确**：`for (int i = 0; i < m + n; i++)`

### ④ `if(nums1[a]==0)`
- **错误 1（逻辑）**：用「值等于 0」来判断 `nums1` 是否取完是**错的**。
  - 题目里末尾的 0 确实是占位符，但**占位符只在「下标 `>= m`」这一段**；下标 `0 ~ m-1` 的有效段里完全可能出现合法的 `0`（题目允许元素为 0，例如 `nums1=[0,1,2,0,0,0], m=3`）。
  - 用「值等于 0」无法区分「有效段里的真 0」和「末尾的占位 0」，一旦有效段里出现 0 就会被误判成「nums1 取完了」，导致丢数据甚至越界。
  - 占位符是**位置**概念，不是**值**概念。所以判空只能用**下标**：`a >= m`（nums1 有效长度只有 `m`）。
- **错误 2（越界）**：`a` 未初始化就去访问 `nums1[a]`，属于**未定义行为（UB）**，可能崩溃或结果错乱。

### ⑤ `if(nums2[b]==None)`
- **错误 1（语法）**：`None` 是 **Python** 关键字，C++ 没有。判断 `nums2` 是否取完应写 `b >= n`。
- **错误 2（越界）**：`b` 未初始化访问 `nums2[b]` 同样越界。

### ⑥⑦ 取大不取小 + 没处理相等
- **错误**：归并的核心是「每次取**较小**的那个元素」。你写成了 `nums1[a] < nums2[b]` 时取 `nums2[b]`——取成了**较大**的那个，逻辑反了。
- 另外 `nums1[a] < nums2[b]` 的 `else` 分支把相等情况也归到了取 `nums1[a]`，这部分「相等取谁」无所谓，但前提是**取较小值**的方向要对。

### 小结：你这次主要踩了两类坑
1. **C++ 语法细节**（引用初始化、变量初始化、for 结构、None 不存在）——这是导致代码根本编译/跑不起来的原因。
2. **算法逻辑**（用值判断「取完」不可靠、归并应取较小值）——这是思路层面的问题。

## 3. 需要补的知识点

### A. C++ 语法基础（优先补，否则写不出能跑的代码）
| 点 | 说明 |
|---|---|
| 引用必须初始化 | `T& r = obj;`，不能 `T& r;` |
| 变量初始化 | `int a=0, b=0;` 每个变量都要显式给初值 |
| `for` 循环三要素 | `for(初始化; 条件; 步进)`，条件是「继续循环」的布尔表达式 |
| 没有 `None` | 用下标 `i >= len` 判断数组遍历完；指针才用 `nullptr` |
| 越界是 UB | 用未初始化/越界的下标访问 `vector` 结果不可预测 |

### B. 算法核心
- **归并（merge）**：两个有序数组，每次从各自的「当前待比较元素」中取**较小值**放入结果，对应指针后移。
- **如何判断某条数组取完**：永远用**下标** `a >= m` / `b >= n`，**不要用元素值**（因为值可能恰好等于你选的「哨兵」）。
- **边界处理顺序**：先判断「某条已空」，再比较两个当前值。
- **原地合并 vs 额外数组**：本题 `nums1` 末尾有 `n` 个空位，**从尾巴往前填**可以做到 `O(1)` 额外空间；从前往后会覆盖还没比较的 `nums1` 元素，必须借助额外数组。

### C. 复杂度意识
- 额外数组法：时间 `O(m+n)`，空间 `O(m+n)`。
- 从尾原地合并：**时间 `O(m+n)`，空间 `O(1)`**（官方推荐 / 最优）。
- 避免 `insert` 反复后移或 `O((m+n)²)` 的低效写法。

## 4. 正确解法

### 解法一：额外数组（从前往后，最符合直觉，先掌握这个）

思路：开一个 `m+n` 的临时数组，用两个指针 `a`、`b` 分别扫 `nums1`（前 `m` 个）和 `nums2`，每次取较小值放入；最后拷贝回 `nums1`。

```cpp
void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
    vector<int> nums3(m + n);
    int a = 0, b = 0, i = 0;
    while (i < m + n) {
        if (a >= m) {                 // nums1 有效部分已取完，直接补 nums2
            nums3[i++] = nums2[b++];
        } else if (b >= n) {          // nums2 已取完，直接补 nums1
            nums3[i++] = nums1[a++];
        } else if (nums1[a] < nums2[b]) {
            nums3[i++] = nums1[a++];  // 取较小值
        } else {
            nums3[i++] = nums2[b++];  // 相等时取 nums2 也行
        }
    }
    for (int k = 0; k < m + n; ++k) nums1[k] = nums3[k];
}
```
- 时间 `O(m+n)`，空间 `O(m+n)`。

### 解法二：从尾合并（原地，`O(1)` 空间，最优解，面试加分）

为什么能原地？因为 `nums1` 后半段是空的（0 占位）。从**最大**的元素开始，往 `nums1` 的**尾部**放，这样不会覆盖还没比较的 `nums1` 前面的有效元素。

```cpp
void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
    int a = m - 1;        // nums1 有效区尾指针
    int b = n - 1;        // nums2 尾指针
    int i = m + n - 1;    // 结果放置位置（nums1 整体尾部）

    while (a >= 0 && b >= 0) {
        nums1[i--] = (nums1[a] > nums2[b]) ? nums1[a--] : nums2[b--];
    }
    // 若 a >= 0：剩余 nums1 元素本就在正确位置，无需处理
    while (b >= 0) {      // 只有 nums2 还有剩余时才需要搬
        nums1[i--] = nums2[b--];
    }
}
```

**手动推演**（nums1=`[1,2,3,0,0,0]`, m=3；nums2=`[2,5,6]`, n=3）：

| 步 | a | b | i | 操作 | nums1 变为 |
|---|---|---|---|---|---|
| 初 | 2 | 2 | 5 | max(3,6)=6 → `nums1[5]=6` | `[1,2,3,0,0,6]` |
| | 2 | 1 | 4 | max(3,5)=5 → `nums1[4]=5` | `[1,2,3,0,5,6]` |
| | 2 | 0 | 3 | max(3,2)=3 → `nums1[3]=3` | `[1,2,3,3,5,6]` |
| | 1 | 0 | 2 | max(2,2)=2 → `nums1[2]=2` | `[1,2,2,3,5,6]` |
| | 0 | 0 | 1 | max(1,2)=2 → `nums1[1]=2` | `[1,2,2,3,5,6]` |
| b<0 停止 | | | | a=0 剩余 `nums1[0]=1` 已在位 | `[1,2,2,3,5,6]` ✓ |

## 5. 一句话总结

> 这题本质是「归并两个有序数组」。语法上要补 **C++ 引用/变量初始化/for 结构/下标判空**；算法上记住 **用下标判断取完、每次取较小值**，并优先掌握 **从尾原地合并**（`O(1)` 空间）这种最优写法。
