# 推理部署框架（Inference / Serving）

> 训完模型不部署 = 白训。这层负责把模型"跑起来对外服务"。
> 注意：**这层是"用 AI 生成"的载体，属于第 3 层推理，不改权重**。
> 你运行时"LLM 生成测试 JSON"就是靠这里起的服务。

---

## 1. vLLM

### 特点

```text
- PagedAttention 显存管理，吞吐极高（你 docs/papers 里那篇论文就是它）
- 支持连续批处理 continuous batching，并发强
- 几乎所有开源模型都能跑
- 适合：高吞吐在线服务、批量生成（部署首选）
```

### 安装

```bash
pip install vllm
```

### 最小可运行示例

启动服务：

```bash
vllm serve Qwen/Qwen2.5-7B-Instruct --port 8000
```

Python 调用（OpenAI 兼容接口）：

```python
from openai import OpenAI

client = OpenAI(base_url="http://localhost:8000/v1", api_key="EMPTY")
resp = client.chat.completions.create(
    model="Qwen/Qwen2.5-7B-Instruct",
    messages=[{"role": "user", "content": "生成一个测试副本的 JSON"}],
    max_tokens=512,
)
print(resp.choices[0].message.content)
```

## 2. SGLang

### 特点

```text
- 结构化输出、多轮对话、复杂调用链很快
- 自带 RadixAttention，多轮/共享前缀场景效率高
- 适合：Agent 场景（反复多轮 + 工具调用 + 结构化 JSON）
```

### 安装

```bash
pip install sglang
```

### 最小可运行示例

```bash
# 启动服务
python -m sglang.launch_server --model-path Qwen/Qwen2.5-7B-Instruct --port 30000
```

Python（结构化生成）：

```python
import sglang as sgl

@sgl.function
def gen_test_case(s, prompt):
    s += sgl.system("你是一个 UE5 测试生成器")
    s += sgl.user(prompt)
    s += sgl.assistant(sgl.gen("json", max_tokens=512))

out = gen_test_case.run(prompt="测试玩家进入副本并领取奖励",
                        backend=sgl.OpenAI("http://localhost:30000/v1"))
print(out["json"])
```

## 3. LMDeploy

### 特点

```text
- 训推一体，和 ms-swift 搭配好
- 量化（4bit/8bit）+ TurboMind 引擎，部署省显存
- 适合：想"训完直接部署"的一站式
```

### 安装

```bash
pip install lmdeploy
```

### 最小可运行示例

```bash
# 量化并启动
lmdeploy quantize Qwen/Qwen2.5-7B-Instruct --work-dir qwen-w4a16
lmdeploy serve api_server qwen-w4a16 --server-port 23333
```

---

## 4. 怎么选

| 维度 | vLLM | SGLang | LMDeploy |
|---|---|---|---|
| 吞吐 | 极高 | 高 | 高 |
| 结构化/多轮 | 中 | 强 | 中 |
| 量化部署 | 中 | 中 | 强 |
| 你用得到 | 部署首选 | Agent 部署 | 训推一体 |

---

## 一句话总结

> 推理框架是"用 AI 生成"的载体：训好的模型靠 **vLLM / SGLang** 起服务，
> 你的测试 Agent 运行时就调用它们生成 JSON。训和推是两件事，框架也分两家。
