# 80 删除有序数组中的重复项 II

> 标签：数组、双指针、原地修改
> 难度：中等
> 核心考点：#26 的推广（最多保留 k 次）、`nums[slow-2]` 判定窗口、快慢指针 O(1) 空间

---

## 1. 题目要点回顾

- 有序数组 `nums`，**原地**删除重复元素，但允许每个值**最多出现 2 次**。
- O(1) 额外空间，不能开额外数组。
- 返回新长度 `k`，`nums` 前 `k` 个为去重后（每值至多 2 次）的结果。

---

## 2. 关键思路

这是 #26 的直接推广。#26 是「最多 1 次」，用 `nums[fast] != nums[fast-1]`（和前一个不同即保留）。
本题「最多 2 次」：只要当前元素**不等于 `nums[slow-2]`**，就说明它前面最多只有 1 个相同值，可以保留；若等于 `nums[slow-2]`，说明已经放了 2 个，这是第 3 个 → 跳过。

> 通用规律：允许每个值最多出现 **k** 次，则判定条件为 `nums[fast] != nums[slow - k]`（前 k 个直接保留作种子）。

---

## 3. 需要补 / 复习的知识点

| 点 | 说明 |
|---|---|
| **#26 的推广** | 把「与前一个不同」换成「与前 k 个（本题 k=2）不同」 |
| **`nums[slow-2]` 窗口** | 利用有序性，用已放置区的 `slow-2` 位置判断是否已超 2 次 |
| **前两格种子** | `slow < 2` 时永远保留（前两个位置天然不超过 2 次） |
| **快慢指针** | 和 #26/#27 同构：fast 遍历，slow 收集保留元素 |
| **O(1) 空间** | 只用到 slow/fast 两个 int，原地写回 |

---

## 4. 正确解法

```cpp
int removeDuplicates(vector<int>& nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.size(); fast++) {
        // 前两个直接保留；之后只要不等于 slow 前面第 2 个（即未超 2 次）就保留
        if (slow < 2 || nums[fast] != nums[slow - 2]) {
            nums[slow++] = nums[fast];
        }
    }
    return slow;
}
```

**推演** `nums=[1,1,1,2,2,3]`：
- fast=0: slow<2 → 留 `1`, slow=1
- fast=1: slow<2 → 留 `1`, slow=2
- fast=2: `nums[2]=1 == nums[0]=1` → 跳过（第 3 个 1）
- fast=3: `nums[3]=2 != nums[0]=1` → 留 `2`, slow=3
- fast=4: `nums[4]=2 != nums[1]=1` → 留 `2`, slow=4
- fast=5: `nums[5]=3 != nums[2]=2` → 留 `3`, slow=5
- 返回 5，前 5 个 `[1,1,2,2,3]` ✓

**推演** `nums=[0,0,1,1,1,1,2,3,3]` → 返回 7，前 7 个 `[0,0,1,1,2,3,3]` ✓

### （拓展）泛化到「最多 k 次」
```cpp
int removeDuplicatesK(vector<int>& nums, int k) {
    int slow = 0;
    for (int fast = 0; fast < nums.size(); fast++) {
        if (slow < k || nums[fast] != nums[slow - k]) {
            nums[slow++] = nums[fast];
        }
    }
    return slow;
}
```
本题调用 `removeDuplicatesK(nums, 2)` 即可。

## 5. 一句话总结

> 有序数组「最多保留 k 次」= 快慢指针 + 判定 `nums[fast] != nums[slow - k]`。本题 k=2，即和 `slow-2` 比。本质就是 #26 把窗口从 1 拉到 2。

## 7. 你的提交分析（2026-08-06）

你的代码：

```cpp
int removeDuplicates(vector<int>& nums) {
    int slow =0;
    for(int fast =0;fast<nums.size();fast++)
    {
        if(nums[fast]!=nums[fast-2]||slow<2)   // ①
        {
            nums[slow]=nums[fast];
            slow++;
        }
    }
    return slow;
}
```

### ① `||` 操作数顺序导致越界（次要 bug）
- C++ 的 `||` 是**短路求值且从左到右**：先算左边 `nums[fast]!=nums[fast-2]`。
- 当 `fast=0`（甚至 `fast=1`）时，`nums[fast-2]` 变成 `nums[-2]`/`nums[-1]`，**负下标访问 `vector` 是未定义行为（UB）**。
- **修复**：把 `slow<2` 放左边，靠短路先拦截。

### ② `nums[fast-2]` 被原地写入破坏（致命 bug，之前判断有误，在此订正）
- 上一条我曾写「`nums[fast-2]` 在有序数组上等价」——**那是错的**。错在忽略了：我们在**原地**写 `nums[slow]=...`，写头 `slow` 会覆盖掉 `nums[fast-2]` 指向的位置。
- 推演 `[1,1,1,2,2,3]`（你报错的这个用例）：
  - fast=3：slow=2，写 `nums[2]=2` → 此时 nums=[1,1,2,2,2,3]
  - fast=4：比较 `nums[4]=2 != nums[2]=?`，而 `nums[2]` 刚被写成 **2**！于是 `2 != 2` 为假 → **误删第二个 2**
  - 结果 `[1,1,2,3]`，恰好就是你看到的错误输出
- 根因：`nums[fast-2]` 落在「原始数组区」，但写头 `slow` 会向前覆盖它；当 `slow == fast-1` 时，`nums[fast-2]` 就是刚写过的 `nums[slow-1]`，读到的是被污染的值。

### 正确写法：用 `nums[slow-2]`（读「结果区」，永远在写头后面，安全）
```cpp
int removeDuplicates(vector<int>& nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.size(); fast++) {
        if (slow < 2 || nums[fast] != nums[slow - 2]) {  // 读 slow 指向的结果区，不在原地写时被污染
            nums[slow++] = nums[fast];
        }
    }
    return slow;
}
```
- `nums[slow-2]` 读的是「已保留的结果区」（下标 < slow），写头只在 `slow`，绝不会覆盖 `slow-2`，所以安全；语义也正确：直接问「结果里是否已有 2 个这个值」。

### 通用原则（记住）
> 原地双指针里，判定「是否保留」要读 **slow 指向的结果区**（`nums[slow-k]`），**不要读 fast 指向的原始区**（`nums[fast-k]`）——因为写头 slow 会污染原始区。
> 另外：`||` 里可能越界的表达式放右边，靠左边守卫短路拦截。
