## 二、范围与操作性定义

本计划默认研究数值预测模型，而非直接微调语言大模型。用户尚未提供具体物理领域、数据、算力或目标期刊；以下是可修改的实验提案，不是已确认的应用事实。

“学会物理”操作化为：在独立测试中，模型能够利用物理参数与约束，提高跨初始条件、跨参数和长时间预测能力，并保持符合该系统的物理一致性。不能以流畅解释、训练残差较小或单一随机测试集误差证明模型获得一般物理理解。

推荐题目：**物理先验的准确性如何影响参数条件化模型的跨工况泛化？**

核心问题：在控制数据量、模型结构和训练预算后，显式物理约束比单纯输入参数改善多少？先验不准确时，改善何时转为负迁移？

研究子问题：
1. 相比纯数据训练，正确物理约束在少样本与分布外预测下是否带来可靠收益？
2. 参数、方程项或边界条件错误分别怎样影响性能？
3. 验证集选择约束权重、未知项残差建模能否缓解错误先验的影响？
4. 残差、守恒误差与真实预测误差是否一致，何时出现指标冲突？

预注册假设（全部待检验）：
- H1：在部分少数据设置中，正确物理约束改善预测与物理一致性。
- H2：错误先验的强约束可能损害预测，且 OOD 下更明显。
- H3：适当降低约束强度或学习缺失项可能缓解负迁移，但并非保证有效。
- H4：物理残差小不充分保证解准确。

贡献边界：本计划首先是一项受控评测和适用范围研究。PINN、PINO、残差混合模型、自适应权重和模型错设修正均已有相关研究；不能把组合这些组件称为新方法。本轮检索不是系统综述，也不足以证明新颖性。

## 三、技术路线与选型

| 路线 | 物理如何进入 | 适合场景 | 主要风险 |
|---|---|---|---|
| 参数条件化 | 参数拼接、特征调制 | 多工况预测 | 参数被忽略、伪相关 |
| 软物理损失 | 方程残差、边界、初始条件 | 方程已知、有可微输出 | 权重失衡、错误方程、优化困难 |
| 硬约束与结构先验 | 边界参数化、等变性、守恒结构 | 先验准确且可结构化 | 错误假设难纠正、积分误差 |
| 混合物理模型 | 已知动力学加神经残差 | 部分机制未知 | 缺失项与噪声难区分 |
| 神经算子 | 学习初始场/参数场到解场映射 | 重复仿真、多初始条件 | 数据成本、OOD 泛化不足 |
| LLM 加求解器 | 参数解析、方程选择、调用数值工具 | 交互式物理推理 | 工具成功不证明模型内部理解 |

主线：先做参数条件化网络与软物理约束的严格对照，再扩展至 FNO/PINO 风格模型。不要在第一阶段同时更换骨干、优化器、采样和损失而无法归因。

## 四、阶段 A：可控 ODE 试验

系统：阻尼振子，m x'' + c x' + k x = 0。以 z=(x,v) 表示状态，学习输入(t,m,c,k,x0,v0)到(x,v)的映射，或统一采用状态推进模型；同一轮比较不混合两种任务定义。

先验：m>0、k>0、c>=0；初始状态约束；x'=v；m v'+c v+k x=0。

能量 E=0.5*m*v^2+0.5*k*x^2，满足 dE/dt=-c*v^2。仅 c=0 时能量守恒；阻尼系统不能错误强制恒能量。

建议数据设计（无量纲化后）：
- m,k 各在 [0.5,2.0]，c 在 [0,0.5]；x0,v0 各在 [-1,1]。
- 先以解析解或高精度独立求解器生成约 1,000 条轨迹；在部分样本上做容差/步长收敛验证。
- ID 按完整轨迹固定 70/15/15 划分。归一化仅拟合训练集。
- 额外 OOD：单独改变质量范围 [2.2,3.0]，或阻尼范围 [0.6,1.0]；不同变化轴分别报告，避免混淆。
- 时间训练区间 [0,10]，长时测试 (10,30]，同时报告预测尾部误差。
- 少数据用嵌套 10%、30%、100% 训练子集；噪声为训练信号 RMS 的 0%、1%、5%，测试真值保持干净，同时可额外评估含噪输入。
- 参数置乱作为依赖诊断；它改变输入一致性，不直接充当正常预测主基线。

对照模型：
B0 不输入物理参数的数据模型，仅作为信息缺失诊断，不是等信息公平主对照。
B1 参数条件化、纯数据监督。
B2 与 B1 同骨干，加入正确运动方程和初始条件损失。
B3 与 B2 同骨干，但训练中漏掉阻尼项或使用偏差刚度。
B4 同骨干、在固定验证预算内选择物理权重；包含权重为零的退路。
B5 可选：已知动力学加神经未知项，用于模型错设修正。

损失形式：L = L_data + lambda_p L_physics + lambda_ic L_initial。先无量纲化，按训练/验证期固定的尺度归一各项。软约束仅推动误差下降，不保证严格满足规律。

实验分两轮：先固定全数据、无噪声验证 B1/B2；成功复现后再逐轴加入数据量、噪声、先验偏差。避免一开始执行巨大全因子矩阵。

## 五、阶段 B：公开 PDE 基准

首选 PDEBench 的 1D Burgers 子集，再考虑二维 Darcy 流或扩散问题。不默认下载整个数据集。

Burgers 方程采用数据集实际定义；常见形式 u_t+u*u_x-nu*u_xx=0。必须核对黏度系数约定、坐标、时间步、边界、降采样方式，不能把通用写法直接当成数据生成方程。

比较：参数条件化 FNO（纯数据）与相同骨干加物理残差；U-Net 可作为额外架构基线。经典逐样本求解的 PINN 与跨样本神经算子不是相同任务，应分开报告训练/推理成本，不做误导性排名。

切分：按初始条件/样本隔离；参数 OOD 留出整个黏度区间；分辨率外推单列，不混同参数 OOD。测试条件冻结，不用于调权或早停。

残差计算：针对网格输出采用验证过的有限差分或谱导数；不能照搬坐标网络自动微分。用真值求解器输出估计离散残差底噪，并检查更细网格，避免模型利用离散算子的盲点。

守恒指标必须服从边界条件与源项。周期无外源 Burgers 可以检查总量平衡；开放边界要计算边界通量。黏性系统不能默认能量恒定。

公开来源：PDEBench 数据 DOI https://doi.org/10.18419/DARUS-2986；代码 https://github.com/pdebench/PDEBench 。开始下载前核对具体文件、许可、大小和哈希。

## 六、评测与统计

主要终点：完整留出轨迹/场上的相对 L2 预测误差。先对每条轨迹计算，再汇总。参考范数接近零时使用明确的稳定化尺度，并补充绝对 RMSE。

次要指标：RMSE、最大误差、独立评估点/网格的方程残差、初始/边界误差、系统正确的守恒或耗散平衡误差、长时发散比例、分频误差、显存、总训练时间、推理时间。

- 正式比较至少 5 个随机种子，报告均值、标准差与配对差值；初筛可用 3 种子。
- 置信区间以独立轨迹/工况为抽样单位；不能把相关时间点当独立样本。分别描述种子波动与测试轨迹不确定性。
- 保持训练数据、骨干容量、优化器、早停规则和调参次数一致；物理损失增加计算，另做等总计算预算敏感性对照。
- 测试集不用于选择超参数或挑选最好种子。
- 总成本包括标签仿真、训练、物理残差计算及测试时适应；区分摊销推理与逐实例求解。
- 预设“收益”需要主预测指标改善，物理指标不恶化，且成本可接受；具体工程阈值在目标领域明确后预注册。
- 若正确物理只在部分区间有益，报告适用边界；若无提升，核查尺度、初始条件、优化与离散误差后如实报告，不删失败工况。

## 十、如果研究对象必须是语言大模型

改为受控系统研究：LLM 直接作答、LLM 加物理检索、LLM 加求解器、LLM 加物理一致性检查的对照。评测单位与量纲正确率、参数提取、方程选择、边界与初始条件完整性、数值误差、工具调用成本及反事实条件变化。

将语言解释正确性与数值系统正确性分开评分；调用外部求解器只能说明系统利用物理，不能证明基础模型内部学会规律。除非具备可微数值模块，不直接把 PINN 的坐标导数损失套在离散文本输出上。该分支需另选数据与基准，不能与上述数值模型实验混为同一贡献。
